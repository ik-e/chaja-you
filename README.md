# chaja-you

사용자의 요청에 맞춰 조사 작업을 설계하고, 전문 에이전트가 나누어 조사한 뒤 출처가 있는 결과를 종합하는 시스템을 개발합니다.

이 공개 저장소에는 공개 가능한 코드와 프로젝트 개요, 협업 안내만 둡니다. 팀 내부 기록과 원본 자료는 저장소에 포함하지 않습니다. 범위는 [공개 프로젝트 개요](docs/public/프로젝트_개요.md)와 [공개 저장소 운영 안내](docs/public/공개_저장소_운영_안내.md)를 참고하세요.

## 시작하기

- 프로젝트 맥락과 저장소 지침은 [AGENTS.md](AGENTS.md)를 읽습니다.
- 팀이 참고할 공개 문서는 [docs/README.md](docs/README.md)에서 찾습니다.
- Discord 읽기 도구 설정은 [Discord 읽기·검색 도구 안내](docs/public/Discord_읽기_검색_도구.md)를 참고합니다.

## 보안

비밀값은 로컬 `.env`에만 저장합니다. `.env.example`에는 변수 이름만 두고 실제 토큰이나 비밀번호를 넣지 않습니다. 공개 저장소에 한 번 올라간 비밀값은 파일을 삭제해도 Git 이력에 남을 수 있으므로, 노출 시 즉시 폐기하고 교체해야 합니다.

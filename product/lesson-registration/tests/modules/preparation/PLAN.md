# TASK-049 · 등록 정보 준비 모듈 계획

- 담당 R02 · 2026-11-25 · 상태 상세 계획과 합성 사례 준비, 실제 모델·구현 시험 전
- 적용한 공통 기준 `339dd8e9a0d1390f0a26aa4c26002bf368bf967e`
- 작업 브랜치 `r02/product-preparation` · 공통 계약 CS-01·CS-02, I2 `PrepareInput → Preparation`
- 목표는 기존 레슨 자료의 사실을 출처와 함께 정리하고, 플랫폼 모의 프로필의 누락·충돌을 사용자에게 확인받는 것이다.

## 경계와 담당자 협의

I2는 `PreparationPort.prepare(request)` 동기 함수다. 입력은 `source`, `profile`, `answers`이며 출력은 `ready`, `values`, `facts`, `issues`, `provenance`다. 결과가 준비 완료일 때 R03은 프로필 값 스키마를 다시 확인한다. 원문 Source는 보존하고 R03이 정규화한 ResolvedAnswer를 받아 현재 등록 준비에 반영한다.

- R03에는 사용자 답변과 원본 사실이 충돌할 때 어떤 `field`와 `conflict` 이슈를 반환해야 `FACT_CONFLICT`로 연결되는지, 모델 중단과 안전 오류의 전달 형태 및 제한 시간을 예제와 함께 확인한다.
- R01의 PR #44 D05는 동기 포트 유지, DB 트랜잭션 밖의 제한된 호출, 늦은 결과 무시를 제안한다. PR은 아직 열려 있다. timeout·revision 및 모델 취소 방식은 확정되지 않았다.
- R03의 독립 서버는 `MODEL_UNAVAILABLE`과 일반 예외를 준비 차단 이슈로 저장하며 스키마가 잘못된 응답은 `RUNTIME_ERROR`로 판정한다. 특정 예외와 응답 지연의 실제 연결은 R02·R03이 공동 시험한다.
- R04·R05와 모의 프로필의 필수 항목과 오류 표시를 맞춘다. 크몽 3단계는 현재 모의 프로필에 한정한다. 단일 모드는 R02 화면에서 가능한 것으로 확인했지만 이 mock 프로필에 없는 상태이며 임의로 빈 패키지를 채우지 않는다. 숨고 mock은 서비스 설정이며 견적·결제를 다루지 않는다.

## 구현 순서

1. 고정 스키마와 Profile 필드를 공통 `SchemaCatalog`로 검증한다. 유효하지 않은 입력이나 허용되지 않은 profile에는 안전한 오류를 반환한다.
2. 모델 호출 인터페이스를 담당 영역에 두고 합성 원문에서 사실 후보·근거 locator·질문을 받는다. 원문에 없는 가격, 단위, VAT, 제공 범위는 자동 확정하지 않는다. provider 선택·접근 환경·비용·의존성은 확인 후 기록한다.
3. 사실과 출처를 검증하고 승인 값과 선택한 프로필 필드를 대조한다. 누락과 출처 불명, 서로 다른 가격·단위·VAT는 issue로 남기며 blocking issue가 있으면 `ready=false`다. 계산·변환은 근거와 단위가 명확하고 프로필 규칙에 맞을 때만 후보로 낸다.
4. 정규화된 사용자 답변을 적용한 뒤 재검사한다. 원본 사실과의 충돌을 숨기거나 임의로 한쪽을 선택하지 않는다. 사실 수정과 현재 요청에만 적용되는 선택을 CS-02에 맞춰 구별한다.
5. 합성 후보로 정상·누락·충돌·잘못된 모델 응답·모델 불가·timeout·늦은 결과·사용자 재답변을 시험한다. 실제 모델 시험은 승인된 환경과 합성 자료에서 별도 수행한다.
6. 공통 계약, R03 연결 및 AT-01·T5-08·T6-02 제품 시험은 동일한 후보·계약·입력에서 별도로 관측한다. 준비 모듈의 단독 통과와 전체 제품 통과를 구별한다.

## 합성 사례와 완료 기준

[사례 목록](../../../fixtures/source/preparation-cases.json)에 각 입력의 기대 관측값을 정리했다. 실사용자 원본·사진은 포함하지 않는다. 모델 원문을 근거로 오인하지 않도록 인용과 데이터 원본을 대조한다.

- AC1 실제 모델의 사실·근거·질문 생성과 크몽·숨고 프로필 검증. 현재 미실행.
- AC2 가격·단위·VAT 누락과 충돌을 유지하고 임의 값 생성 금지. 현재 구현·시험 전.
- AC3 재현 명령, 합성 자료, 유지보수 인계. 12/4는 인계 후보 목표이며 담당자 가용성과 공수 확인 전.

## 환경 및 검증 기록

- 임시 worktree macOS, Python 3.12.16, `uv` 0.13.10. 제품 lock 기준 `uv sync --locked --python 3.12` 성공.
- `uv run --locked --python 3.12 python dev.py doctor` 통과. 계약 핀·소유권·합성 이미지 확인.
- `uv run --locked --python 3.12 python dev.py test r02-preparation` 통과. **초기 replay 1개**이며 준비 모듈의 실제 기능이나 실제 모델 시험을 뜻하지 않는다.
- 현재 환경에서 일반적인 주요 모델 API 키 환경변수 및 로컬 Ollama는 확인되지 않았다. 실제 모델 사용 경로와 비용·승인된 시험 환경은 미확인이다. 비밀값은 조회·기록하지 않았다.
- 변경된 공통 계약·의존성은 없다. 담당 영역 내부의 세부 설계와 fixture만 준비한다.

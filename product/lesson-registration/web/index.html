레슨 멀티플랫폼 등록 지원 시스템

단일 원본 레슨 입력을 바탕으로 숨고/크몽 플랫폼의 모의 등록을 안전하게 조율합니다.

R04 Web UI MVP

1. 원본 레슨 정보 (Source)

강사의 원본 레슨 사실을 입력합니다. 원본 사실은 불변이며, 수정 시 새로운 불변 버전이 생성됩니다.

2. 등록 준비 및 질문지 확인 (Prepare)

선택한 플랫폼에 맞게 AI가 구조화한 필수 문항 답변을 검토하고 수정합니다. 준비 상태가 완료(Ready)되어야 승인 단계로 진행할 수 있습니다.

준비 완료 (Ready: True)

플랫폼 필수 문항 확인

3. 플랫폼 인증 및 원격 뷰어 (Auth)

원격 브라우저 세션에 안전하게 로그인합니다. 인증 토큰은 화면 뷰어에만 일시 전달되며 저장되지 않습니다.

[뷰어 세션 열기]를 클릭하면 여기에 격리된 원격 브라우저 화면이 마운트됩니다.

인증 상태: 준비됨 (Ready) 확인된 계정: acc-soomgo-midi-42

4. 최종 검토 및 승인 (Review)

등록될 최종 설정값을 확인하고 승인합니다. 승인 후에는 취소, 변경, 롤백이 불가합니다.

# R04 · 사용자 입력·승인·결과 화면 코드 영역

R04 책임(착수 승인 이후):
1. 합성 원본/이미지 입력 → F1 결과/충돌 검토 → 지정한 초안 버전·동작 승인 → 모의 실행 요청 → 결과 확인의 **클릭 가능한 화면**.
2. R03 상태·오류 의미 그대로 표시. `unknown`을 완료/접수 성공으로 표시하지 않음.
3. 계약과 동일한 mock 응답으로 먼저 실행, R05 API 연결 시 교체하는 접점 유지.
4. 정상·값 누락·응답 유실 3가지 UI 시연 경로 및 최소 재현 명령 제출.

**제외:** 판매 조건의 업무 규칙 복제, 실제 플랫폼 브라우저 제어, 자격증명 수집.

**산출:** 실행 가능한 UI 코드 + 화면별 I/O 연결표 + 동작 증거. 프레임워크 선정은 R05와 기술 계약 정렬 뒤.

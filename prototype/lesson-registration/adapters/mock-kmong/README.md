# R05 · F2 모의 등록 어댑터/연결 코드 영역

R05 책임(착수 승인 이후):
1. **실제 크몽이 아닌** 로컬 모의 등록 폼(필수 필드/파일 업로드/제출 응답만) 제공. 실제 화면 필드는 출처 확인 수준 표시.
2. R03의 승인 스키마를 받아 `mock` 환경에서만 필드 입력·샘플 이미지 첨부.
3. 등록 작업/단계 이벤트/모의 증거 참조 반환; 업로드 실패·응답 유실(unknown) 주입 가능.
4. R04 UI 연결용 최소 인터페이스·애플리케이션 실행 경계 정의, 실제 동작 명령과 로그 제출.

**제외:** 실제 계정 로그인, 세션·OTP 수집, 크몽 무단 자동 제출·안티봇 우회, R03 검증 규칙 재구현.

**판정:** 합성 fixture 1건으로 mock 입력·첨부가 재현되고, 오류/unknown을 구분한 실제 실행 결과가 있어야 완료.

# R03 · 업무 규칙/상태 코드 영역

R03 책임(착수 승인 이후):
1. 합성 `SourceLesson`에서 F1 필드 검증·변환 후 draft/error 반환.
2. 가격·시간·횟수·추가 비용·일정 변경 조건을 원본 없이 임의로 만들지 않음.
3. 승인 버전/허용 동작 검증과 F3 `unknown`/실패/모의 성공 상태 판정 및 자동 재시도 차단.
4. 호출 가능한 코드와 단위 테스트(정상 1, 값 충돌 1, 승인 버전 불일치 1, unknown 1 이상) 제출.

**제외:** UI·실제 크몽 자동조작·API/DB 서버 구현. 상태와 오류 의미는 [공통 계약](../contracts/README.md)에서 먼저 협의.

**산출:** 실행 명령, expected vs actual, 테스트 로그. 설계/샘플의 존재만으로 코드 완료 판정하지 않음.

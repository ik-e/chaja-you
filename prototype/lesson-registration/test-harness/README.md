# R03 · 공통 모의 테스트 환경 (TASK-043)

- **목표:** R04 숨고 및 R05 크몽 구현에 공통으로 제공할 오프라인/로컬 모의 등록 환경.
- **만들 것:** 합성 레슨 데이터와 대체 이미지, 플랫폼별 최소 mock 페이지, 입력/첨부/승인/결과 오류 주입, 정상·필수 누락·미승인·업로드 실패·응답 유실/unknown 테스트.
- **기준:** 크몽은 레슨 서비스 상품 1건. 숨고는 고수 프로필·서비스 등록이 다르므로 R04가 실제 등록 객체를 확인하기 전에는 임시 가정으로만 표현.
- **제출:** 이 폴더에 실행 가능한 테스트 코드/fixture/mock 페이지, 재현 명령, 테스트별 기대/관측 로그, 설치 의존성/버전 근거.
- **완료:** 실제 외부 계정 없이 mock 정상/오류/unknown을 재현하고 결과를 증명. 실제 크몽·숨고 게시 성공으로 기록하지 않음.
- **금지:** R04·R05의 내부 기술 스택 강제, 실제 사이트 자동 제출, 개인 계정/세션/비밀번호 보관.
- **설계:** 시작 시 입력/출력/상태/오류 최소 계약을 기록. 기술은 담당자 선택, 공통 루트 의존성은 협의 후 반영.

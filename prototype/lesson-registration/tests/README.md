# MVP 인수 시험 (계획)

이 폴더에는 착수 승인 후 재현 가능한 테스트 코드와 공개 가능한 합성 입력을 둔다. **현재 테스트는 전부 미실행**이다.

| 케이스 | 조건 | 기대값 |
| --- | --- | --- |
| C01 | 유효한 합성 레슨 1건과 이미지 | F1 사실 보존→버전 승인→mock 입력/첨부→mock 결과 |
| C02 | 필수 조건 누락 또는 가격/시간 충돌 | 사용자 확인 필요·자동 확정 금지 |
| C03 | 승인 v2 후 draft v3 실행 | 거절 및 재승인 요구 |
| C04 | mock 사진 첨부 실패 | 실패 기록·거짓 성공 없음 |
| C05 | mock 제출 직후 응답 유실 | unknown·자동 재제출 0건 |
| C06 | 허용되지 않은 live 실행 | 사전 차단 |
| C07 | 승인 없이 실행 | 차단·승인 요청 |

R03: 사실/상태 테스트, R05: 어댑터·API/통합 테스트, R04: 화면 동작, R01: E2E 판정. 케이스별 환경·명령·버전·기대/관측·증거를 기록하며 PASS는 실행 증거가 있을 때만 사용한다.

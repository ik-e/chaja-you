# 현행 기준선 및 이력 적용 규칙

- 근거: R01 2026-11-25 지시 — “이전에 설계들은 내가 더 진행하지 않고 새롭게 한 이유는 분명해서 기록으로만 남겨두면 충분하지 않아 그래서 헷갈리지 않게 정확한 기준선을 만들면 되잖아”
- 현행 진입점: [사람용](CURRENT-DESIGN.md) · [AI용](CURRENT-DESIGN.json). 이 문서는 적용 범위와 검증 실행 규칙이며 별도 제품 설계 정본이 아니다.
- 이전 설계는 재개하거나 다시 채택하지 않는다. 당시 결정·대안·근거만 보존하며 누락된 과거 이유를 소급 작성하지 않는다.
- 적용 순서: 현재 Phase/사용자 승인 → A2 등 상위 의무 → 채택 논리 V5·데이터 V4.1·프로필 V2·공통 V1 → IB-01~05 승인 구현 방향 → 현재 TASK/WORKSPACE. 상위 계약과 충돌하는 하위 결정은 적용하지 않는다.
- 이전 WBS, V0.3~V0.8 계약, 초기 로컬 브라우저 가설, 재개/취소 정책은 현행 실행 기준이 아니다. 명시적으로 계승된 요구사항 및 고정 참조만 사용한다.
- 이전 브랜치는 [보관 기록](BRANCH-REVIEW-20261125.md)에서 조회한다. archive 브랜치는 절대 main에 병합하지 않는다.
- 검증은 [독립 검증 실행 안내](VALIDATION.md)를 따른다. 과거 검증의 통과를 현재 제품 성공으로 승격하지 않는다. 실제 서비스 접근 금지, 실제 제품 시험은 별도.

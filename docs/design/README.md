# 설계 문서

- `architecture/`: 시스템 구성, 구성 요소, 데이터 흐름
- `api/`: API 계약, 요청·응답 예시, 오류 규칙
- `data/`: 데이터 모델, 스키마, 마이그레이션 기준
- `decisions/`: 주요 선택의 맥락과 근거를 남기는 설계 결정 기록

현재 유효한 설계 내용을 갱신하고, 영향이 큰 선택의 변경 이유는 `decisions/`에 날짜별로 남깁니다.

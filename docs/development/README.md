현재는 **의미 있는 기능·계약 변경에 TASK 브랜치와 PR을 기본으로 사용**합니다. 의미가 바뀌지 않는 작은 문서·프로젝션 갱신은 직접 반영할 수 있으며, 모든 PR에 R01 승인을 요구하지 않습니다. TASK 내부는 owner, 공유 계약은 관련 owner, 제품 범위·공통 구조는 R01이 결정·확인합니다.

이 README와 협업 규칙은 기존 결정을 설명하는 문서입니다. 새 운영 결정을 임의로 만들지 않으며, 기준이 바뀔 때에는 사람의 결정 기록을 근거로 함께 갱신합니다.

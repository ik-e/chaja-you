## 6. 작성 규칙 및 한계

- 단일 동작은 한 주체·한 논리 효과를 기준으로 정의한다. 동일 행위의 매개변수화(정확 대상/항목/결정 종류)와 실제 분리 가능한 효과를 구분. 복합 업무는 별도 동작 조합이며 실제 클릭/함수 수와 무관.
- 대상 유형이 여러 개 적힌 동작은 허용 대상 타입의 선택이며 실제 호출에서는 정확 하나의 대상/항목 또는 사전 정의된 요청 범위를 명시한다. 결과를 여러 가지로 해석하는 포괄 업무명이 아니다.
- R03 외부 플랫폼 동작은 외부 실제 처리에 대한 의미 모델이며 플랫폼에 해당 기능이 존재하거나 프로젝트가 이를 실행할 수 있다는 주장 아님.
- C20~C23은 역할·관계 유형이다. 특정 외부 실체가 여러 역할을 가질 수 있으며 모든 논리 개념을 독립 DB 테이블로 만들지 않는다.
- 별도 채택/조건부/범위 밖 용어는 의미만 정의. 실제 팀 자료상의 필드 의미·하위 객체 식별·정확 완료 효과·정책 근거 미확인은 유지.
- 기존 모의 실행 제한 유지. 현재 의미 모델 자체는 사용자 행동의 최종 SVO 원장이나 화면 설계가 아니다.

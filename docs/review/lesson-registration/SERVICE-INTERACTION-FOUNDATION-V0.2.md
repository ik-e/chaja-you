# 서비스 행동·업무 대상·사용자 상호작용 기준 V0.2

> 기획안 V1.2가 기준. 팀원 조사 근거. 2026-11-28 / TASK-058 / 검토 초안. 페인포인트를 해결하는 주체는 서비스. 기존 사용자 행동의 직접 해결/보조 역할 분류는 대체한다. 원본 330개는 수정하지 않는다.

## 1. 설계 기준

- 문제 → 사용자 목표/기대 결과 → 문제를 해결하는 서비스 행동 → 필요한 사용자 상호작용 → 서비스 응답/오류 대응 → 가치.
- 서비스 행동은 직접 해결·성립 지원·복합·조건부로 구분. 강사가 실제로 해야 할 행동은 정보 제공·선택·판단·직접 인증·승인·요청 등이다. 열람과 기대 결과는 버튼 클릭 요구가 아니다.
- 사용자 목표(원하는 것), 실제 SVO 행동(하는 것), 서비스 결과(기대하는 것), 오류 상황에서의 서비스 응답은 구분한다. 사용자 행동의 모든 기존 ID를 정확 의미 대상·서비스 행동·기대 결과와 연결한다.
- 객체·업무 효과·완료 조건을 먼저 정한다. 논리 대상 정의는 DB 구조 또는 UI를 결정하지 않는다.

## 6. 사용자 상호작용 계약 목록

아래는 목표, 사용자 행동, 서비스가 제공해야 할 결과를 분리한 검토 단위이며 스토리/화면/흐름 확정 아님. 직접 조작은 필요한 경우에만. 실제 사용자 행동은 기존 원장 번호와 연결한다.

### I01. 서비스 이용 안내·지원 범위

- **원하는 것:** 강사는 자신의 업무를 서비스가 어디까지 지원하는지 알고 싶다.
- **사용자 행동 후보:** 서비스 안내를 읽거나 필요한 플랫폼의 업무와 제약을 확인한다. 첫 이용 및 정보가 필요할 때만.
- **기대 서비스 결과:** 지원/미지원/미확인과 직접 수행 필요 사항이 분명하다. 외부 업무를 가능하다고 과장하지 않는다.
- **오류/제약 시 기대:** 미확인 또는 제한이면 이유와 가능한 내부 지원을 제공한다.
- 대상: O01 · O16 / 용어: T11 · T19 / 서비스: F06 · B01 / 범위: 기획 관련 또는 보조 책임; 개별 후보 범위 유지

### I02. 서비스 본인 식별

- **원하는 것:** 강사는 본인의 정보와 작업에 안전하게 접근하고 싶다.
- **사용자 행동 후보:** 필요할 때 서비스 인증·가입·동의·복구를 수행한다. 작업 공간 선택은 실제 필요성이 확인될 때만.
- **기대 서비스 결과:** 본인 자료만 접근 가능하며 인증 방법과 실패/복구가 분명하다.
- **오류/제약 시 기대:** 인증 실패/계정 불명/동의 거절 시 자료 노출과 작업 시작을 차단한다.
- 대상: O01 / 용어: T02 / 서비스: B01 / 범위: 기획 관련 또는 보조 책임; 개별 후보 범위 유지
- 기존 행동 후보: UA-002, UA-003, UA-004, UA-005, UA-006, UA-007, UA-008, UA-280

### I03. 원본 목록·선택

- **원하는 것:** 강사는 여러 레슨 중 필요한 원본을 찾아 재사용하고 싶다.
- **사용자 행동 후보:** 필요한 기존 원본을 선택한다. 검색·재조회는 필요한 경우만.
- **기대 서비스 결과:** 본인의 저장 원본과 필요한 정보가 제공되고 동일 값을 다시 입력하지 않는다.
- **오류/제약 시 기대:** 조회 실패/없음/권한 불일치 구분, 기존 원본 보존.
- 대상: O01 · O02 · O03 / 용어: T02 / 서비스: F02 · B01 / 범위: 기획 관련 또는 보조 책임; 개별 후보 범위 유지

### I04. 새 원본 제공·직접 작성

- **사용자 행동 후보:** 기존 자료를 제공하거나 필요한 레슨 사실을 입력한다. 이미 제공된 값과 자동 추출 가능한 표현은 반복 입력하지 않는다.
- **기대 서비스 결과:** 서비스가 제공 자료를 구조화하고 필요한 실제 사실·자료만 수집한다. 새 원본은 외부에 자동 등록되지 않는다.
- **오류/제약 시 기대:** 필수값·파일 오류·권리 문제에 대해 해당 항목만 안내한다.

### I05. 자료 권리·용도·공개 범위

- **원하는 것:** 강사는 적절한 자료만 필요한 용도로 사용하고 싶다.
- **사용자 행동 후보:** 필요시 자료의 권리·용도·공개 범위를 결정하고 문제가 있는 자료를 교체·제거한다.
- **기대 서비스 결과:** 대표/프로필/본문 등 목적별 자료와 권리·규격 문제를 분리한다. 유효한 자료는 재첨부하지 않는다.
- **오류/제약 시 기대:** 권리 불명·규격 위반 자료는 해당 사용을 제한하고 정정 기회를 제공한다.

### I06. 추출 사실 검토·보완

- **사용자 행동 후보:** 필요한 경우 근거와 추출값을 검토하고 누락된 사실을 제공하거나 잘못된 값을 정정한다.
- **기대 서비스 결과:** 확인된 사실 및 근거가 연결되고 임의 가격·시간·자격 등이 생성되지 않는다.
- **오류/제약 시 기대:** 추출 실패/불확실/충돌은 자동 확정하지 않고 필요한 사실만 요청한다.
- 대상: O02 · O03 · O05 / 용어: T01 · T06 / 서비스: F03 · F09 · F10 / 범위: 기획 관련 또는 보조 책임; 개별 후보 범위 유지

### I07. 원본 수정

- **사용자 행동 후보:** 필요한 원본 항목을 변경한다. 동시 편집/업무 영향이 있을 때 변경 차이와 적용 범위를 확인한다.
- **기대 서비스 결과:** 정확한 원본에 수정이 반영되고 과거 승인 및 다른 외부 등록물은 임의 변경되지 않는다.
- **오류/제약 시 기대:** 최신본 충돌/저장 불명은 덮어쓰기 금지, 해당 편집을 복구할 수 있게 안내한다.
- 대상: O02 · O03 · O14 / 용어: T03 / 서비스: F04 · F05 · B05 / 범위: 기획 관련 또는 보조 책임; 개별 후보 범위 유지

- **사용자 행동 후보:** 저장 의사를 표현한다. 저장만 또는 저장 후 준비 의도를 선택할 수 있다. 실패 확정 후에만 새 시도, 불명은 기존 요청 확인.
- **기대 서비스 결과:** 저장 성공/실패/불명과 현재 자료가 분명하고 같은 값·대상을 다시 입력하지 않는다.
- **오류/제약 시 기대:** 미확인 저장을 성공/실패로 단정하지 않으며 동일 요청 결과 확인.
- 대상: O02 · O10 · O14 / 용어: T01 · T03 · T20 / 서비스: F05 · F07 · B06 · B10 / 범위: 기획 관련 또는 보조 책임; 개별 후보 범위 유지

### I09. 원본 삭제

- **원하는 것:** 강사는 불필요한 원본 정보를 제거하고 싶다.
- **사용자 행동 후보:** 정확한 원본에 삭제 요청을 하고 필요한 영향/보존 안내를 확인한다. 불필요한 확인 조작은 줄인다.
- **기대 서비스 결과:** 삭제 완료·보류·실패, 남은 기록/연결 처리와 외부 게시물 유지 여부가 분명하다.
- **오류/제약 시 기대:** 진행/미확인 업무·보존 요구·삭제 요청 불명은 안전하게 처리하고 상태를 전달한다.

### I10. 업무 의도·플랫폼 선택

- **사용자 행동 후보:** 작업 대상과 업무 종류를 선택한다. 준비 의도 및 플랫폼 선택은 이미 확인된 경우 다시 요구하지 않는다.
- **기대 서비스 결과:** 서비스가 정확 대상별 업무의 지원/준비/보류 범위를 표시하고 다른 채널과 독립 처리한다.
- **오류/제약 시 기대:** 지원/허용 미확인·부적합 업무는 제한하고 이유 제공.

### I11. 플랫폼별 입력안 준비

- **사용자 행동 후보:** 자동 생성된 입력안을 필요시 검토하고 누락·잘못된 플랫폼 값만 보완하거나 정정한다.
- **기대 서비스 결과:** 서비스가 자료 재사용·변환·검증·재생성을 처리하며 정상값은 유지한다.
- **오류/제약 시 기대:** 규격·변환 실패·불확실성은 해당 항목만 정정 또는 보류한다.

### I12. 플랫폼별 적용 조건 결정·관리

- **오류/제약 시 기대:** 지원/의미 불명·가격/시간 등 충돌 시 관련 효과만 보류하고 대안을 안내한다.

### I13. 제약 충돌 대안 선택

- **원하는 것:** 강사는 실제 제공할 수 없는 조건을 임의 적용받지 않고 가능한 대안을 받고 싶다.
- **사용자 행동 후보:** 실제 값과 환산 결과 및 충돌을 확인하고 제공 가능한 대안을 선택하거나 거절한다.
- **기대 서비스 결과:** 선택한 실제 조건만 재변환·검증한다. 유효한 대안이 없으면 해당 효과를 진행하지 않는다.
- **오류/제약 시 기대:** 관련 가격 변경만 보류하고 독립적인 다른 업무는 유지한다.

### I14. 보류·제외·재검토

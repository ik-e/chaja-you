# 식별 조건 기반 용어 및 동작 계약 V0.5

> 기획안 V1.2 기준 / R01 / 검토안. 이전 V0.4의 자연어 설명을 실행 기준으로 사용하지 않는다. 객체 유형 ID와 인스턴스 ID를 구분하고, 동작에는 정확한 대상과 전후 효과를 지정한다.

## 1. 주체

| ID | 명칭 | 정의 | 제외 |
|---|---|---|---|
| ACT.USER | 강사 | 본인에게 귀속되는 서비스 요청을 작성하거나 공식 외부 화면에서 직접 행동하는 사람. 실제 서비스 권한은 인증된 ACT.USER와 ACCOUNT 참조로 판정한다. | 사람과 계정은 동일 개념이 아니며, 서비스가 동일인 여부를 추측하지 않는다. |
| ACT.SERVICE | 찾아you | 내부 읽기·쓰기, 사용자에게 정보 제공, 허가된 외부 동작 시도, 근거에 의한 판정을 수행하는 제품 책임 주체. | 외부 플랫폼의 실제 변경이나 사람의 결정을 대신했다고 정의하지 않는다. |
| ACT.PLATFORM | 외부 플랫폼 | PLATFORM으로 식별된 외부 시스템에서 자체 객체와 심사·공개 등의 상태를 실제로 처리하는 주체. | 서비스의 관측·효과 판정 주체가 아니다. |
| ACT.OPERATOR | 운영자 | 서비스 운영 사건의 조사 및 허용된 대응을 담당하는 역할. | 강사의 승인 대행 주체 아님. 제품상 관리자 개입 절차 미채택. |
| ACT.AUTH_PROVIDER | 공식 인증 제공자 | 실제로 별도 공식 인증 사업자가 있을 때 해당 인증 요청에 대한 결과를 제공하는 주체. | 인증 사업자 도입 자체는 미결정. |
| ACT.RIGHTSHOLDER | 자료 권리자 | 정확 자료에 대해 사용 허용 여부를 결정할 법적 권리를 가진 사람 또는 조직. | 정보주체와 동일하다고 가정하지 않음. |
| ACT.DATA_SUBJECT | 정보주체 | 특정 개인정보로 식별되거나 식별될 수 있는 사람. | 자료 권리자와 동일하다고 가정하지 않음. |
| ACT.LEARNER | 수강생 | 외부 모집 정보의 대상이 되는 사람. | 기획상 제품의 수강생 상담·결제·수업 관리 주체가 아님. |

## 2. 대상 유형 전체

| 유형 ID | 명칭 | 종류 | 생성/성립 조건 | 동일성 | 구성 | 변경 | 종료 | 제외 |
|---|---|---|---|---|---|---|---|---|
| ACCOUNT | 서비스 계정 | record | 서비스의 가입 절차에서 계정이 생성된 때 | 같은 서비스 계정 ID | 계정 ID, 계정 접근 상태, 서비스 인증에 필요한 참조 | 이메일/표시명 변경은 계정 ID를 바꾸지 않는다 | 계정 삭제/사용 불가 시 기존 ID 재할당 금지 | 동일 이름·이메일만으로 동일인/동일 계정 판정 금지 |
| SESSION | 서비스 로그인 세션 | record | 서비스 인증 후 세션 발급 시 | 같은 발급 세션 ID | 계정 ID, 발급/만료 시각, 접근 범위 | 세션 종료/만료는 기존 세션 상태 변경 | 종료/만료 후 재사용 금지, 새 발급은 새 세션 | 외부 플랫폼 세션 아님 |
| AUTH_ATTEMPT | 인증 시도 | event | 인증 절차를 한 번 시작할 때 | 같은 시도 ID | 인증 대상 종류 SERVICE 또는 EXTERNAL, 요청 주체, 목적, 시작 시각, 결과 참조 | 추가 인증 단계는 같은 시도에 포함할 수 있음; 새 시작은 새 시도 | 종료·실패·취소·만료 기록 | 인증 성공/계정 권한/세션 자체 아님 |
| LESSON | 저장 레슨 정보 | record | 강사가 새로 저장할 정보로 지정하고 서비스가 최초 저장에 성공한 때 | 같은 레슨 정보 ID. 값·제목·수업 내용 일치 여부는 동일성 기준 아님 | 레슨 정보 ID, 소유 계정 ID, 현재 항목값 집합, 자료 사용 관계 집합 | 기존 ID를 지정하여 저장하면 값이 바뀌어도 같은 레슨 정보. 새 정보로 저장하면 내용이 동일해도 새 ID | 삭제 확인 후 해당 ID는 활성 원본으로 조회/사용 불가; 필요한 기록 참조만 별도 보존 | 실제 강의 상품/수업 회차/외부 게시글/파일 한 개/버전 자체가 아님 |
| EDIT | 미저장 편집 내용 | record | 새 저장 또는 기존 정보 변경을 위해 편집을 시작할 때 | 같은 편집 문맥 ID와 대상(기존 LESSON ID 또는 NEW) | 편집 대상, 기준 버전, 아직 저장되지 않은 항목값과 자료 관계 | 편집값 변경은 저장 레슨 정보 변경 아님 | 저장 완료 또는 폐기 확인 후 해당 편집값 적용 종료; 보존 방식 미정 | 이미 저장된 LESSON 값과 구분 |
| FIELD_DEF | 정보 항목 정의 | schema | 항목의 대상 유형·의미·값 형식·단위·적용 범위를 정할 때 | 같은 항목 정의 ID와 규격 버전 | 대상 유형, 의미, 값 형식, 단위, 복수값 여부, 적용 범위 | 의미/단위가 달라지면 다른 정의 또는 명시 버전 | 폐기된 정의는 새 입력 검증에 사용하지 않음 | 값 자체/화면 라벨 아님 |
| FIELD_VALUE | 정보 항목값 | value | 정확한 항목 정의에 값을 제공하거나 추출/변환/관측할 때 | 같은 소속 대상/항목 정의/적용 위치·범위의 값 슬롯. 값 변경은 슬롯 변경 아님 | 소속 대상 참조, FIELD_DEF 참조, 값 또는 값 없음, 단위, 출처, 적용 범위 | 값과 출처·검토 결과는 별개로 변경 가능 | 해당 값 슬롯 제거/대체 시 이전 값의 현재 적용 종료 | 진실을 보장하지 않음; 모르는 값을 거짓/0으로 대체 금지 |
| MATERIAL | 제공 자료 | record | 강사가 특정 파일·텍스트·링크를 제공하고 자료 참조가 생성된 때 | 같은 자료 ID. 파일명/URL만으로 동일성 확정 금지 | 자료 ID, 소유/제공 주체, 종류, 실제 내용 또는 참조, 출처 | 내용 교체는 별도 자료 또는 명시 개정 참조로 처리; 자료 ID의 의미를 임의 변경하지 않음 | 삭제/접근 제한 확인 시 더 이상 사용 불가 | 자료 사용 관계/외부 첨부 파일 아님 |
| MATERIAL_USE | 자료 사용 관계 | relation | 자료를 특정 정보 또는 입력안에 특정 용도로 사용하도록 지정할 때 | 같은 소속 대상 ID·자료 ID·용도 키 | 소속 대상(LESSON, EDIT, INPUT_SET 중 정확 하나), 자료 ID, 용도 | 용도가 달라지면 다른 관계; 같은 관계의 세부 속성 변경은 동일 관계 | 관계 제거 확인 시 해당 용도에서 미사용 | 자료 자체 삭제 및 외부 첨부 삭제 아님 |
| RIGHTS | 자료 사용 허용 범위 | decision | 권리자/강사의 사용 권한 정보와 공개 허용 범위를 기록할 때 | 같은 자료 ID·용도·권리/공개 항목·판정 시점 | 자료, 용도, 권리 정보, 공개 대상/범위, 출처, 확인 여부 | 권리 정보 변경은 새 판단 근거; 기존 사용 영향 별도 확인 | 철회·만료 후 해당 범위 사용 금지 | 사용자 주장만으로 권리 실재 확정 아님 |
| PLATFORM | 플랫폼 | reference | 조사 대상 외부 서비스가 등록될 때 | 같은 플랫폼 ID | 플랫폼 ID, 서비스 명칭, 공식 출처 | 표시명 변경은 같은 플랫폼으로 확인될 때 ID 유지 | 범위에서 제외되어도 이력 ID 유지 | 외부 계정 또는 접속 방식 아님 |
| EXT_ACCOUNT | 외부 플랫폼 계정 | reference | 외부 공식 인증 등으로 계정 식별 근거가 확보될 때 | 같은 플랫폼 및 플랫폼이 보장하는 계정 식별 근거. 근거 부족 시 동일성 미확인 | 플랫폼 ID, 외부 계정 식별 근거, 확인 시각 | 표시명 변경은 동일 계정 근거 유지 시 ID 유지 | 접근 해제는 계정 삭제가 아님; 계정 존재/폐쇄는 외부 근거 필요 | 서비스 계정/외부 인증 세션 아님 |
| EXT_TYPE | 외부 대상 유형 | schema | 팀 조사로 외부 시스템의 대상 종류를 구분하고 식별 규칙을 정할 때 | 같은 플랫폼·외부 대상 유형 ID·규격 버전 | 외부 식별 규칙, 상하위 관계, 필드 정의, 지원하는 효과와 근거 | 동일 객체인지 속성인지 미확인인 경우 유형 후보로만 기록 | 실재/식별 미검증 유형으로 실행 불가 | 상품·프로필·게시판을 하나의 동일 유형으로 간주 금지 |
| EXT_OBJECT | 외부 객체 | reference | 정확한 외부 대상 유형의 특정 객체를 외부 근거로 식별할 때 | 같은 플랫폼·유형 및 해당 유형의 외부 식별 규칙이 동일이라고 증명하는 대상 | 플랫폼, 유형, 외부 식별 근거, 접근 계정 참조 | 제목/본문/가격/URL 변경만으로 동일성 변경/유지 확정 금지 | 외부 삭제는 외부 근거 필요; 내부 참조 제거와 별개 | 외부 실제 객체와 이를 가리키는 내부 참조를 혼동하지 않음 |
| EXT_REL | 외부 객체 관계 | relation | 외부 시스템이 정확한 상위·하위 또는 분류 연결을 표현할 때 | 같은 플랫폼·관계 유형·양쪽 외부 대상 식별 근거 | 관계 유형, 상위/하위 또는 분류 참조, 외부 관계 식별 근거 | 관계 속성 변경과 관계 제거/추가 구별 | 외부 관계 제거는 독립 효과 근거 필요 | 내부 관리 관계 아님 |
| LESSON_LINK | 레슨-외부 대상 연결 | relation | 서비스가 정확 LESSON과 외부 대상(EXT_OBJECT 또는 확인된 EXT_REL)의 연결을 기록할 때 | 같은 LESSON ID와 정확 외부 대상 참조 | 레슨 정보 ID, 외부 대상 참조, 식별 근거 | 다른 레슨/외부 대상으로 바꾸려면 별도 관계 제거/추가 | 제거 시 내부 연결만 종료 | 외부 삭제·외부 인증·외부 객체 생성 아님 |
| ACCOUNT_LINK | 서비스-외부 계정 연결 | relation | 별도 제품 채택 시 서비스 계정과 확인된 외부 계정의 관리 관계 기록 | 같은 ACCOUNT ID와 EXT_ACCOUNT 참조 | 서비스 계정 ID, 외부 계정 참조 | 관계 변경과 인증 상태 변경 구별 | 제거 시 계정 후보 관계 종료 | 외부 접근 허가/지속 인증/외부 계정 삭제 아님 |
| OVERRIDE | 플랫폼 적용값 | value | 사용자가 특정 플랫폼에서 적용할 항목값을 별도로 지정할 때 | 같은 LESSON ID·플랫폼·항목 정의·적용 범위(이번 TASK 또는 향후 재사용 규칙)·필요시 계정/외부 대상 | 항목값, 정확 적용 범위, 사용자 결정 근거 | 값 변경은 지정 범위에만 적용; 범위 변경은 새 범위 지정 | 제거/유효 범위 종료 후 적용하지 않음 | 실제 공통 레슨 정보의 자동 변경 및 외부 반영 아님 |
| INPUT_SET | 외부 입력안 | record | 특정 TASK에 대해 서비스가 외부에 입력할 예정 항목값을 구성할 때 | 같은 TASK ID·입력안 버전 식별 | 대상 유형, 적용할 항목값·자료 사용 관계, 출처/변환 규칙 참조 | 값 변경은 입력안 개정; 승인 당시 버전과 구분 | 폐기·대체 시 현재 실행용으로 사용하지 않음 | 실제 외부 저장값·사용자 승인 그 자체 아님 |
| CHECK | 검사 결과 | record | 정확 검사 대상에 규칙을 적용할 때 | 같은 검사 실행 ID·대상·규칙 버전 | 대상 참조, 규칙 참조, 결과 값, 사유·근거, 검사 시점 | 새 검사 결과는 이전 검사 결과 덮어쓰지 않고 구별 가능 | 입력/규칙 변화 시 이전 결과를 현재 충족으로 재사용 금지 | 외부 실제 효과 또는 사용자 결정 아님 |

## 8. 검토 결정 및 한계

- LESSON의 동일성은 현실 세계의 같은 레슨을 자동 판정하는 것이 아니라 강사가 신규 저장과 기존 정보 변경을 구분한 의도 및 서비스 ID로 결정한다. 최초 저장 성공 때 ID를 발급하는 것은 논리 제안이며 사전 UUID 발급 구현을 금지하는 뜻은 아니다.
- 원본이라는 이름을 저장 레슨 정보로 대체한다. 새 정보 최초 저장과 기존 정보 변경 저장은 별개 효과. 제목/값/내용 동일성은 레슨 ID의 동일성 조건이 아님.
- 값은 FIELD_DEF에 결부된 값이다. 출처, 검토 결과, 값 유무는 별도 판정 축이다. 사람 제공/AI 추출 중 어느 쪽도 객관적 사실이라는 보장 없음.
- 객체 유형 식별자와 객체 인스턴스 식별자는 별개. 예시 ID는 계약의 이름이며 DB 키 형식이나 UUID 사용을 강제하지 않는다.
- 외부 객체 ID를 임의 생성하여 외부 실체를 확정하지 않는다. 외부 동일성은 플랫폼별 검증된 식별 규칙과 증거에 의존. 미확인 상태에서는 외부 쓰기 차단.
- 자료 권리자와 정보주체를 독립 주체로 분리했다. 운영자/인증 제공자/수강생의 제품 기능 채택은 미정/범위 밖.
- 복합 동작을 일반 동작 이름으로 숨기지 않는다. U.REQUEST/S.ATTEMPT 등은 구체 종류·대상·인자가 채워지지 않으면 호출 가능한 명세가 아니다. S.ASK의 질문 구성/전달 등은 후속 원자 계약에서 더 분리할 부분으로 남긴다.
- 기획안 F01~F29/E01~E05, V0.4 243개 동작 및 330개 후보의 전체 의미 계약 재작성은 후속 단계. 본 작업은 객체 정의 방식과 핵심 동작 계약을 바로잡기 위한 기준안이며 최종 완결성 주장 아님.

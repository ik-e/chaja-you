## 검토 요청

- SVO 문장이 실제 사용자 의도를 표현하는지, 다른 행동이 섞이지 않았는지.
- 기획안의 P01(반복 준비), P02(반복 실행), P03(반복 확인·대응)에 기여하는지 또는 필요한 안전·이용 지원인지.
- 직접 입력해야 하는 값인지, 자동 추출·변환·재사용 가능한지, 열람만으로 충분한지.
- 팀원 조사에 있으나 제품 범위에 근거가 부족한 행의 포함·보류·제외 판단.
- 행동 누락, 중복 및 잘못된 대응을 ID로 기록. 검토 후 원자화·관계 연결·그룹화 및 새 DB 설계 진행.

## 한계 및 열린 문제

- 기획안 V1.2는 저장소상 팀원 검토안이나 이번 원장의 기준으로 사용하라는 R01 지시를 적용. 이 작업이 기획 승인 또는 실제 구현 승인이라는 의미는 아님.
- 팀원 조사 및 실제 이용 경험이 근거. 기존 V2.3/V3.1, 화면·상태·업무·DB는 누락 탐색 참고; 기존 구조에 맞추지 않음.
- 행동은 사용자 목표/화면/정상·예외 흐름으로 아직 묶지 않음. 순번은 ID일 뿐 순서 아님. 필드별 입력 후보와 일반 입력 후보 간 중복 가능성을 보존; 후속 정규화 필요.
- 기획 관련은 직접 조작이 반드시 필요하다는 뜻 아님. 자동 입력·변환·표시·단일 조작 가능성을 후속 검토. 열람은 별도 확인 버튼이 아님.
- 공식 직접 절차는 찾아you 기능의 대행 대상이 아니며 외부 접근·실제 등록은 검증하지 않음. 팀원 조사상의 필수·선택 및 공개 표시는 서버 검증과 구분.
- 팀원 원본 248개 전수 초기 대응은 구조 검사 완료; 의미 등가성 및 완전성의 전수 검증 아님.
- R02 실제 필수·선택 배열 86개(행동 대응 85개, 확인일 메타데이터 후보 1개)와 검토 요약 96개 간 차이 10개는 미해결. 임의 보완 금지.
- R02/R04/R05 상세 원본 필드 250개를 별도 대조. 규칙 기반 초기 대응은 의미 검토 전이며 다의/복합 항목이 남음. 통합 참고 주장 374개 및 팀 플랫폼 업무 126개, 기존 행동 155개·상태·오류·추가 팀원 텍스트는 evidence.json에 보존; 개별 행동 매핑 전수 확인은 후속 작업.
- 기획과 팀 제안이 충돌하거나 필요성이 불명확한 항목(장기 모니터링·관리자 확인·최초 모집 일정·대표 서비스·외부 임시저장·추가 옵션 등)은 확정하지 않음.
- 개별 행동 오류·전이·선후 및 실제 필수 조작 수는 다음 단계. 사용자 행동 후보 누락이 없다고 최종 선언하지 않음.

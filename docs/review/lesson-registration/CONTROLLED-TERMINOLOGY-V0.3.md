# 찾아you 통제 용어 기준 V0.3

> 기획안 V1.2와 팀 조사 근거를 토대로 의미를 통제하는 용어 기준안. 실제 플랫폼 기능 실재, 대행 허용, 제품 제공 범위, 구현 검증, 효과 발생을 새로 확정하지 않는다. 원본 사용자 행동과 기존 기획안은 변경하지 않는다. 용어 정비 결과는 후속 행동 정규화의 기준이며 DB/API/UI 구조를 정하지 않는다.

[기계 판독 정본](../../artifacts/planning/lesson-registration-20261126/integrated/terminology-v0.3/terminology.json) · [이전 V0.2 기준](SERVICE-INTERACTION-FOUNDATION-V0.2.md)

## 1. 문장 작성 규칙

- 명세는 주체(강사/서비스/외부 플랫폼), 정확한 대상 및 범위, 동작, 결과 판정 기준을 포함한다.
- 같은 단어라도 내부/외부, 실행/조회, 사용자 판단/서비스 증거 검증, 상태/효과, 요청/수락/실행 시도를 구분한다.
- 용어의 존재가 기능 채택을 의미하지 않는다. 불명확한 현실은 미확인 또는 별도 검토로 기록한다.
- 단독 '지원 가능', '등록 완료', '성공', '관리', '연동', '갱신', '확인'으로 설계 결정을 표현하지 않는다.

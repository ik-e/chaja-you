# 프로젝트 현황 라우트

이 폴더는 프로젝트 상태를 다시 복사해 적는 곳이 아니라, 현재 상황의 기준 자료로 안내하는 라우터입니다.

## 현재 프로젝트 진행 상황

- 일정·진척·산출물: 팀이 별도로 접근 권한을 받은 최신 대시보드를 기준으로 확인합니다. 대시보드 URL이나 사본은 이 공개 저장소에 기록하지 않습니다.
- 교육 과정 참고 가이드: [guidelines/README](../guidelines/README.md)

## 팀원별 현재 상황

- 개인별 최신 상태는 `members/Rxx/daily/YYYY-MM-DD.md`에서 확인합니다.
- 전체 팀원 경로와 일일 상태 형식은 [members/README](../members/README.md) 및 [일일 상태 템플릿](../members/templates/일일_상태_템플릿.md)을 참고합니다.
- 작업과 직접 관련된 팀원의 기록만 확인합니다. 필요한 기록이 없거나 오래되었으면 상태를 추정하지 말고 미기록·확인 필요로 표시합니다.
- 오늘 준비한 내일 작업안: [2026-11-11 리서치·기획·WBS 계획](2026-11-11_리서치_기획_WBS_계획.md)

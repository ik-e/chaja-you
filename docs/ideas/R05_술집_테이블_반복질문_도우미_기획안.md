# 술집 테이블 반복 질문 도우미 — 기획안

> 작성: R05 · 2026-11-20 · 원안: R02 "AI 술집 주문 도우미"

**한 줄 소개:** 바쁜 술집에서 손님이 테이블에서 묻는 반복 질문(화장실, 라스트오더, 안주 언제 나와요 등)에 바로 답하고, 답할 수 없는 질문만 직원에게 넘기는 테이블오더 도우미.

---

## 1. 타깃

- **쓰는 사람:** 요리주점·이자카야·포차에서 테이블오더로 주문하는 손님 (호프·치킨집은 제외)
- **혜택 받는 사람:** 저녁 피크 시간에 홀을 1~2명이 맡는 술집의 직원과 점주

**왜 술집인가**
- 테이블오더 수요는 매장에 머무르며 식사하는 동네 식당이나 **주점**을 중심으로 늘고 있다 (한국투데이). 도우미가 들어갈 기기가 이미 있다.
- 음식점업 인력 부족률은 3.9%로 전 산업(2.4%)보다 높고, 1~2인 운영 매장이 늘고 있다 (데일리안).

---

## 2. 페인포인트

**홀 직원·점주**
- 서빙·계산 중에 "화장실 어디예요?", "안주 언제 나와요?" 같은 질문을 반복해서 받아 일이 끊긴다.
- 여러 테이블이 동시에 부르면 주문·요청을 놓치기 쉽다.

**손님**
- 시끄럽고 바쁜 매장에서는 직원을 부르기 어렵고, 불러도 기다려야 한다.
- 안내문이 있어도 찾아 읽기보다 직원에게 묻는 게 편하다.

> **근거 상태:** 인력 부족과 테이블오더 확산은 출처가 있다. 하지만 **반복 질문이 얼마나 자주 나오는지는 공개 데이터가 없는 가설**이다. 가장 먼저 확인한다 (6절).

---

## 3. 문제 정의

> **테이블에서 바로 답할 수 있는 질문인데도 직원이 직접 와서 답해야 한다.**

기존 테이블오더의 직원 호출 버튼은 물·수저 같은 **물건 요청**용이다. "화장실 어디예요?" 같은 **정보 질문**은 호출을 눌러도 결국 직원이 테이블까지 와서 말로 답해야 한다.

질문으로 바꾸면: **"어떻게 하면 손님이 직원을 기다리지 않고, 직원은 일을 멈추지 않고 반복 질문을 해결할 수 있을까?"**

---

## 4. 핵심 피처: 반복 질문 답변

**① 바로 답하는 질문** (술집에서 자주 나올 것으로 보는 질문, 인터뷰로 확인 예정)

| 묶음 | 질문 예시 | 답의 출처 |
|---|---|---|
| 매장 정보 | 화장실 어디예요? / 와이파이 비번? | 점주가 처음에 한 번 입력 |
| 운영 정보 | 라스트오더 몇 시예요? / 몇 시까지 해요? | 점주 입력 |
| 계산 | 더치페이 돼요? / 계산은 어떻게 해요? | 점주 입력 |
| 포장 | 남은 안주 포장 돼요? | 점주 입력 |
| 주문·대기 | 안주 언제 나와요? / 주문 들어갔어요? | 주문 시각 + 메뉴별 평균 조리 시간 |

**② 답하는 방식**
- **입력된 정보로만 답한다.** 모르는 질문은 지어내지 않는다.
- **대기 시간은 범위로** 안내한다 ("보통 15~20분 걸려요. 지금 12분 지났어요"). 범위를 넘기면 손님에게 사과하고 **직원에게 바로 알린다.**
- 라스트오더는 손님이 **물었을 때만** 답한다.

**③ 직원에게 넘기는 질문**
- 입력되지 않은 질문
- 안주의 재료·알레르기 질문
- 안내한 대기 시간을 넘긴 경우
- 실제 포장 요청, 결제 문제

**④ 입력 방식**
- 술집은 시끄러워서 **자주 묻는 질문 버튼(터치)이 기본**이고, 음성은 선택이다.
- 음성은 버튼을 누를 때만 듣고, 인식한 말을 글자로 보여 준다. 녹음은 저장하지 않는다.

**지키는 원칙:** 술을 권하지 않는다. 미성년자 확인은 직원이 한다.

---

## 5. 첫 MVP

- 가상 술집 한 곳의 **테이블 화면 + 직원 화면**을 웹으로 만든다.
- 흐름: 손님이 질문 버튼을 누르거나 말한다 → 바로 답한다 → 답할 수 없으면 직원 화면에 알림이 뜬다.
- 주문 시각은 자체 데이터로 대신한다. 결제·POS 연동·실제 기기는 제외한다.
- 실서비스는 독립 앱보다 **기존 테이블오더에 들어가는 기능**이 현실적이다. 주문 시각 같은 데이터가 테이블오더 회사 시스템에 있기 때문이다 (토스플레이스).

**기존 서비스와의 차이:** 기존 직원 호출은 물건 요청을 받고, 기존 테이블오더 AI(티오더AI)는 점주의 매장 운영을 돕는다 (벤처스퀘어). 손님의 정보 질문에 바로 답하는 기능은 이번 조사에서 찾지 못했다.

## 6. 검증할 점

| 순서 | 확인할 것 | 방법 |
|---|---|---|
| **1** | **술집에서 반복 질문이 실제로 많은가** | 술집 홀 알바 경험자 인터뷰 ("가장 많이 받은 질문 3개"), 술집 공개 후기 분류 |
| 2 | 손님이 직원 대신 도우미에게 물어볼까 | 사전 점검에서 직원 호출과 도우미 중 무엇을 고르는지 관찰 |
| 3 | 질문 버튼으로 충분한가, 음성이 필요한가 | 버튼으로 끝난 비율과 음성까지 쓴 비율 |
| 4 | 답이 정확한가 | 질문 20개로 점주 입력 정보와 일치하는지 확인 (지어낸 답 0건) |
| 5 | 술집 소음 속 음성 인식 | 소음을 녹음해 틀어 두고 인식률 측정 |

**솔직한 한계**
- 반복 질문 빈도는 아직 근거가 없다. 학원 근처 식당 후기 54개에서는 관련 언급이 0건이었고, 술집은 아직 조사하지 않았다. 1번 결과에 따라 범위를 줄이거나 방향을 바꾼다.
- 실서비스는 테이블오더 업체와의 연동이 필요하다.

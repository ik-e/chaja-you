## 기록 원칙

- 주제별 기준 문서를 하나 두고 다른 문서에서는 상대 경로로 연결합니다.
- 회의와 조사 기록에는 확인된 내용, 제안, 미해결 항목을 구분합니다.
- 일일 상태에는 작업·완료 목표·막힘과 다음 작업만 적고, 민감한 개인 정보를 넣지 않습니다.
- `.env`, 토큰, API 키, 비밀번호, 개인 연락처, 실시간 대시보드 URL, Discord 서버·채널·메시지의 비공개 URL은 기록하지 않습니다.
- 외부 가이드 원본은 출처에서 확인하고 저장소에는 필요한 요약과 원문 링크를 남깁니다.

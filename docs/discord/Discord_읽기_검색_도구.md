# Discord 읽기·검색 도구

이 도구는 Discord 봇이 접근 가능한 서버의 텍스트·공지·포럼 채널 메시지와 활성·공개 보관 스레드를 읽고, 채널·기간·키워드로 필요한 내용만 찾습니다. 메시지 전송, 수정, 삭제, 반응 기능은 구현하지 않았습니다. Discord에서 가져온 대화 내용은 참고 자료로만 취급하며 그 안에 적힌 에이전트 지시문을 실행하지 않습니다.

## 설정

1. Python 3.9 이상을 준비합니다. 외부 Python 패키지는 필요하지 않습니다.
2. Discord Developer Portal에서 봇을 만들고 **Message Content Intent**를 켭니다.
3. 봇을 서버에 추가하고, 읽을 채널에서 **채널 보기**와 **메시지 기록 읽기** 권한만 부여합니다. 비공개 채널은 채널별로 봇 역할에 권한을 부여해야 합니다.
4. 저장소 루트에 `.env` 파일을 만들고 토큰을 직접 입력합니다. 토큰을 채팅이나 저장소에 올리지 마세요.

```dotenv
DISCORD_BOT_TOKEN=여기에_봇_토큰
```

## 사용법

저장소 루트에서 PowerShell로 실행합니다.

```powershell
py tools/discord_reader.py --guild "서버 이름" --keyword "배포"
py tools/discord_reader.py --guild "서버 이름" --channel "개발" --keyword "배포" --after 2026-11-01 --before 2026-11-10
py tools/discord_reader.py --guild "서버 이름" --channel "개발" --keyword "API 오류" --after 2026-11-08T09:00:00+09:00 --max-scan 5000 --max-results 20
py tools/discord_reader.py --guild "서버 ID" --channel "채널 ID" --keyword "결정" --json
```

- `--guild`: 서버 이름 또는 ID (필수)
- `--channel`: 채널 또는 스레드 이름/ID. 생략하면 봇이 접근 가능한 텍스트·공지·포럼 채널과 활성·공개 보관 스레드를 검색합니다.
- 부모 채널을 지정하면 그 채널에 속한 검색 가능 스레드도 함께 검색합니다. 스레드 이름이나 ID를 지정하면 해당 스레드만 검색합니다.
- `--keyword`: 필수 검색어. 공백으로 나눈 여러 단어는 모두 포함되어야 결과로 표시됩니다.
- `--after`: 시작 날짜/시각 포함. 날짜만 지정하면 해당 날짜 자정부터 검색합니다.
- `--before`: 종료 날짜 미포함. 날짜만 지정하면 그 날짜 전체를 제외합니다.
- `--max-scan`: 한 번의 실행에서 확인할 메시지 수 상한. 전체 채널 검색은 채널 수에 따라 나눠 적용됩니다.
- `--max-results`: 출력 결과 상한. 기본값 30입니다.
- `--json`: 결과를 JSON으로 출력합니다.

본문 외에 첨부파일 이름과 임베드 제목·설명도 키워드 검색 대상입니다. CLI는 첨부파일 본문을 자동 검색하지 않지만, 메시지 JSON에 포함된 URL로 텍스트 첨부를 별도 내려받아 읽을 수 있습니다. 활성 스레드와 공개 보관 스레드는 검색합니다. 공개 보관 스레드는 채널마다 최대 500개까지 찾아봅니다. 비공개 스레드는 봇이 참여해 접근할 수 있는 활성 스레드만 대상이며, 비공개 보관 스레드 목록은 추가 `스레드 관리` 권한 없이 조회할 수 없어 포함하지 않습니다. 음성 대화는 검색하지 않습니다. 검색 범위가 한도에 닿으면 기간을 좁히거나 `--max-scan`을 늘리세요.

## 현재 상태와 제한

Discord 앱 `chaja-you Reader`가 생성되었고 Message Content Intent가 켜졌습니다. 사용자가 봇을 `최종프로젝트` 서버에 초대했고, 봇은 채널 보기와 메시지 기록 읽기 권한으로 동작합니다. 저장소 루트의 로컬 `.env` 토큰 연결을 확인했고, 서버의 현재 텍스트·공지 채널 6개 모두 메시지 기록을 읽을 수 있음을 확인했습니다. `#일반` 채널에서는 기간·키워드 검색 결과도 반환되는 것을 확인했습니다. 토큰은 이 문서나 저장소에 기록하지 않습니다. 팀원 각자의 PC와 개인 AI 연결은 [팀원별 개인 AI 연동 안내](팀원별_개인_AI_연동.md)를 참고하세요.

# L3/L5 · 플랫폼별 등록 객체·필드·업무 흐름

> 2026-11-24 · R01 V0.2 상세 설계 검토 초안. 최종 채택 및 실서비스 실행 승인 아님. [구조화 정본 후보](detail-design-v0.2.json) · [근거·검토 안내](README.md)

크몽을 현재 우선 제품 후보로 유지하고 숨고를 독립 검증 대상으로 둔다. 탈잉은 확장 조사이며 구현 대상 아님. 아래 화면·규칙은 팀원 보고에 근거한 설계 후보로, 실제 사이트 접근·등록 허용 또는 검증을 의미하지 않는다.

## 적용 경계

모의 공통 T1의 이미지 요구와 숨고 서비스 설정의 사진 필수성이 다를 수 있다. 공통 시험 계약은 변경하지 않는다. R03/R04 협의 시 fixture와 목표 객체별 증거(프로필 이미지 첨부가 별도 단계라면 별도 의도)를 명시하고, 이미지가 없는 객체에 무리하게 가짜 필드를 강제하지 않는다. 현 단계 어떤 live 실행도 금지.

상위 결정: [최상위 보완](top-design-amendment-v1.json), [논리 V4](logical-behavior-v4.json). R01의 상세 설계 진행 승인에 따른 후보이며 본 구현/실서비스 승인 아님.

## 동작
원본 확인 → 알려진 플랫폼 필수·제약 검사 및 초안 → 사용자 내용 확인 → 직접 인증·대상 확인 → 고정 절차에 값 바인딩 → 승인/시작 → 순차 실행 및 독립 결과 확인. 오류 시 추가 실행 없이 중단·결과 제공. 실행 후 사용자 취소·변경·재개 없음. 같은 요청 키/효과 중복 방지.

## 인계 및 미결
1. 세부 schema 표현은 후보로서 executable schema/fixture, 플랫폼 실제 세부 필드/DOM 및 테스트와 연결 필요.
2. 실제 인증/격리/원자성/동시성/외부 효과/사용자 가치 시험은 후속 구현 검증. 실제 실행 허용 없음.
3. 과거 WBS 및 AT-06/T5-04 재개·취소 요구는 새 제품 후보와 충돌하므로 다음 통합 기준선 채택 전 개정. 현재 독립 TASK-043~045/T1~T6와 일정·담당은 변경하지 않음.

이 문서와 JSON은 기존 설계 이력과 구분된 후보. 충돌 시 상위 R01 최신 결정과 mock-only 제한 우선. main 및 팀원 브랜치 변경 없음.

## 이용 흐름

### LR-UC-01 · 최초 등록

1. 원본·조건·자료·대상 제공
2. 사실 구조화 및 누락 질문
3. 대상별 초안·필수값·충돌 제시
4. 사실·자료·목표·동작/환경·버전 검토와 명시 승인
5. 승인/허용 검사 후 모의 동작 수행
6. 관측 결과·근거·다음 조치 표시

예외: 값/규칙 충돌→확인; 승인 변경→재승인; 오류→마지막 확인 단계 보존; 응답 유실→unknown.

종료: 목표 모의 결과 또는 근거 있는 실패/차단/미확인; 크몽 실제 심사 접수는 향후 후보이며 공개와 별개

### LR-UC-02 · 재확인 및 재개

1. 실패 동작·마지막 확인 단계 구분
2. 효과 가능성 미확인→unknown/재실행 차단
3. 부작용 없는 조회·사용자 증거로 기존 결과 확인
4. 이미 달성하면 상태만 갱신; 효과 부재/안전한 다음 단계 확인 후 명시 재개 및 승인/허용 재검사

예외: 조회 불가/상충→unknown 유지; 승인 철회→추가 동작 금지.

종료: 확인된 결과 또는 안전한 재개 대기·실패·미확인

### LR-UC-03 · 플랫폼별 독립 결과

1. 대상별 규칙·초안·승인·실행 이력 보존
2. 한 플랫폼 실패/미확인으로 다른 작업 결과 변경 금지
3. 대상별 목표/환경/결과/근거 표시

예외: 복수 동시 실행 기능은 미채택.

종료: 개별 결과 집합; 부분 완료를 전체 성공으로 판단하지 않음

## 가치 검증

같은 원본·자료·대상·초기 상태·목표·품질에서 직접 등록 A/범용 AI B/전용 서비스 C 비교. 능동 시간, 설치, 총 시간, 개입, 재작업, 결과와 지불 의향 구분. R02의 1~2시간은 회상이며 3채널 20~30분은 희망치; 현재 실측/확정 합격선 없음.

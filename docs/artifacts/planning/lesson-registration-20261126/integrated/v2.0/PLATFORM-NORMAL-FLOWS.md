# 사용자 스토리 V2.0 — 7개 플랫폼별 정상 흐름 (1차 검토안)

> TASK-058 · R01 · 2026-11-26 · 개별 업무 채택·실제 운영사 허용·완료 실증 전. [공통 정상 흐름](COMMON-NORMAL-FLOWS.md)의 N09~N21과 연결한다. V1.3 업무 원장 44개 업무는 전부 유지하여 지원 후보/보류/내부 안내/조건부를 구분한다. 최신 R02 R02-US-036은 별도 결정 후보로 추가하며 기존 업무의 묵시적 확대가 아니다. 모든 외부 접근 및 실행은 현행 mock-only. 아래 정상 실행 경로는 해당 업무별 정책·권한·조건이 검증되어 채택될 때의 목표 동작이며 실측 외부 UI 순서가 아니다.

## 1. 읽는 방법

각 플랫폼의 필드별 검토(N11 확장)와 업무별 구체 흐름을 순서대로 읽는다. 등록·수정은 선택 필드만 적용하되 입력안·대상·권한·외부 효과를 모두 확인한다. 각 단계는 사용자의 조작 또는 독립적인 서비스 처리와 결과를 나타낸다. 공통 단계는 생략한 기능이 아니라 재사용 참조다. 신규 등록은 N09→N10→해당 플랫폼 필드 검토→N12(읽기/인증 허용 및 기존 효과 확인)→N13→신규 실행→N17; 기존 수정은 N09→N12→N10→필드 검토→N13→수정 실행→N17. 외부 인증과 읽기 단계도 별도 허용을 요구한다. 미지원/불명확한 것은 정상적인 제한 안내 흐름에서 종료한다. 별도 오류 발생과 복구는 2차로 정의한다. 필드 확인 행동은 원본에 근거한 제품 검토 조작이며 해당 외부 플랫폼의 정확한 필수 여부·값·서버 검증을 보장하지 않는다.

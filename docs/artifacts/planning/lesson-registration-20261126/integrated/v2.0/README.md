# 사용자 스토리 V2.0 — 정상 흐름 검토 기준 및 추적

> TASK-058 · R01 · 2026-11-26 · 1차 정상 흐름 후보. 사용자 지시: 정상 흐름 전체 정의 우선, 멘토 참고 자료 수준의 행동, 오류는 다음 단계. 기존 V1.3을 보존하고 별도 버전으로 검토한다. 이 문서는 새 범위 승인이나 정본 교체가 아니다.

## 읽는 순서

1. [공통 정상 이용 흐름](COMMON-NORMAL-FLOWS.md) — 최초 이용부터 종료까지 N01~N24, 각 정상 선택 분기·조작·서비스 처리·결과.
2. [플랫폼별 정상 이용 흐름](PLATFORM-NORMAL-FLOWS.md) — 7개 플랫폼의 관리 객체, 항목별 검토, 기존 44개 업무별 시작/종료/제외/불확실성, 신규 재등록 결정 후보.
3. 이 문서의 추적표와 오류 이월 목록 — 누락 여부와 범위 결정 확인.

## 정상 흐름 승인 전 검토 사항

- 서비스 진입·계정·복구·개인정보 지원은 인증 방식/운영 정책과 별도 채택 판단이 필요하다. N07/N08은 신규 지원 기능 제안으로서 기본 승격 아님.
- 정상 선택과 실행 오류를 분리한다. 승인 거절/철회, 선택 해제, 사용자 보류/중단/재개는 정상 선택이다. 기존 V1.3의 중단/재개 후보를 보존했으며 최종 승인 전이다. 정책 허용·미확인 상태에서 외부 실행은 제공하지 않는다.
- 7개 플랫폼 설계 포함은 확정. 업무별 우선/후순위/보류/조건부는 V1.3 기준이며 14개 범위 결정 미승인 유지. PL06/07의 동일 내용 새 게시물 생성은 R02-US-036에 근거한 별도 미결정 후보로만 추가; 기존 글 갱신이나 자동 반복으로 승격하지 않는다. 최신 R02의 2일/3일 공지 상충 및 로그인 이후 미관찰을 보존한다.
- 구체적 UI 레이아웃·인증 기술·외부 DOM·API/DB 구현은 확정하지 않는다. 항목별 실제 외부 필수 조건과 데이터 전수 정규화는 남아 있다. 모든 플랫폼 업무의 독립 완료 실증 및 운영사 허용 미확인.
- 정상 흐름 확정 후 각 단계별 오류/예외 ID를 만들고 정상 단계 ID와 직접 연결한다. 14개 이월 행동뿐 아니라 모든 단계의 독립 실패/미확인/충돌/권한/상태/부수 효과를 점검한다. 기존 693개 분기·대표 30개·정책 사례 16개는 비교 근거이며 복사로 종료하지 않는다. 발생 원인, 서비스 처리, 사용자 후속 행동, 복귀 또는 종료, 새 실행 허용 여부를 정의한다.
- 오류까지 검토하고 R01이 서비스 범위를 확정하기 전 DB/ERD/API 상세 진입은 보류한다.

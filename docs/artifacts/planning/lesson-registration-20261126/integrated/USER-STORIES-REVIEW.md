## 1. 서비스가 해결하는 문제와 가치

개인 음악 레슨 강사가 동일 레슨 정보를 여러 모집 채널마다 반복 작성·등록·수정하고 상태를 따로 확인하는 부담을 줄인다. 원본 저장·재사용 및 플랫폼별 정확한 업무 실행/결과 확인으로 반복 조작·재작업·분산 확인 시간을 줄인다. 실제 절감은 별도 검증한다.

## 2. 설계 범위와 구현 순서

**사용자 지시: MVP의 구현 순서와 무관하게 7개 플랫폼 모두 설계에 포함한다.** 크몽·탈잉·숨고·프람피·뮬·힙합플레이야·힙합LE의 데이터, 객체·관계, 업무/정상·오류·완료 규칙을 설계한다. 설계 포함과 실제 지원·대행 허용·구현 순위는 서로 다른 판단이다.

- 144개 행동: 기본 110개, 조건부 29개, 제외 5개. 개별 범위 승인 0개. 44개 플랫폼 업무도 개별 승인 0개. 7개 플랫폼 설계 포함은 확정.
- 단일 크몽 mock 기술 검증과 최소 2개 제품 MVP는 순차 구현·첫 가치 검증의 기존 추천. 첫 구현 대상·일정·업무 지원 여부가 7개 설계 범위를 축소하지 않는다.
- 모든 7개 플랫폼에 입력/반환 데이터, 계정/객체 식별, 상태, 오류·반복·완료 기준 및 권한/지원 불가/미확인 표현을 마련한다. 미확인 업무 실제 실행은 차단한다.
- 자동 모니터링·탈잉 최초 모집 일정·숨고 대표 서비스 설정은 별도 채택 전 미제공. 최초 owner 식별 관계 생성은 기본 추천. 독립 가입 화면·인증 기술은 미확정. 개인정보 권리 처리 유지.

## 10. 제외 경계

- **수강생 상담·유료 견적/제안서 발송** — 모집 정보 등록·관리와 별도 고객별 업무. 숨고/프람피 프로필 및 제공 조건과 구분.
- **수업 자체 일정 운영·출결·결제·정산·세금·수업 운영** — 수업 운영 및 금융 거래 범위 밖. 레슨 가격 정보/모집 오픈 조건과 구분.
- **동의 없는 외부 실행/신규 재등록·삭제, 보안 절차 우회** — 사용자·운영사 승인과 정확한 대상·효과 확인을 충족하지 않으면 금지. 기존 mock-only 유지.
- **기본 업무 완료 후 인증 유지** — 기본 세션은 완료·실패·철회·만료 후 폐기. 별도 조건부 모니터링만 후보.
- **후기·영상 콘텐츠 별도 제작 및 마케팅·유료 광고 운영, 수강생·매출 증가 보장** — 초기 문제 정의를 넘어서는 업무. 기존 원본 사진·영상/소개글 활용과 구분.
- **외부 가입·전문가 인증·약관 동의·정산 계좌 설정의 대행, 민감 증빙의 기본 수집/보관** — 공식 플랫폼 사용자가 직접 수행. 일반 직접 로그인 지원과 구분.
- **외부 게시물 삭제, 강제 외부 심사 취소, 원복, 외부 임시저장/조회, 독립 계정 삭제 UI·별도 가입 화면 강제·workspace 선택** — 독립 효과·권한 및 가치 불명 또는 기본 문제 범위 밖. 개인정보 요청 처리 의무 제외 아님.

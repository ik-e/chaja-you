### 기본 서비스의 정상 흐름

1. 강사는 서비스를 이용하고, 원본을 입력하거나 저장된 원본을 선택한다.
2. 서비스는 원본을 구조화하고 보존한다. 강사는 필요 정보를 정정/보완한다.
3. 강사는 지원 업무·제약을 확인하고 플랫폼과 업무 종류를 선택한다.
4. 서비스는 플랫폼별 입력안을 변환·검증한다. 실제 제공 가능한 대안을 강사가 선택한다.
5. 강사는 필요한 공식 로그인/추가 인증을 직접 수행한다. 서비스는 계정·권한·정확한 대상·기존 등록 여부를 확인한다.
6. 강사는 최종 정보와 실행 범위를 검토하고 승인한다. 서비스는 최신 조건과 양 승인을 대조한다.
7. 서비스는 허용된 신규/추가 등록·기존 수정·갱신을 수행하고 독립 근거로 결과를 확인한다.
8. 강사는 대상별 결과·증빙·이력·마지막 관측 상태를 확인한다. 필요 시 상태 조회나 후속 대응을 선택한다.
9. 서비스는 완료·실패·철회·만료 시 업무용 접근 차단 및 세션 폐기를 수행한다.

기존 수정에는 현재 게시값 비교와 변경 범위 선택이 추가된다. 직접 등록물의 관리 연결은 내부 관계이며 외부 게시 변경이 아니다. 반려 보완 후 재심사는 허용된 새 업무로 취급한다. 화면 수나 버튼 수를 확정하지 않는다.

- **외부 가입·전문가 인증·약관 동의·정산 계좌 설정의 대행, 민감 증빙의 기본 수집/보관** — 공식 플랫폼 사용자가 직접 수행. 일반 직접 로그인 지원과 구분.

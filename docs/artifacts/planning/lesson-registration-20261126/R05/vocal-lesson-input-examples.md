| 화면 항목 | 입력 초안 |
| --- | --- |
| 제목 | 신대방삼거리 1:1 대면 보컬 레슨 |

| 서비스 설명 | 신대방삼거리역 근처에서 진행하는 1:1 대면 보컬 레슨입니다. 1회 2시간씩 총 6회 진행하며, 스케일과 화음 연습을 시작으로 저음과 고음까지 단계적으로 다룹니다. 수업 일정은 강사와 협의해 정합니다. 연습하고 싶은 곡이나 어려운 구간이 있다면 수업 전에 알려주세요. |

| 의뢰인 준비사항 | 연습하고 싶은 곡이나 평소 부르기 어려운 구간이 있다면 미리 정리해 주세요. 필요한 자료와 장비는 강사 확인 후 안내합니다. |

| 메인 이미지 | 사용이 승인된 사진 확보 후 배치. 보컬 레슨 화면에서 필수 1~4장, 652×488px, PNG·JPG 안내 확인 |

기존 보컬 레슨 편집 화면에서 패키지 사용 시 기본 금액, 회당 시간, 레슨 횟수, 작업 기간, 수정 횟수의 필수 표시를 확인했다. 작업 기간과 수정 횟수는 강사 답변이 필요하다. 6회만 판매할 때 필요한 가격 단계, 패키지 끄기 후의 입력 구성, 기본 금액과 구매자 결제액의 관계는 화면 조사만으로 확인되지 않았다.

## 탈잉

| 화면 항목 | 입력 초안 |
| --- | --- |
| 클래스명·운영 방식 | 스케일부터 고음까지 단계별 1:1 보컬 레슨 / 오프라인 |
| 카테고리·클래스 대상 | 보컬 레슨에 해당하는 항목 선택 후보 / 발성 기초를 점검하거나 어려운 음역을 연습하고 싶은 수강생 |
| 클래스 요약·상세 소개 | 1회 2시간씩 총 6회 진행하는 대면 보컬 클래스입니다. 신대방삼거리역 근처에서 스케일과 화음을 익히고, 저음부터 고음까지 차례로 연습합니다. |
| 회차·참여 인원 | 총 6회 / 1명 |
| 수강료 | 시간당 12,500원 × 회당 2시간 × 6회 = 화면 기준 최종 수강료 150,000원 |
| 썸네일·일정·장소 | 썸네일은 강사 승인 이미지 필요. 일정과 장소는 협의 내용과 운영 정보를 강사에게 확인 |

### 회차별 소개 초안

1. 현재 발성과 음역을 살펴보고 편한 음역에서 스케일을 연습합니다.
2. 스케일을 반복하며 음정과 발성의 안정감을 점검합니다.
3. 기준 음을 듣고 간단한 화음을 맞춰 봅니다.
4. 저음 구간에서 소리가 흐려지거나 흔들리는 부분을 연습합니다.
5. 고음 구간을 나눠 연습하고 어려운 부분을 점검합니다.
6. 연습곡에 배운 내용을 적용하고 이후 연습할 부분을 정리합니다.

시간당 가격·회당 시간·횟수로 최종 수강료가 계산되는 화면을 확인했다. 화면에는 심사 후 회차 변경이 불가능하다는 안내가 있어 6회 구성은 강사에게 먼저 확인해야 한다. 일정·장소 탭은 클래스 오픈 상태에서 사용할 수 있다는 안내를 확인했으며, 실제 오픈 후의 일정 등록 및 장소 노출은 미확인이다.

| 약관동의 | 실제 게시 담당자가 게시 전 내용을 확인할 항목 |

개인레슨 작성 화면에서 구분·제목·약관동의의 필수 표시와 수강료의 쉼표 없는 원 단위 입력 안내를 확인했다. 수강료 입력란의 회당·총액 기준과 저장 후 노출 방식은 미확인이다. 본문에 총액 기준을 명시하고 별도 수강료 입력값은 플랫폼 기준이 확인될 때 확정한다.

## 강사에게 다시 물어볼 항목

1. **수업 대상과 구성** — 어떤 수강생을 받으시나요? 1회 120분씩 6회가 맞나요? 회차별 구성과 연습곡은 어떻게 진행하시나요?
2. **가격과 판매 방식** — 15만 원은 수강생이 내는 6회 총액인가요? 6회만 판매하나요? 2회·4회도 판매한다면 각 가격은 얼마인가요?
3. **장소와 일정** — 실제 수업 장소와 가능한 요일·시간은 어떻게 되나요? 주소는 어느 범위까지 공개해도 되나요?
4. **준비물과 이미지** — 수강생이 준비할 것은 무엇이고 강의실이나 장비는 제공되나요? 썸네일로 사용할 수 있는 사진이 있나요?
5. **크몽 운영 조건** — 작업 기간과 수정 횟수에는 어떤 기간과 변경 조건을 안내할 수 있나요?

## 확인 범위와 근거

- 공통 원본만으로 소개·절차·회차별 초안과 가격 변환 후보를 작성할 수 있다. 상세주소, 실제 운영 일정, 이미지, 플랫폼별 필수 운영값은 추가 확인이 필요하다.
- 필수 표시와 안내 문구는 기존 화면에서 관찰한 내용이다. 이 예시를 실제 양식에 입력하거나 저장·심사·게시하지 않았다. 저장 후 반영, 최종 공개 표시, 대행 허용 여부는 미확인이다.

### 회차별 소개 초안

1. 현재 발성과 음역을 살펴보고 편한 음역에서 스케일을 연습합니다.
2. 스케일을 반복하며 음정과 발성의 안정감을 점검합니다.
3. 기준 음을 듣고 간단한 화음을 맞춰 봅니다.
4. 저음 구간에서 소리가 흐려지거나 흔들리는 부분을 연습합니다.
5. 고음 구간을 나눠 연습하고 어려운 부분을 점검합니다.
6. 연습곡에 배운 내용을 적용하고 이후 연습할 부분을 정리합니다.

기존 오프라인 1:1 편집 화면에서 시간당 12,500원 × 회당 2시간 × 6회 = 150,000원으로 표시됐다. 심사 후 회차 변경이 불가능하다는 안내가 있어 120분·6회·15만 원과 회차별 구성을 강사에게 먼저 확인한다. 실제 제공 조건이 플랫폼 제약과 충돌하면 강사가 제공 가능한 대안을 선택한 뒤 시간·가격·회차를 다시 검토한다. 선택 가능한 대안이 없으면 등록을 보류한다. 일정·장소 탭에는 클래스 오픈 상태에서 사용할 수 있다는 안내가 있었으며, 모집 오픈과 일정 등록의 실제 선후 관계 및 장소 노출은 미확인이다. ## 신규·추가 등록 모의 분기

### 1. 기존 등록 확인 실패

예를 들어 크몽에서 같은 보컬 레슨이 이미 등록됐는지 조회하던 중 목록 조회가 실패했다고 가정한다.

| 기존 등록 확인 결과 | 다음 처리 |
| --- | --- |
| 있음 | 기존 후보와 근거를 표시한다. 수정이 필요하면 강사가 해당 게시물을 선택하고 수정 흐름에서 별도 승인을 한다. |
| 없음 확인 | 확인된 계정과 조회 범위를 근거로 남기고, 나머지 선행 조건이 충족되면 최종 입력안과 실행 범위 검토로 넘어간다. |
| 확인 못 함 | 해당 플랫폼의 신규 등록을 보류한다. 조회 실패나 후보 불명확 사유를 표시하고, 다시 조회하거나 해당 플랫폼을 건너뛸 수 있게 한다. |

`확인 못 함`을 0건으로 기록하지 않는다. 다른 플랫폼은 자체 선행 조건을 충족한 경우에만 계속한다. [TASK-058 통합 스토리 IS-106](https://github.com/ik-e/chaja-you/blob/6cce5d6/docs/artifacts/planning/lesson-registration-20261126/integrated/user-stories.json)

### 2. 제출 응답 유실 후 미확인으로 종료

모의 환경에서 뮬의 입력·약관·실행 선행 조건이 충족됐다고 가정한다. 글 등록을 한 번 실행했으나 응답이 유실됐고, 기존 반영 여부를 독립적으로 다시 조회해도 확인하지 못한 경우다.

| 플랫폼 | 모의 결과 | 화면에 표시할 내용과 후속 처리 |
| --- | --- | --- |
| 크몽 | 심사 접수 확인 | 접수 상태와 근거를 표시한다. 공개 여부는 별도로 남기고 제출을 반복하지 않는다. |
| 탈잉 | 준비 보류 | 강사의 회차별 구성 확인이 남았음을 표시한다. 실행 이력은 미실행으로 남긴다. |
| 뮬 | 외부 반영 미확인 | 응답 유실과 마지막 재조회 결과를 표시한다. 다시 조회하거나 미확인 상태로 종료할 수 있다. 미확인으로 종료하면 새 제출 없이 해당 상태와 근거를 저장한다. |

작업 종료 뒤에도 뮬의 상태는 미확인으로 남는다. 새 제출 전에 기존 외부 반영 여부를 먼저 확인한다. 크몽의 접수 결과와 탈잉의 미실행 상태도 각각 보존한다. [R04 흐름 보고서 §7 L6 및 §9.1 UF-01](https://github.com/ik-e/chaja-you/blob/605479a/docs/members/R04/workspace/2026-11-25_R04_마이AI오피스_서비스절차_사용자흐름_설계보고서.md)

# 차자유 유저스토리

개인 음악 레슨 강사는 레슨 정보를 한 번 작성해 여러 플랫폼에 재사용하고, 등록 결과와 모집 상태를 한곳에서 확인하고 싶다.

- **처음 등록하는 강사** → 본인 확인 → 레슨 작성·저장 → 플랫폼별 작업 준비 → 최종 승인 → 결과 확인
- **저장한 레슨이 있는 강사** → 내 레슨 관리 → 원본 또는 등록물 선택 → 추가 등록·수정·공고 갱신·상태 조회

화면 구성은 설계 검토안이다. 외부 플랫폼 작업은 현재 모의 환경을 기준으로 한다.

## 1. 본인 확인 화면

- **사용자 행동** · 처음 이용하는 강사는 본인 확인과 필요한 동의를 마친다. 다시 접속한 강사는 본인 확인 후 저장한 레슨과 이전 작업을 연다.
  - **오류 상황** · 인증에 실패하거나, 최초 계정이 생성됐는지 확인되지 않거나, 이전과 다른 계정으로 접속했다.
  - **예외 처리** · 인증 실패나 만료 시 다시 인증하도록 안내한다. 최초 계정 생성 결과가 불분명하면 기존 요청을 먼저 확인해 중복 생성을 막는다. 같은 계정으로 돌아오면 저장된 레슨과 작업을 보여 주고, 열람 권한이 없는 레슨은 표시하지 않는다.

## 2. 내 레슨 관리 화면

- **사용자 행동** · 강사는 저장한 레슨, 연결한 외부 등록물, 최근 작업 결과를 확인한다. 원하는 레슨이나 등록물을 골라 후속 작업을 시작한다.
  - **오류 상황** · 저장한 레슨이 없거나 목록을 불러오지 못한다.
  - **예외 처리** · 저장한 레슨이 없으면 새 레슨 작성으로 안내한다. 불러오기에 실패하면 다시 불러올 수 있게 한다. 외부 등록물에는 마지막 상태 확인 시각을 표시한다.

- **사용자 행동** · 강사는 저장한 원본을 삭제하거나 외부 등록물의 관리 연결을 해제한다.
  - **오류 상황** · 진행 중이거나 결과가 확인되지 않은 작업이 연결돼 있거나, 보존해야 할 기록이 있다.
  - **예외 처리** · 영향을 받는 작업과 보존 범위를 먼저 보여 준다. 결과 확인이 필요하면 처리를 보류한다. 원본 삭제와 연결 해제는 차자유 내부에만 적용된다.

## 3. 레슨 작성·수정 화면

- **사용자 행동** · 강사는 레슨 소개, 가격, 수업 시간, 지역 등을 입력하고 사진이나 자료를 첨부한다.
  - **오류 상황** · 지원하지 않는 파일이거나 자료의 사용 권한을 확인할 수 없다.
  - **예외 처리** · 문제가 있는 파일과 이유를 표시한다. 나머지 입력은 보존하고 해당 파일만 교체하거나 제거할 수 있게 한다.

- **사용자 행동** · 강사는 서비스가 정리한 레슨 정보를 검토하고 잘못된 내용을 수정한다.
  - **오류 상황** · 가격·시간·회차가 빠져 있거나 자료마다 값이 다르다.
  - **예외 처리** · 확인이 필요한 항목과 근거가 된 자료를 보여 준다. 강사가 직접 확인한 값을 저장에 사용한다.

- **사용자 행동** · 강사는 원본을 저장하거나 저장 후 등록 준비로 이동한다.
  - **오류 상황** · 다른 곳에서 같은 원본을 수정했거나 저장 응답이 끊겼다.
  - **예외 처리** · 동시 수정이 감지되면 최신 저장본과 현재 편집 내용을 비교할 수 있게 한다. 응답이 끊기면 입력을 보존하고 같은 저장 요청의 결과를 확인한다. 실패가 확인되면 다시 저장할 수 있다.

- **사용자 행동** · 강사는 작성을 마치기 전에 목록으로 돌아가거나 다른 레슨을 연다.
  - **오류 상황** · 저장하지 않은 변경 내용이 남아 있다.
  - **예외 처리** · 계속 편집, 저장 후 이동, 변경 내용 버리기 중에서 선택하게 한다. 저장 요청의 결과를 확인 중이었다면 입력을 보존하고, 돌아왔을 때 같은 요청을 이어서 확인한다.

## 4. 작업 준비·최종 승인 화면

- **사용자 행동** · 강사는 작업할 플랫폼을 고르고 신규·추가 등록, 기존 정보 수정, 공고 갱신 중 필요한 업무를 선택한다.
  - **오류 상황** · 플랫폼이 업무를 지원하지 않거나 수행 권한이 불분명하다.
  - **예외 처리** · 제한 이유를 보여 주고 해당 대상만 보류하거나 제외할 수 있게 한다. 내부 작성이 가능한 업무는 작성안으로 안내한다. 다른 플랫폼은 각자의 조건에 따라 준비를 계속한다.

- **사용자 행동** · 강사는 플랫폼별 입력안을 검토하고 필요한 항목을 보완한다.
  - **오류 상황** · 가격·시간·회차·이미지 규격이 맞지 않거나, 수정 전 입력안이 늦게 도착했다.
  - **예외 처리** · 문제가 있는 항목과 가능한 대안을 보여 준다. 가격이나 수업 시간을 바꾸려면 강사가 확인한다. 오래된 입력안은 적용하지 않고 영향을 받은 대상만 다시 준비한다.

- **사용자 행동** · 강사는 특정 플랫폼의 소개 문구를 바꾸거나 공통 레슨 정보를 수정한다.
  - **오류 상황** · 한 플랫폼에만 적용할 변경이 레슨 원본에도 반영될 수 있다. 반대로 원본 가격을 바꾸면 다른 플랫폼에서 준비 중인 입력안에도 영향이 생긴다.
  - **예외 처리** · 이번 플랫폼에만 적용할지, 원본도 수정할지 선택하게 한다. 원본을 수정하면 영향을 받는 미실행 작업을 다시 검토하게 한다. 이미 게시한 내용은 별도의 수정 작업으로 처리한다.

- **사용자 행동** · 강사는 수정할 등록물을 고르거나 직접 등록한 기존 글을 차자유에 연결한다.
  - **오류 상황** · 제목이 비슷한 등록물이 여러 개이거나, 이미 등록·연결됐는지 확인할 수 없다.
  - **예외 처리** · 계정과 등록물 정보를 보여 주고 정확한 대상을 고르게 한다. 이미 연결된 등록물은 상세 화면으로 안내한다. 기존 등록 여부가 불분명하면 신규 등록을 보류한다. 관리 연결만 요청했다면 차자유에 연결 정보만 저장한다.

- **사용자 행동** · 강사는 수정할 항목과 반영 범위를 확인한다.
  - **오류 상황** · 숨고의 소개처럼 여러 서비스에서 함께 쓰는 프로필 항목이 포함돼 있다.
  - **예외 처리** · 승인 전에 함께 바뀌는 서비스와 항목을 보여 준다. 영향 범위를 확인할 수 없으면 해당 변경을 보류한다.

- **사용자 행동** · 강사는 기존 모집 공고의 갱신을 요청한다.
  - **오류 상황** · 아직 갱신할 수 있는 시점이 아니거나, 횟수 제한·비용·갱신 방법이 불분명하다.
  - **예외 처리** · 확인된 제한과 다음 요청 가능 시점을 보여 준다. 조건을 확인할 수 없으면 보류한다. 갱신을 위해 결제하거나 기존 글을 삭제해 새로 올리는 동작은 차단한다.

- **사용자 행동** · 강사는 최종 입력 내용, 수정 전후 차이, 대상 계정, 실행 범위와 예상 결과를 확인하고 승인한다.
  - **오류 상황** · 승인 후 원본·계정·권한이 바뀌거나 강사가 승인을 철회했다.
  - **예외 처리** · 해당 대상의 추가 실행을 막고 현재 내용으로 다시 검토하게 한다. 이미 반영된 내용이 있으면 결과 화면에서 확인할 수 있게 한다.

- **사용자 행동** · 강사는 승인한 작업의 실행을 요청한다.
  - **오류 상황** · 실행 버튼을 여러 번 눌렀거나 응답이 끊겨 작업이 접수됐는지 알 수 없다.
  - **예외 처리** · 같은 요청의 접수 여부를 먼저 확인한다. 접수된 작업이 있으면 그 작업을 열고, 확인 중에는 같은 작업을 새로 만들지 않는다.

## 5. 외부 플랫폼 인증 화면

- **사용자 행동** · 강사는 필요한 경우 플랫폼 공식 화면에서 직접 로그인하고, 확인된 계정을 이번 작업에 사용할지 선택한다. 전문가 인증이나 약관 동의가 필요하면 공식 화면에서 직접 진행한다.
  - **오류 상황** · 인증이 만료·취소됐거나 다른 계정으로 로그인했다. 권한이 부족하거나 필요한 절차의 완료 여부를 확인할 수 없는 경우도 있다.
  - **예외 처리** · 준비한 입력안은 보존하고 해당 작업을 보류한다. 올바른 계정으로 다시 인증하거나 필요한 절차를 진행할 수 있도록 공식 경로를 안내한다. 비밀번호와 인증코드는 플랫폼 공식 화면에서 입력한다.

- **사용자 행동** · 강사는 외부 인증을 마치고 차자유의 작업 화면으로 돌아온다.
  - **오류 상황** · 외부 인증 중 차자유 로그인이 만료됐거나 작업 대상이 바뀌었다.
  - **예외 처리** · 필요한 경우 같은 차자유 계정으로 다시 로그인하게 한다. 현재 선택된 플랫폼 계정과 작업 대상을 확인한 뒤 이어갈 수 있게 한다. 이전 인증 결과만으로 작업을 자동 실행하지 않는다.

## 6. 업무 진행·결과 화면

- **사용자 행동** · 강사는 플랫폼별 작업 결과와 확인 근거를 본다.
  - **오류 상황** · 제출 응답이 끊겼거나 접수 이후 실제 반영 여부를 확인할 수 없다.
  - **예외 처리** · 확인된 접수·심사·공개·모집 가능 상태를 각각 표시한다. 실제 반영 여부가 불분명하면 **미확인**으로 표시하고 기존 결과부터 조회한다.

- **사용자 행동** · 강사는 여러 플랫폼 중 후속 조치가 필요한 대상을 고르거나, 한 등록물에서 완료되지 않은 단계를 확인한다.
  - **오류 상황** · 일부 플랫폼만 성공했거나, 상품은 만들어졌지만 사진 첨부나 심사 접수가 됐는지 알 수 없다.
  - **예외 처리** · 확인된 성공과 이미 생성된 등록물을 보존한다. 미확인 단계는 먼저 조회한다. 이전 요청이 끝났고 반영되지 않은 것으로 확인되면, 지원되는 남은 단계만 같은 등록물에서 다시 준비하고 승인받는다.

- **사용자 행동** · 강사는 진행 중인 작업의 상태를 확인한다.
  - **오류 상황** · 접근 권한이 철회되거나 플랫폼 변경으로 작업 결과를 확인할 수 없게 됐다.
  - **예외 처리** · 해당 대상의 남은 전송을 멈추고 **반영 확인**, **미전송**, **반영 미확인**을 각각 표시한다. 필수 결과를 확인할 경로가 없다는 사실을 실행 전에 알게 되면 작업을 보류한다.

- **사용자 행동** · 강사는 등록물의 최신 상태를 조회한다.
  - **오류 상황** · 새 조회에 실패하거나 새로 확인한 정보가 이전 기록과 서로 다르다.
  - **예외 처리** · 조회 실패 시 마지막 확인 상태와 시각을 유지하고 새 조회 실패를 따로 표시한다. 근거가 충돌하면 해당 등록물의 변경을 보류하고 어떤 정보가 다른지 보여 준다.

- **사용자 행동** · 강사는 심사 반려나 입력 실패의 원인을 확인하고 필요한 내용을 수정한다.
  - **오류 상황** · 반려 사유가 표시되지 않거나 재심사를 요청할 수 있는지 알 수 없다.
  - **예외 처리** · 확인된 사유를 보여 주고 알 수 없는 사유는 **미확인**으로 표시한다. 재심사를 지원하면 같은 등록물의 수정안을 준비하고 새 승인을 받는다.

- **사용자 행동** · 강사는 화면을 나갔다가 이전 작업을 다시 연다.
  - **오류 상황** · 화면을 나갈 때 작업이 진행 중이었거나 결과가 불분명했다.
  - **예외 처리** · 돌아오면 같은 작업과 현재 확인된 결과를 보여 준다. 화면 이탈이나 재접속만으로 작업을 취소하거나 재실행하지 않는다.

**부분 성공 예시**

- 크몽은 심사 접수가 확인됐다 → **심사 접수 확인**
- 탈잉은 제출 중 응답이 끊겼다 → **제출 미확인**, 기존 접수 여부 먼저 조회
- 숨고는 권한 문제로 실행 전에 멈췄다 → **미실행**, 권한 확인 후 숨고 작업만 다시 준비

## 7. 직접 작성안 화면

- **사용자 행동** · 강사는 외부 작업이 제한된 경우 제공 가능한 내부 작성안을 확인하고 직접 사용할지 결정한다.
  - **오류 상황** · 작성안에 필수 정보가 빠져 있거나 확인되지 않은 내용이 남아 있다.
  - **예외 처리** · 작업 준비 화면에서 필요한 항목만 보완하게 한다. 작성안을 제공한 경우에도 차자유의 외부 작업 상태는 **미수행**으로 표시한다.

## 8. 외부 계정 관리 화면

- **사용자 행동** · 강사는 외부 계정을 관리용으로 연결하거나 다시 인증한다.
  - **오류 상황** · 선택한 계정과 실제 로그인한 계정이 다르거나 인증이 만료됐다.
  - **예외 처리** · 올바른 계정을 직접 선택하거나 다시 인증하게 한다. 이번 작업에 계정을 사용하는 선택과 관리용으로 연결하는 선택을 따로 확인한다.

- **사용자 행동** · 강사는 외부 계정 연결을 해제하거나 접근 권한을 철회한다.
  - **오류 상황** · 새 접근은 차단됐지만 기존 작업용 로그인이 종료됐는지 확인할 수 없다.
  - **예외 처리** · 접근 차단을 유지한다. 계정 연결 해제 여부와 기존 작업용 로그인 종료 여부를 각각 표시한다.

## 9. 설정·개인정보 화면

- **사용자 행동** · 강사는 본인 데이터의 열람·삭제 등을 요청하거나 처리 상태를 확인한다.
  - **오류 상황** · 접수 여부가 불분명하거나 진행 중인 작업과 보존해야 할 기록이 관련돼 있다.
  - **예외 처리** · 접수 결과와 영향을 받는 범위를 확인하고, 현재 처리 상태와 추가로 필요한 조치를 보여 준다.

- **사용자 행동** · 강사는 차자유에서 로그아웃한다.
  - **오류 상황** · 외부 작업의 종료 여부나 기존 작업용 로그인 종료 여부가 확인되지 않았다.
  - **예외 처리** · 새 접근을 차단하고 기존 작업과 확인된 결과를 보존한다. 같은 계정으로 다시 접속하면 저장된 상태를 보여 준다.

## 플랫폼별 등록 대상과 결과 확인 기준

- **크몽** · 레슨 상품과 가격 옵션을 등록한다. 같은 계정에 상품과 승인 내용이 저장됐는지 확인하고, 심사 접수·심사 승인·판매 가능 상태를 각각 표시한다.
- **탈잉** · 오프라인 음악 레슨 클래스를 등록한다. 클래스 저장과 심사 상태를 확인하고, 일정·장소와 실제 신청 가능 여부를 따로 확인한다.
- **숨고** · 고수 프로필에 레슨 제공 서비스를 연결한다. 서비스와 승인한 설정이 반영됐는지 확인하고, 공개 프로필 노출과 요청 수신 가능 여부를 따로 확인한다.
- **프람피** · 전문가 프로필에 레슨 분야를 연결한다. 분야와 입력값이 저장됐는지 확인하고 공개 상태를 따로 표시한다.
- **뮬** · 개인레슨 게시판에 공고를 등록한다. 게시물과 게시 상태를 확인한다. 같은 글의 갱신은 방식·간격·횟수·비용·실제 반영 여부를 확인한 뒤 지원할 수 있는 후보다.
- **힙합플레이야** · 홍보 게시판에 레슨 글을 등록한다. 승인한 내용이 저장됐는지 확인하고 공개 목록 노출을 따로 확인한다.
- **힙합LE** · 레슨 장터에 글을 등록한다. 승인한 내용이 반영됐는지 확인하고 공개 목록과 상세 화면 노출을 따로 확인한다.

7개 플랫폼이 설계 범위에 포함된다. 실제 지원 여부는 플랫폼과 업무별로 확인한다. 자동 모니터링·알림, 탈잉 최초 모집 일정 등록, 숨고 대표 서비스 설정은 별도 채택 후 제공할 수 있다.

## 3. 가장 강한 대안과 잔여 문제를 구분

| 대안 | 이미 제공하는 것(확인 범위) | 이후에 남는지 실험할 것 |
|---|---|---|
| [경찰 ECRM](https://ecrm.police.go.kr/minwon/main) | 공식 신고/상담 안내와 준비·작성 과정 | 원문과 사건 요약 왕복 확인/반복 정정 부담 |
| 수기 표·메모·플랫폼 서비스 | 이용자 스스로 선택·정리 가능 | 누락/수정 관리에 들어가는 총수고 |
| **범용 LLM + 충분한 지시** | 사건 요약·표·누락 질문·수정 가능 | 원문 출처 연결, 사실/주장/미확인 구분, 정정 후 일관성이 남는 문제인지 |
| 무료 법률 상담 | 안내를 받을 수 있는 경로 | 실제 정리 단계의 수고가 감소하는지 |

**반대 가설을 반드시 작성:** "ECRM 안내 + 충분히 지시한 범용 LLM으로도 사용자 부담을 충분히 줄일 수 있다." 기존 대안에 없는 기능이 있다고 단정하지 않고 **같은 입력/예산**으로 비교한다.

## 5. 사용자 시나리오와 핵심 기능 2~3개

**예시 시연 (전부 가상 자료):** 대화에는 판매자가 '발송했다'고 썼지만 배송 확인 자료는 없다. 사용자가 송금일을 11월 10일로 말했으나 이체 기록에는 11월 11일로 표기됐다. 시스템은 **판매자의 주장**과 **확인된 기록**을 구별하고 날짜 충돌을 **미확인**으로 제시한다. 사용자가 날짜를 정정하면 관련 요약·질문·자료 참조를 함께 갱신한다. 임의로 진실을 확정하지 않는다.

**사용자 흐름:** 자유 입력/비식별 자료 → 경위 카드·원문 연결 → 누락/충돌 질문 → 사용자 정정 → 요약·증빙 목록·미확인 항목·상담 질문 검토/복사.

| 피처 | 직접 줄일 Pain | 관측 결과/수용 기준 |
|---|---|---|
| F1 사건 경위·자료 구조화 | 재입력·원문 재탐색 | 각 주요 내용이 출처 자료/입력 위치에 연결되며 임의 사실 추가 없음 |
| F2 누락·충돌·정정 일관성 | 재확인·사실 왜곡 | 충돌을 임의 해소하지 않고, 사용자 수정이 연결된 결과에 반영됨 |
| F3 결과 검토·용어 안내(선택) | 설명 준비·작성 중 막힘 | 이용자가 요약/자료/질문을 검토·복사할 수 있고 공식 신고를 대신하지 않음 |

## 6. 가장 작은 실험을 구체화

**E0: 문제 검증.** 실제 경험자 1~3명과 인터뷰(모집 가능 시). 서비스 소개 전에 최근 준비 과정, 썼던 도구, 실제 다시 확인·정정했던 순간, 불편이 없었던 반대 사례를 질문한다. 실제 사건 원문 제출을 요구하지 않는다.

**E1: 가상 사건 3~5개 비교(제안 규모).** A=ECRM 공개 안내로 수기 준비, B=동일 자료·충분한 지시를 제공한 범용 LLM, C=시제품. 원안의 실험 A **내용 구조화 품질**과 실험 B **자료 찾기부터 종료까지 총부담**을 분리한다.

| 시험 항목 | 데이터·지표 | 실패/축소 조건 |
|---|---|---|
| 사실 보존 | 기준 사건 대비 중요한 누락·왜곡·임의 사실 추가 | 새로 생긴 사실 왜곡이 있으면 시간 단축과 무관하게 실패 |
| 수정 부담 | 정정 횟수, 원문 왕복, 검토 시간, **전체 준비 시간** | 범용 LLM/수기가 동등하거나 우수하면 차별성 재검토 |
| 미확인 보존 | 알 수 없는 사실과 자료 충돌의 출력 상태 | 임의 확정/법적 판단 생성 시 기능 축소 |
| 사용자 문제 | 인터뷰에서 남는 실제 불편 여부 | 기존 안내로 이미 충분하면 타깃/문제 재정의 |

**기술 효과는 별도:** 단일 에이전트 vs 고정 역할 vs 동적 작업 비교는 동일 모델·자료·예산에서 기술적 이점만 검증하며 사용자 수요의 근거로 삼지 않는다.

## 7. 8주 MVP/도입·안전 경계

- **Must:** 텍스트 입력, 사건/원문 연결, 사실·상대 주장·미확인 분리, 정정/누락 검토, 사람 승인 후 복사, 가상 사례 정확도 검증.
- **제외:** 공식 신고 자동 접수, 범죄 성립/책임 확정, 법률 자문/대리, 민감 신원 자료 자동 수집, 법적 효과 보장.
- **자료/권한:** 가상·비식별 사례로 시작. 실제 사건 자료 취급·외부 모델 전송·저장/삭제·법률관계 문서 작성 경계는 별도 전문 검토 전 승인하지 않는다.
- **사용/도입:** 이용자·유입/신뢰 경로·비용 지불 주체/운영 책임은 [미확인, 검증 질문 작성].
- **WBS 연결:** [R03 8주 예비안](WBS-alternatives.md)에서 1~3일 작업과 단일 owner, 선행·결과물·수용 기준을 보완한다.

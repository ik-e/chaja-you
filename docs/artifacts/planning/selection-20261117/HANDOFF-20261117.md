## 3. 채점/교차 검토 절차

1. **G1~G3 먼저:** G1 실체, G2 적법·허용되는 조사/실험 경로, G3 8주 MVP·기존 대안 비교 가능성. G2에서 **무허가 자동 수집·보안절차 우회를 허용된 경로로 간주하지 않음**. 조건부·중단 위험·근거 부족 기록.
2. **A~F 등급 0~4의 정수로 입력:** A 사용자 페인 **25**, B 기존 대안 후 잔여 문제 **25**, C 피처 해결력 **15**, D 8주 가능성 **20**, E 근거·반증 **10**, F 사용·도입 **5**. `점수=배점×등급/4`. `null`은 0이 아니고, 부분 평가 총점으로 순위 확정하지 않는다.
3. **증거를 함께 기록:** 해당 항목마다 원본 버전, 확인된 사실/제안자 주장/추정, 가장 강한 반대 근거, 확인 못 한 점, 검증 실험 1개, 확신도를 기록. `score-template.json` 복사해 평가자·후보별 **별도 JSON** 작성.
4. **불일치 해결:** 같은 항목에서 **2등급 이상 차이** 나면 평균 전 같은 버전·근거를 대조. 큰 점수 차이도 평가 방식과 실험 제약을 따로 검토. 자가 평가는 참고자료일 뿐 4인 독립평가의 한 표가 아니다.
5. **결정 초안:** 2개 후보 추천 및 3개 보류 사유를 게이트/점수/최단 반증 실험으로 작성. 단순 고득점 자동 확정 금지. 18:00까지 팀 의견 수렴, 20:00 멘토 피드백 뒤 최종 제품 결정 별도.

### 눈에 띄는 불일치 — 반드시 확인

- **R04:** 본인 평가에서 85.1점, R01 AI 평가에서는 36.25점. 본인 평가가 공식 정수 등급 대신 **3.5 등급**을 사용한 점과 반올림 오차도 확인. 비용/필수 제출 요건/행정정보 공동이용/발급 대행/정부24 허용 경로/출력물 공식 인정이 **검증 우선**. v0.2의 연 1,500~2,000만 원은 실무자 의견 기반 **추산**으로, 원천 증빙과 실제 대상 건수 확인 전 실증 사실로 주장하지 않는다.
- **R05:** R04 보고서 평가 대상은 '가전 구매'이므로 **키오스크 평가에는 사용 불가**. 메뉴 설명/필터만 개선한 대조군과 같은 정보량 비교 필요.
- **R02:** 제출 주제가 TASK-017과 다름. R02의 가정 점수는 공식 채점의 누락값을 메우는 근거가 아니다.
- **R01:** 실제 감독관의 잔여 손실 규모·기관 승인 미확인. 공식 지침+비AI 체크리스트 대조가 필수.
- **R03:** 경험자 부담과 ECRM·충분히 지시한 범용 LLM 이후 잔여 문제 미검증. 사실 왜곡과 총작업량을 함께 비교.

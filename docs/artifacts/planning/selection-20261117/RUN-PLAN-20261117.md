## 두 후보에서 반드시 확인할 핵심 질문

**R03 중고거래 상담·신고 준비**
- ECRM 공식 절차, 수작업, **충분한 지시를 준 범용 LLM** 이후에도 자료 찾기·원문 대조·정정 반복의 부담이 남는가?
- 사건 타임라인/원문-주장 연결, 빠진 내용·충돌 표기, 정정 후 일관성 유지가 **전체 준비 시간과 사실 보존**을 개선하는가?
- 가상·비식별 사건으로 시작하고 실제 개인정보 수집/범죄 판단/신고 대행·법률 자문은 MVP 외로 명시하는가?

**R05 키오스크 메뉴 선택**
- '기준이 없는 상태'와 '메뉴 정보 부족'을 분리해 대상을 특정했는가?
- **같은 정보량**을 주는 일반 메뉴·간단 필터와 AI 도우미를 비교해 **전체 선택 시간, 질문 수, 포기·이해 오류, 선택 만족의 이유**를 기록하는가?
- 6개 가상 메뉴/텍스트/주문 확인까지로 축소하고 POS·결제·음성/실제 매장 도입은 후순위인가? 매장 데이터 입력·갱신 주체의 검증 계획이 있는가?

## 점수/게이트 공정성

- 평가 기준은 그대로. G1 문제 실체 / G2 허용 실험 / G3 8주 검증을 먼저; A25/B25/C15/D20/E10/F5, 등급 정수 0~4.
- 근거 미평가 `null`은 0점이 아니다. 본인 평가·서로 다른 주제/버전을 같은 후보 통계에 합치지 않는다.
- R04 G2(정부24 자동화의 허용 여부, 출력물 인정, 행정정보 공동이용 대안)는 특히 확인. 승인 없는 자동 수집이나 CAPTCHA 회피 실험 금지.
- R03·R05를 잠정 우선으로 준비하더라도 탈락 3개를 형식적으로 처리하거나 반대 근거를 숨기지 않는다.
- 2개를 준비하는 이유/보류 3개 이유는 **멘토 재검토를 위한 임시 편성**으로 표시한다.

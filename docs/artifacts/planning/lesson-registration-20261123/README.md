## 완료 판단과 인계
1. TASK의 필수 산출물이 **지정 경로**에 있고 최종 URL/commit이 확인되어야 합니다.
2. 주장마다 직접 관찰/공식 자료/본인 추정/검증 전 가설을 구분하고, 확인일 또는 근거 링크를 남깁니다.
3. 알아내지 못한 내용은 "미확인"으로 기록하고, 수행한 조사 범위·막힌 이유·다음 확인 방법을 명시합니다. **답 미확인 자체는 실패가 아니라 무근거로 성공을 주장하는 것이 실패**입니다.
4. owner는 자신의 TASK `result`에 결과·근거·검증·결정 요청을 반영합니다. 결과가 없는 TASK는 완료가 아닙니다.
5. 공통 기획 원본은 R01이 통합하고 다른 팀원은 자신의 공간에서 제안합니다. 기존 초안과 과거 TASK 원본은 보존합니다.

# CAND-016 기획안 V1.0 → V1.1 변경 기록

- 2026-11-16 · 상태: 독립 후보 수정안 (팀 공식 최종 주제 아님).
- **V1.0 원문 및 요약은 무수정 유지.** 타깃/도입 주체/페인포인트 S1~S4/F1~F3/8주 MVP 경계를 보존.
- **운영 시나리오:** 시험 전 승인 → 시험 중 감독관 육안/허가된 관측 → 전담요원 선별 → 승인 전달 → 종료 후 확인 → 사후 경위 정리.
- **기존 대안 대비 가치:** 육안·지침·전담인력·RF·조서가 이미 해결하는 일을 인정하고, 불필요 개입/재질의/사후 재작성 시간을 줄일 수 있는지 비교.
- **탐지 주장 제한:** L0 상태, L1 송신 관측, L2 공간 추정, L3 기기군 추정, L4 검토 사건. 특정 수험생 자동 확정 금지.
- **평가:** A 기존 지침, B 체크리스트, C 같은 정보의 사건 카드, D 실측 센서 추가. 필요한 확인 누락과 전체 업무 시간 악화 금지.
- **남은 가설:** 사용자 실제 손실·시스템 효용·기관 승인·실측 RF 검출 성능은 미검증.

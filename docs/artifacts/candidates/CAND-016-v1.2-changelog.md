- **불변:** [V1.0 동결 원문](CAND-016-v1.0-snapshot.md), [V1.1 상세](CAND-016-v1.1-proposal.md)과 요약 유지.
- **추가 근거:** [기존 서비스·잔여 페인포인트 검증 원장](CAND-016-evidence-review-2026-11-16.md).
- **기존 대안 수정:** Monito, SmarterProctoring, ProctorU(온라인), Innovatiview·VigIA(대면), ExamGuard·Exam-Proctor-System·ExamShield·ZuckOff(공개 도구/프로토타입)를 유형별로 직접 비교.
- **철회:** '대면시험장 통합 대안 없음', '스마트안경 탐지/타임라인/보고가 새로운 기능', '센서 경고=특정 학생의 부정행위' 등의 주장은 근거 없음.
- **근거 분리:** 공개된 제품 기능 ≠ 독립 성능 검증, 공식 시험 규정 ≠ 모든 시험의 단일 규정, 대면 기록 공백 사례 ≠ 새 시스템의 개선 효과 입증.
- **페인포인트 재검증:** P1 기술적 한계는 다수 근거 확인. P2/P3 후속 작업량·손실 규모 및 대체안 대비 개선은 아직 미측정.
- **제품 방향:** F1/F2/F3 이름은 유지하되, 비AI 체크리스트 대비 감독관 업무의 증분 가치가 있는 경우에만 구현·도입을 정당화.
- **평가 원칙 유지·강화:** A 공식 지침/양식; B 비AI 체크리스트; C 동일 정보 사건 지원; D 통제 실측 센서. 부적절 개입/재구성 시간 개선, 필요 확인 누락·총업무시간 악화 금지.
- **8주 제약:** 모의 사건 12~20개·정답/실패 기록 필수, 센서는 효과와 승인 확인 시 조건부, AI/ML/LLM은 기준선 우월성 없으면 미채택.
- **사람의 미결정:** 시험 1종/규정, 사용자 문제의 크기, 기관 승인·도입, 제품화 가치, 장비·모델, 팀 공식 주제 승격.

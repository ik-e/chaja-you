# 시험장 부정행위 위험 탐지 및 감독 지원 시스템
## 기획 요약 · V1.3

- 작성일: 2026-11-21
- 상태: **R01 독립 기획 후보 · 효과 검증 전**

### 1. 타깃 사용자

**실사용자:** 대면시험의 현장 시험감독관. **도입 주체:** 시험 운영기관. **협업:** 판별 전담요원·운영본부. 시험 중 스마트안경 등 미허가 기기가 의심되지만 관찰만으로 위반을 확정할 수 없는 상황을 다룬다.

### 2. 페인포인트

| 상황 | 감독관이 겪을 수 있는 손실 |
|---|---|
| **S1 발견** | 정상 수험생을 잘못 의심하거나 확인이 필요한 상황을 놓칠 위험 |
| **S2 판단** | 불확실한 관측으로 확인·보류·이관을 결정할 때 부적절 개입·확인 누락·판단 부담 |
| **S3 인계** | 관측 사실과 추정의 혼동, 반복 설명·재질의·기록 누락 가능성 |
| **S4 사후** | 이의제기 시 관찰과 조치 경위를 다시 정리하는 부담 가능성 |

탐지·운영의 기술적 한계와 기존 절차는 확인됐지만, 위 **사용자 손실의 실제 발생 빈도·규모는 미측정**이다.

### 3. 문제 정의

**대면시험 감독관은 제한된 관측을 바탕으로 시험별 규정에 따라 확인·보류·이관하고 그 근거를 기록해야 한다. 이 과정에서 불필요한 개입·필요한 확인 누락·인계와 사후 기록 부담이 남을 수 있으나, 기존 지침·장비·전담인력을 사용한 이후의 잔여 손실은 아직 검증되지 않았다.**

**원인:** C1 관측만으로 기기·사람·위반을 단정하기 어렵다(기술적 제약 확인). C2 사실·추정·규정·확인 시점의 연결 과정에서 혼선이 발생하는지는 미검증. C3 제한된 기록 환경에서 인계·사후 재작성 부담이 남는지는 미검증.

### 4. 핵심 피처

| 해결 대상 | 기능 | 기대 결과 및 검증 지표 |
|---|---|---|
| S1 / C1 | **F1 징후 발견·선별** | 관측 출처와 불확실성 구분 → 불필요 경고와 필요한 확인 누락 측정 |
| S2·S3 / C1·C2 | **F2 근거 중심 판단·대응** | 사실·추정·미확인·규정·확인/보류/이관 상태 연결 → 부적절 개입·이관 정확성·시간 측정 |
| S3·S4 / C3 | **F3 기록·사후 재구성** | 관찰·검토·조치 이력과 정형 보고 → 사실 누락·재질의·재구성 및 총업무시간 측정 |

### 기존 대안과 검증

공식 지침·전담 인력·조서, 온라인 감독 서비스(Monito·ProctorU 등), 대면 관제(Innovatiview 등), 탐지 도구가 **이미 존재한다**. 기능의 조합만으로 차별화하지 않는다.

**8주 최소 검증:** 시험 1종의 규정과 모의 사건 12~20개를 준비하고 **A: 현행 지침·양식 / B: 비AI 체크리스트 / C: 동일 정보 사건 처리 도구 / D: 검증된 센서 추가(조건부)**를 비교한다. B 대비 C가 사용자 손실을 줄이되 필요한 확인 누락·총업무시간을 악화시키지 않아야 한다. 센서·AI는 추가 효과가 입증될 때만 적용한다.

**미확인:** 감독관의 실제 손실 규모, 기존 절차 대비 개선, 실기기 탐지 정확도, 기관 승인. 승인 전 실제 시험장 수집·시연 및 자동 부정행위 판정은 범위에 포함되지 않는다.

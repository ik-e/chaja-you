# CAND-016 기존 대안 및 잔여 페인포인트 검증 기록

- 조사일: 2026-11-16 (KST)
- 범위: 대면시험 스마트안경 등 미허가 전자기기 의심 사건의 발견(S1/P1) · 대응 판단(S2/P2) · 기록/이관/소명(S3~S4/P3)
- 상태: **후보 기획의 근거 문서. 정식 도입·효과·법적 판단 확정 아님.**
- 연결: [기획 V1.2](CAND-016-v1.2-proposal.md) · [V1.1](CAND-016-v1.1-proposal.md) · [V1.0 동결본](CAND-016-v1.0-snapshot.md)
- 기록 규칙: **직접 확인된 기능**, **공급사/개발자 설명**, **언론 보도**, **해석/가설**, **미확인**을 분리한다. 검색되지 않았다는 이유로 기능이 없다고 결론짓지 않는다.

## 1. 핵심 요약

1. **탐지→사람 검토→증거 연결→보고/이관**은 이미 제품화·공개 구현된 기술 조합이다. 기능 나열, 센서+대시보드, 사건 타임라인·PDF만으로 신규성을 주장하지 않는다.
2. **원격시험과 일반 지필 대면시험은 서로 다른 운영 환경**이다. 원격시험의 웹캠/화면/채팅 로그를 지필 시험장에서 동일하게 쓸 수 있다고 가정하지 않는다.
3. **대면시험 자체에도 통합 보안 대안**(Innovatiview CamView/GuardView)이 있다. '대면시험용 통합 시스템이 없다'는 주장은 철회한다. 해당 제품이 한국 시험별 판단 규정을 자동 적용하는지는 미확인이다.
4. **잔여 사용자 가치의 입증은 아직 없다.** 발견(P1)의 기술적 한계는 다수 자료로 확인되지만, 판단(P2)과 기록(P3)의 추가 작업량 및 제안 시스템의 개선 효과는 인터뷰/비교실험이 필요하다.
5. 제도적 기준은 **시험별**로 달라진다. 수능 규정을 모든 대면시험에 일괄 적용하지 않으며, 센서 신호를 학생·착용·부정행위로 자동 귀속하지 않는다.

## 4. 아직 증명되지 않은 차별화 가설

- **H1 (P1):** 신호·행동 경고를 수험생/부정행위로 단정하지 않으면서 중복/외부 신호를 선별하면, 기존 장비 경고 대비 필요 확인 누락 없이 불필요 경고를 줄일 수 있다.
- **H2 (P2):** 시험별 승인된 규정 버전·관측 사실·미확인을 연결한 사건 카드는 공식 지침+비AI 체크리스트보다 부적절한 확인·잘못된 이관을 줄인다.
- **H3 (P3):** 전담요원과 운영본부의 인수인계 전후 기록 구조가 사실 누락·재질의·사후 재구성 시간을 줄인다.
- **H4 (도입):** 장비 설치/네트워크/수집·보존 권한·감독관 조작 부담을 충족하지 못하면 기술 성능과 무관하게 도입 불가하다.
- **H5 (기존 대안):** 이미 공개된 지침/체크리스트·상용 제품으로 같은 결과를 더 낮은 운영비용에 낼 수 있다면, 독립 제품 가치가 없다.

## 5. 비교와 실행 가능한 검증

**사전 조사 → 모의 실험 → 사람 결정** 순서를 유지한다. 실측 이전에 성공을 기정사실로 쓰지 않는다.

| 조건 | 사용자 입력·도구 | 비교 목적 |
|---|---|---|
| A | 해당 시험의 공식 지침 + 기존 기록양식 | 현행 업무 기준선 |
| B | A + 비AI 체크리스트 | 저비용 대체안 |
| C | **B와 정보량이 같은** 사건 카드·규정 분기·인계·타임라인 | 소프트웨어 F2/F3의 독립 가치 |
| D | C + 통제 실측에서 확인된 단일 센서 이벤트(확보 시) | F1 관측의 증분 가치 |

- 초기 사건 12~20개는 **탐색적 PoC**. 정상 안경, 단순 조작, 외부 BLE, 무송신, 적법한 확인 시점, 이관, 사후 이의제기를 포함하고 정답을 분리한다.
- 관찰 지표: 올바른 조치·필요 확인 누락·부적절 개입·관측/추정 혼동·기록 누락·재질의·사후 재구성 시간 및 **전체 작업 시간**.
- B보다 나아지지 않으면 C의 도입 가치 주장을 보류한다. D가 C를 개선하지 않으면 센서를 빼고 범위를 축소하거나 후보 자체를 재검토한다.
- 원격 상용 서비스를 그대로 시험장에 설치할 수 있다는 전제가 성립하지 않으면 대조표에서 **'기능 선행'과 '현장 대체 가능성'을 구분**한다.
- 법규·개인정보·촬영·무선 수집·접근 권한은 운영기관의 사전 승인 및 검토가 필요하며, 무허가 현장 시연은 하지 않는다.

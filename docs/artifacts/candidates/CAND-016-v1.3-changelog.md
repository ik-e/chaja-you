# CAND-016 V1.2 → V1.3 변경 기록

- 변경일: 2026-11-21
- 변경 종류: **기획안의 설명 구조·문체 개선**, 근거 및 제품 선정 상태 변경 없음.
- 기존 V1.0~V1.2와 각 시점의 근거 기록은 수정하지 않고 보존한다.

## 변경 내용

1. 주요 본문을 **타깃 사용자 → 페인포인트 → 문제 정의·원인 분석 → 핵심 피처** 순서로 재배열했다.
2. 페인포인트에는 실제 사용자 상황과 손실을, 문제 정의에는 공통 장애와 원인을, 핵심 피처에는 이를 줄이는 기능과 측정 지표를 각각 배치했다.
3. S1~S4 / C1~C3 / F1~F3 대응표로 문제와 해결의 관계를 직접 추적할 수 있게 했다.
4. 기존 대안·증거·MVP·검증은 본문 후반부로 이동하고, 근거 상세는 기존 증거 원장(E01~E13)을 연결했다.
5. '타깃 사용자는 이미 결정했다', '철회해야 할 주장', '멘토 예상 질문', 과거 변경 지시처럼 독자에게 필요 없는 내부 작업 설명은 기획서 본문에서 제외했다.
6. 실사용자 손실 규모, 기존 대비 효용, 현장 권한·실측은 **여전히 미확인**으로 유지했다. AI·센서 자동 판정이나 팀의 공식 주제 채택을 확정하지 않았다.

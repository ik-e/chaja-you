# 멘토 검토용 요약 — 시험장 AI 안경 감독 지원 V1.1

**상태:** 독립 후보 수정안 · [V1.0 동결 원문](CAND-016-v1.0-snapshot.md) 유지.

**도입 주체:** 대면시험 운영기관 · **실사용자:** 시험감독관 · **협업:** 판별 전담요원·시험 운영본부

| 흐름 | 한눈에 보는 설명 |
|---|---|
| **타깃/상황** | 시험 중 스마트안경 등 미허가 전자기기가 의심되지만 바로 확증하기 어려운 감독관 |
| **페인포인트** | 정상 수험생을 잘못 확인해 시험을 방해하거나 실제 위반을 놓칠 위험, 사건 이관·사후 소명 시 반복 설명 부담 |
| **문제 정의** | 불확실한 징후를 관찰 사실·규정·판단과 조치 기록으로 연결하면서 불필요 개입과 누락을 줄이기 어렵다 |
| **F1 징후 발견·선별** | 수동/승인 센서 관측을 구분하고 배경·중복 경고를 걸러 확인 가치가 있는 사건 선별 |
| **F2 판단·대응 지원** | 관측/추정/미확인과 규정에 따라 확인·보류·전담요원 이관 |
| **F3 기록·재구성** | 사건 타임라인·근거·검토자·조치 이력을 보존하고 사후 경위 정리 |

### 실제 업무 흐름 가설

**시험 전:** 기관 승인 설정 → **시험 중:** 감독관 기존 육안 감독·허가된 장비 관측 → **전담요원:** 중복·외부 신호·근거 검토 → **공식 경로:** 확인 보류/이관 → **종료 후:** 실물 확인 및 기록 → **사후:** 사건 경위 재구성.

감독관에게 금지된 스마트폰 조작을 요구하지 않고, 무선 신호만으로 특정 학생·좌석·부정행위를 확정하지 않는다.

### 기존 지침·전담인력보다 실제로 덜 할 일

**불필요한 추가 확인 / 같은 사실 반복 설명 / 사건 경위 다시 작성**. 이 세 업무가 기존 체크리스트로도 충분히 해결된다면 새 시스템의 가치는 미입증으로 판정한다. KCA 발주 요구에도 센서·근거·경고·로그가 포함되어 있으므로 기능 나열은 차별점이 아니다.

### 8주 MVP와 검증

**필수:** 정답 있는 모의 사건 12~20개, 사건 카드, 규정 기반 확인/보류/이관, 기록·타임라인·사후 요약, A/B 평가. **조건부:** BLE/Wi-Fi 한 가지 검증 센서 경로, 개선될 때만 다중 수신기/ML/LLM. 3~4주차 장비 채택 게이트.

**대조군:** A 공식 지침+보고 양식, B 지침+비AI 체크리스트, C B와 동일한 정보를 가진 사건 지원 시스템, D 검증 센서가 추가된 C.

**합격 가설:** B 대비 부적절 개입 또는 재구성 시간 개선, 필요한 확인 누락·**전체 업무시간** 악화 금지. 아직 결과 없음.

**미확인:** 실제 업무 손실, 시험기관의 장비/데이터/경고 전달 승인, 스마트안경 실측, 기존 대안보다 뛰어난 사용자 가치.

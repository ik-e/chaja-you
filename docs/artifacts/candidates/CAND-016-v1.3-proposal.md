# 시험장 부정행위 위험 탐지 및 감독 지원 시스템
## 기획안 V1.3

- 작성일: 2026-11-21
- 대상: 대면시험 운영기관 및 현장 시험감독관
- 상태: **독립 기획 후보 · 사용자 가치 및 도입 효과 검증 전**

**서비스 개요:** 스마트안경 등 미허가 전자기기의 사용이 의심되는 대면시험에서 감독관이 관측 사실과 불확실성, 시험별 규정 및 후속 조치를 연결해 **적절하게 확인·보류·이관하고 사건을 기록하도록 지원**하는 시스템이다. 기존 감독 절차보다 실제 업무 손실을 줄일 수 있는지는 검증 대상이다.

## 1. 타깃 사용자

| 구분 | 대상 | 담당하는 업무 |
|---|---|---|
| **핵심 사용자** | **현장 시험감독관** | 시험 중 응시자를 관찰하고, 의심 상황에서 규정에 따라 확인·보류·이관하며 사실관계를 기록 |
| 도입·승인 주체 | 대면시험 운영기관 | 시험별 규정, 장비·데이터 수집과 보관, 담당 권한·예산·설치 승인 |
| 협업 사용자 | 판별 전담요원·시험 운영본부 | 현장 관측 검토, 사실 확인·인계와 후속 조치 |
| 보호 대상 | 수험생 | 근거 없는 부정행위 지목, 불필요한 시험 방해와 부적절한 정보 수집으로부터 보호 |

**사용 상황:** 지필시험 등 대면시험에서 안경 교체·반복 조작 또는 전자기기 관련 신호가 관측되지만, 그 사실만으로 특정 응시자의 규정 위반을 확정할 수 없는 순간이다. 실제 적용할 **시험 1종과 해당 규정**은 기관 협의 및 검증 단계에서 정한다.

## 2. 페인포인트

감독관의 현재 역할과 관측 가능한 제약을 출발점으로, 실제로 줄여야 할 불편과 손실을 구분했다. **아래 손실의 발생 빈도·규모는 아직 감독관 대상 실측으로 확인되지 않았다.**

| 상황 | 감독관이 해야 하는 일 | 겪을 수 있는 불편·손실 | 현재 근거 수준 |
|---|---|---|---|
| **S1 · 의심 징후 발견** | 정상 안경·행동과 확인이 필요한 전자기기 징후 구분 | **오인:** 정상 수험생에게 불필요한 확인·개입. **미발견:** 실제 확인할 상황을 놓침 | 탐지 기술·기종·무송신·소유자 식별 한계 및 실제 시험장 대응 체계는 확인. 현장 오인·미발견 빈도는 미측정 |
| **S2 · 대응 여부 판단** | 제한된 근거를 바탕으로 시험 규정과 허용된 시점에 맞게 확인·보류·전담요원 이관 결정 | 불필요한 개입으로 시험을 방해하거나 필요한 확인을 놓칠 위험, 판단·전달 부담 | 공식 규정과 전담 판단 절차는 확인. 기존 절차를 쓴 뒤 남는 오류·부담은 미측정 |
| **S3 · 사건 인계** | 관찰한 사실, 알 수 없는 사항, 조치 시각과 담당자를 후속 담당자에게 전달 | 사실과 추정의 혼동, 기록 누락, 반복 설명·재질의 가능성 | 기존 구두 보고·조서·보고 시스템 존재. 추가 전달 손실은 미측정 |
| **S4 · 사후 확인·이의제기** | 당시의 관측과 대응 근거를 재구성해 설명 | 사실관계 재확인·경위서 작성에 시간 소요 가능성 | 일부 대면시험 교실의 영상 확인 제한은 공식 자료로 확인. 재작성 시간·개선 효과는 미측정 |

**핵심 사용자 손실:** 단순히 스마트안경을 탐지하지 못하는 기술 문제가 아니라, **확정할 수 없는 의심을 다루면서 불필요한 개입과 필요한 확인 누락 사이의 위험을 관리하고, 후속 설명·기록까지 수행해야 하는 부담**이다.

## 3. 문제 정의와 원인 분석

### 문제 정의

**대면시험 감독관은 미허가 전자기기가 의심될 때 관측만으로 위반 여부를 단정할 수 없어, 관측 사실·불확실성·해당 시험 규정·담당 권한을 종합하여 확인·보류·이관하고 그 근거를 남겨야 한다. 이 과정에서 불필요한 개입, 필요한 확인 누락, 반복 인계·기록 부담이 발생할 수 있으며, 기존 지침과 장비·전담인력을 사용한 뒤에도 이러한 손실이 얼마나 남는지는 검증이 필요하다.**

### 원인 분석

| 원인 | 현재 확인한 사실과 검증할 가설 | 연결되는 페인포인트 |
|---|---|---|
| **C1 · 관측 정보의 식별 한계** | 육안·일부 무선 신호만으로 착용자, 기기 사용 상태 또는 부정행위를 확정할 수 없다. 신호 미관측은 기기 부재의 증거도 아니다. **기술적 한계는 확인**, 실제 감독 업무 손실은 조사 필요 | S1·S2 |
| **C2 · 관측과 판단 기준의 연결 부담** | 시험별 규정과 전담 판별 절차는 존재한다. 실제 사건에서 **관찰 사실·추정·확인 불가 항목·허용 시점이 얼마나 일관되게 연결되는지**는 미확인 | S2·S3 |
| **C3 · 사건 정보의 인계·재구성 부담** | 보고 양식·영상·사건 관리 서비스는 이미 존재한다. 다만 **영상·기록 조건이 제한된 특정 대면시험에서 정보 누락·반복 작성이 남는지**는 미검증 | S3·S4 |

따라서 해결해야 할 문제는 **부정행위 자동 판정**이 아니라, 불확실한 관측에서 적절한 사람의 조치와 재검토 가능한 사건 기록까지 이어지는 **감독관의 사건 대응 업무**이다. C2·C3가 실제 현장에서 발생하지 않거나 기존 절차로 충분히 해결된다면 관련 기능의 제품 가치는 성립하지 않는다.

## 4. 핵심 피처

| 핵심 피처 | 해결하려는 손실·원인 | 사용자에게 제공하는 기능 | 효과 측정 |
|---|---|---|---|
| **F1 · 위험 징후 발견·선별** | S1 / C1: 불필요한 경고와 확인할 상황의 누락 | 감독관 관찰·승인된 센서 이벤트의 **출처, 시각, 관측 범위, 불확실성**을 표시하고 중복·배경 경고를 분리 | 필요한 확인 누락, 불필요 경고 수, 경고 지연 |
| **F2 · 근거 중심 판단·대응 지원** | S2·S3 / C1·C2: 근거가 불명확한 확인·보류·이관 | **관찰 사실 / 시스템 추정 / 미확인**을 구분한 사건 카드에 해당 시험의 규정 출처·버전과 확인·보류·이관 상태 표시 | 부적절 개입, 필요한 확인 누락, 올바른 이관, 판단·전달 시간 |
| **F3 · 사건 기록·사후 재구성** | S3·S4 / C3: 사실 누락·반복 설명·재작성 | 관찰·확인·담당자·조치·수정 이력을 시각순으로 보존하고 **확인된 사실만** 정형 보고에 반영 | 필수 사실 누락, 재질의, 사후 재구성 시간, 총업무시간 |

### 문제와 기능의 연결

**S1 발견 위험 → C1 관측 한계 → F1 징후 선별**  
**S2 판단 부담 → C1·C2 근거·규정 연결 부담 → F2 판단·대응 지원**  
**S3·S4 인계·사후 부담 → C3 기록 연속성 문제 가설 → F3 기록·재구성**

세 기능의 **존재나 조합 자체는 신규성이 아니다.** 기존 공식 절차와 비AI 체크리스트 대비 사용자 손실이 감소한다는 결과가 확인되어야 제품 가치가 인정된다.

## 5. 사용자 업무 흐름

1. **시험 전:** 운영기관이 대상 시험의 공식 규정, 확인 가능한 시점, 판별 책임자, 승인 장비·자료 범위를 정한다.
2. **시험 중:** 감독관이 기존 절차대로 관찰한다. 허가된 관측 이벤트가 있는 경우에만 출처와 수집 상태를 함께 기록한다.
3. **의심 상황 선별:** 담당자가 실제 관측 사실, 배경·외부 신호 가능성, 아직 알 수 없는 사항을 분리한다. 신호만으로 수험생을 특정하지 않는다.
4. **확인·보류·이관:** 시험 규정에서 허용하는 시점과 경로에 따라 감독관·전담요원이 결정한다. 시스템은 가능한 대응과 근거를 보여줄 뿐 자동 제재하지 않는다.
5. **사건 인계:** 확인된 관측·추정·미확인·조치·담당자를 구분한 사건 기록을 승인된 경로로 넘긴다.
6. **사후 확인:** 실제 확인 결과와 수정 내역을 보존하고, 확보되지 않은 사실이나 영상을 생성하지 않은 채 경위를 요약한다.

시험 중 감독관에게 금지된 스마트폰·PC 조작을 요구하지 않는다. 실제 운영 승인 전에는 이 흐름을 **모의 사건**에서만 구현·평가한다.

## 6. 기존 대안과 차별화 검증 대상

| 기존 방식·서비스 | 이미 해결하거나 지원하는 영역 | 추가로 확인할 문제 |
|---|---|---|
| **공식 지침·전담요원·조서** (교육부·시험 운영기관, E11·E12) | 시험별 확인·판단·이관 체계, 기존 보고 절차 | 특정 시험에서 부적절 개입·인계 누락·사후 재작성이 실제로 남는가 |
| **온라인 감독 서비스** (Monito·SmarterProctoring·ProctorU, E01~E03) | 웨어러블 플래그, 사람 검토, 영상·사건 타임라인, 보고서 | 지필 대면시험의 장비·권한·규정에도 동일한 기능을 적용할 수 있는가 |
| **대면시험 보안 서비스** (Innovatiview·VigIA, E04~E06) | 반입 검사, CCTV·AI 관제, 현장 경고·영상 근거 | 대상 기관의 설치·운영 조건과 비용에 부합하는가. 남은 업무가 있는가 |
| **공개 탐지·감독 구현** (ExamGuard·ZuckOff 등, E07~E10·E13) | 일부 BLE·광학·영상 관측, 경고, 로그·보고 | 환경·기종별 오탐/미탐과 실제 운영 효용을 독립적으로 검증했는가 |

출처별 확인 수준은 [근거 원장 E01~E13](CAND-016-evidence-review-2026-11-16.md)에 기록한다. 제품 소개·개발자 README·기관의 사업 계획을 독립적인 정확도나 현장 효과의 증거로 간주하지 않는다.

**차별화 가설:** 특정 대면시험 환경에서 관측 사실·불확실성·적용 규정·후속 조치를 연결함으로써 **공식 지침 + 비AI 체크리스트보다 적절한 대응과 인계·기록 품질을 개선**할 수 있는가. 실제 비교 결과는 아직 없다.

## 7. 8주 MVP 범위

| 구분 | 범위 | 결정 기준 |
|---|---|---|
| **필수 P0** | 시험 1종의 규정과 정답 있는 모의 사건 **12~20개**, 수동 관측 입력, 사실/추정/미확인 사건 카드, 확인·보류·이관 상태, 사건 타임라인·정형 보고, 대조 실험 | 하드웨어가 없어도 F2·F3 사용자 가치를 검증 가능해야 함 |
| **조건부 P1** | BLE 또는 Wi-Fi **단일 센서 입력**, 필요시 복수 수신기·규칙/ML/LLM 비교 | 통제 실측, 적법한 접근·기관 승인, 단순 기준선 대비 추가 가치 확인 시에만 포함 |
| **제외 P2** | 학생·좌석 자동 식별, 모든 스마트안경 탐지 보장, 부정행위 자동 확정, 대규모 영상 AI, 정밀 RF 측위·독자 SDR, 무허가 현장 운영 | 실측·제도·안전·일정 근거 부족 |

후보가 선정될 경우, **2주차** 규정·시나리오·기준선 확인 → **3주차** 사건 처리 예비 실험 및 단일 센서 검토 → **4주차** 가치·기술 게이트와 구현 범위 결정 → **5~6주차** 선택 기능 통합·평가 → **7~8주차** 운영 제약·오류·재현성 점검 순으로 진행한다. 본 일정은 채택 전 계획이며 팀 공식 WBS를 변경하지 않는다.

## 8. 검증 계획

먼저 감독관·운영기관의 실제 업무에서 S1~S4 손실의 **발생 여부·빈도·시간·현행 대처 방법**을 확인한다. 기존 대안으로 충분히 해결되는 경우 관련 기능의 필요성부터 재검토한다.

| 조건 | 비교할 방법 | 검증 목적 |
|---|---|---|
| **A** | 해당 시험 공식 지침 + 기존 조서·보고 양식 | 현행 절차의 성과 |
| **B** | A + 비AI 체크리스트 | 낮은 비용의 대체 방안 |
| **C** | B와 **동일한 관측 정보** + 사건 카드·대응·이관·기록 | F2·F3의 추가 효용 |
| **D (조건부)** | C + 통제 실측으로 검증된 센서 이벤트 | F1의 추가 관측 가치 |

모의 사건별로 관측 정답, 기기·행동의 정답(알 수 있는 경우), 시험 규정상 적절한 조치, 미확인 항목을 분리한다. **12~20건은 탐색적 평가**이며 실제 감독관 전체의 오류율·업무 절감 효과로 일반화하지 않는다.

- **안전·정확성:** 필요한 확인 누락, 부적절 개입, 올바른 확인·보류·이관, 관측 사실과 추정 혼동.
- **업무 효율:** 최초 판단·기록·이관·사후 재구성 시간, 반복 질의, **총업무시간**.
- **센서 도입 시:** 통제된 소유·동의 기기의 검출·누락·오경보·지연 및 환경 변경 내성.

**채택 기준:** B보다 C가 적어도 하나의 주요 사용자 손실을 개선하면서 **필요한 확인 누락과 총업무시간을 악화시키지 않아야 한다.** 센서 D도 C 대비 추가 가치가 있어야 한다. 구체적인 합격 임계값은 본 평가 전에 정한다. 실측·인터뷰 결과가 없거나 기준에 미달하면 기능 축소 또는 후보 중단을 검토한다.

## 9. 운영 제약과 근거

- **판단 책임:** 자동 경고는 검토 단서일 뿐 부정행위 판정이나 제재 근거가 아니다. 실제 조치는 해당 시험의 규정과 권한 있는 담당자가 결정한다.
- **관측 한계:** 무송신·미지원 기기를 놓칠 수 있고 BLE/RSSI는 개인·좌석을 확정하지 않는다. 영상이 없으면 사후 영상 복원도 불가능하다.
- **데이터와 권한:** 실제 시험장 센서·녹화·개인정보 수집·보관·공유는 별도 법적 검토와 기관 승인이 선행되어야 한다.
- **현재 검증 상태:** 실제 감독관 인터뷰, 현장 손실 규모, 센서 실측, C/D 비교 실험, 기관 도입 승인 모두 **미확인 또는 미실시**이다.

**근거 자료:** [기존 서비스·운영 절차·잔여 문제 조사](CAND-016-evidence-review-2026-11-16.md) (2026-11-16, E01~E13).

**결론:** 이 기획의 성패는 F1~F3 구현 여부가 아니라 **현재 감독 업무에 남는 구체적인 손실이 존재하며, 기존 지침·체크리스트보다 유의미하게 줄어드는지**에 달려 있다.

# 시험장 부정행위 위험 탐지 및 감독 지원 시스템
## 기획안 V1.0 — 사용자 문제 중심 · 기술 검증형 MVP

- 작성: 2026-11-16
- 프로젝트: 2026-11-10 ~ 2027-01-04 (5인 · 약 8주)
- 상태: **독립 주제 후보의 기획 기준선**. 팀의 공식 채택·기관 도입·실측 성능이 확정되었다는 의미가 아님.
- 제품명: 미정 (기존 공개 'ExamGuard' 명칭과 혼동 가능)
- V0.9 대비: 타깃 재선정 없음. 사용자 흐름을 본문 중심에 두고, 기술/하드웨어는 실험 부록과 게이트로 이동.

## 1. 한눈에 보는 문제 해결 구조

**도입 주체: 대면시험을 운영하는 기관 → 실사용자: 현장 시험감독관 → 주요 고통: 미허가 전자기기 의심 상황에서 '오인하여 개입할 위험'과 '놓칠 위험'을 동시에 감당하고, 후속 기록·소명 부담이 발생할 수 있음 → 문제: 불확실한 징후를 확인 가능한 근거와 규정상 조치로 연결하기 어려움 → 해결: (F1) 위험 징후 발견·선별 + (F2) 판단·대응 지원 + (F3) 사건 이력·사후 재구성 → 성과: 불필요한 개입, 필요한 확인 누락, 처리·재구성 시간을 줄이는지 기존 지침·체크리스트와 비교 검증.**

### 역할 구분
| 역할 | 정의 | 제품과의 관계 |
|---|---|---|
| 도입·승인 주체 | 대면시험 주관·운영기관 | 허가·예산·보관 정책과 운영요건 결정 |
| **실사용자** | **시험감독관** | 의심 징후 확인, 판단 보류·요청·이관, 사실 기록 |
| 협업 사용자 | 판별 전담요원·시험 운영본부 | 전달된 관측 사실 검토·처리·이관 |
| 보호 대상 | 수험생 | 근거 없는 지목·시험 방해·부적절한 정보 수집을 최소화해야 함 |

**운영 전제:** 감독관이 시험 중 금지된 스마트폰 등을 조작하도록 설계하지 않는다. 경고 전달·입력·확인은 해당 시험의 공식 절차 및 기관이 승인한 장비·담당자·시점으로 제한한다.

## 2. 상황에서 출발한 페인포인트

| 상황 | 실제로 어려운 작업 | 발생 가능한 손실 | 기존 대안 | 이번 제품의 검증 가설 |
|---|---|---|---|---|
| **S1. 시험 중 안경 조작·교체 또는 무선 경고 관측** | 이상 징후를 놓치지 않고 정상 행동과 구분 | 미발견, 정상 수험생 오인 | 입실 검사, 육안 감독, 전담요원, 탐지 장비 | 여러 관측 중 실제 확인 가치가 있는 사건을 더 잘 선별할 수 있는가 |
| **S2. 의심은 있지만 확증이 없어 즉시 확인이 부담됨** | 확인/보류/이관을 규정에 맞춰 결정 | 불필요한 검사·시험 방해 또는 필요한 확인 누락 | 감독 지침, 상황실 협의 | 근거·불확실성·규정 제시가 조치 오류를 줄이는가 |
| **S3. 시험 중 발견과 사후 확인 사이 시간차** | 관찰한 시각·행동과 추정을 구별해 후속 담당자에게 전달 | 사실 누락, 반복 질문, 이관 시간 | 구두 보고, 조서, 종이 양식 | 사건 기록과 이관 형식으로 누락·재질의를 줄이는가 |
| **S4. 확인 결과 일반 안경이거나 이후 이의제기** | 당시 관측과 조치의 근거를 재구성 | 경위서·자료 준비·소명 시간 및 민원 부담 *가능성* | 기관 법률지원, 보험, 기존 기록 | 기록된 사건 타임라인이 재구성 시간을 줄이는가 |

**근거와 한계:** 교원 2,716명 온라인 설문에서 식별 어려움 82.3%, 정상 안경 오인 분쟁 우려 64.4%가 보고되었다. 이는 실제 오탐률·민원율·손해액이 아님. 사전 검사 후 교체, 교시 종료 후 확인, 육안·제보 기반 적발의 실제 사례/제도가 확인됐다. 스마트안경 오인 소송의 반복 발생 및 감독관 1인당 손실 시간은 **미확인**.

## 3. 문제 정의와 제품 가설

**문제 정의**  
대면시험 감독관은 미허가 전자기기 사용을 의심하는 순간, 제한된 관측 근거와 시험 규정 사이에서 확인·보류·이관을 결정해야 한다. 기존 지침과 전담인력은 존재하지만, 발견된 징후를 정확한 관측 사실·불확실성·조치 기록으로 연결하는 과정에서 불필요한 개입, 필요한 확인 누락, 사후 자료 재구성 부담이 얼마나 남는지는 아직 검증되지 않았다.

**해결 가설**  
인정 가능한 관측 입력을 사건으로 선별하고 출처·불확실성·규정상 절차를 명확하게 제시하면, **기존 지침과 비AI 체크리스트 대비** 감독관의 불필요한 개입과 사건 기록·재구성 부담을 줄이되, 필요한 확인의 누락은 증가시키지 않을 수 있다.

**명확히 하지 않는 약속:** 부정행위 자동 판정, 특정 수험생·좌석·스마트안경 확정 식별, 모든 기기 탐지, 실제 소송 감소, 법적 증거능력 보장.

## 4. 핵심 피처와 측정 지표 — 3개

| 핵심 피처 | 사용자의 수행 작업 | MVP 결과물 | 성공 여부 판단 |
|---|---|---|---|
| **F1. 위험 징후 발견·선별** | 관찰·허가된 센서 경고 중 확인할 사건을 구분 | 수동 관찰 입력 + 검증된 경우에만 무선 센서 이벤트 입력; 중복·배경 경보 필터 | 실제 모의 사건 발견률, 시험실 시간당 불필요 경고, 누락·지연 |
| **F2. 근거 중심 판단·대응 지원** | 확인/보류/전담요원 이관 선택 | '관찰 사실 / 시스템 추정 / 미확인'을 분리한 사건 카드와 적용 규정·조치 상태 | 부적절 개입률, 필요한 확인 누락률, 판단·이관 시간 |
| **F3. 사건 기록·사후 재구성** | 관찰·조치 이력을 남기고 이후 설명 자료 준비 | 사건 타임라인, 확인자·수정이력, 출처 연결, 경위 요약 | 사실 누락, 재질의 횟수, 사후 자료 준비시간, 전체 업무시간 |

**F1의 구현 기술은 미확정.** F2·F3는 센서 없이도 모의 사건으로 개발·평가할 수 있으나, 체크리스트보다 추가 가치가 없으면 독립 제품으로 인정하지 않는다.

### 단일 업무 시나리오(데모)
1. 감독관이 안경 교체·반복 조작을 관찰하거나 승인된 센서에서 교실 단위 송신 이벤트가 발생한다.
2. 시스템은 출처/시간/특징을 이벤트로 기록하되, 무선 신호만으로 특정 수험생에 귀속하지 않는다.
3. 사건 카드가 **확인됨 / 추정 / 미확인**을 구분하고, 해당 시험에 유효한 규정과 가능한 다음 행동(관찰 유지·확인 보류·전담요원 이관)을 보여준다.
4. 감독관/전담요원은 규정상 허용된 시점에 직접 판단·조치하고 결과를 남긴다.
5. 이후 이의제기가 발생하면 관측·사람의 판단·조치 이력을 분리한 사실관계 요약을 생성한다.

## 5. 기존 대안 대비 제품이 덜어야 하는 '일'

| 업무 | 현재 대안 | 우리가 줄이려는 반복·오류 | 비교 기준 |
|---|---|---|---|
| 이상 징후 확인 | 육안·사전 검사·기존 RF 경고 | 원인 불명 경보로 발생하는 불필요한 확인 | 육안/단일 센서 |
| 확인·보류·이관 결정 | 기관 지침·전담요원 | 관측 사실과 추정을 혼동한 부적절 개입 | 지침만 / 지침+종이 체크리스트 |
| 사건 설명·전달 | 구두 보고·표준 조서 | 이미 말한 내용을 다시 설명, 필수 사실 누락 | 기존 보고 양식 |
| 사후 경위 정리 | 조서·기관 지원·보험 | 기록을 다시 모아 정리하는 시간 | 일반 양식/사건 카드 |

**차별화 주장은 결과 조건부:** KCA 공개 제안요청서에도 BLE·Wi-Fi 탐지, 신뢰도·오탐, 운영화면·로그 등이 포함되어 있다. 센서+대시보드 자체는 차별점이 아니다. '기존 방법 대비 감독 업무 손실의 측정 가능한 감소'를 입증해야 한다.

## 6. 실제 8주 안에 만들 MVP

### 필수(P0; 센서 성능과 독립적으로 구현)
- 공식 지침/체크리스트 기준선과 동일한 12~20개 **정답이 있는 모의 감독 사건**
- 수동 관찰 또는 공개/실험 데이터 이벤트 입력 API와 이벤트 저장·재생
- 사건 분류(근거 출처·불확실성)와 확인/보류/이관 상태
- 감독관·전담요원용 단순 화면; 관측과 자동 추정을 분리
- 사건 타임라인 및 경위 요약(먼저 정형 템플릿)
- 기존 지침·체크리스트 대비 A/B 평가 기록

### 조기 검증 후 채택(P1)
- **단 하나의 유효한 무선 입력 경로**(BLE 또는 Wi-Fi), 실제 실험에서 관측 가치를 보인 경우만 실시간 연동
- 단일 수신기에서 해결되지 않는 공간 구분 문제가 입증될 때만 수신기 2~3대 비교
- 규칙/통계 대비 효과가 있을 때에만 ML/LLM(LLM은 사건 요약·규정 안내 보조)

### 이번 범위 제외(P2)
- 모든 스마트안경 기종 자동 판별, AI 질문 내용 탐지, 특정 좌석/개인 추적
- SDR 자체 제작, AoA/Channel Sounding/RTT 정밀측위, 대규모 영상 인식 학습
- 법적 책임 자동 판정, 소송 예방 보장, 기관 승인 없는 시험장 운영

**권장 구조:** 수집 어댑터(수동/승인 센서) → 공통 이벤트 로그 → 규칙/통계 기반 사건 선별 → 사건 카드/규정 확인 → 감독관 판단/이관 → 사후 재구성. 수집 어댑터만 바꿀 수 있게 설계한다.

## 7. 기술·하드웨어 후보(조사 범위 내, 구매 결정 아님)

| 후보 | 검증 가능한 기능 | 주요 한계 | 결정 |
|---|---|---|---|
| 기존 PC·SQLite + 공개/모의 데이터 | 데이터 저장·재생, 사건 흐름, 비교 평가 | 실제 RF 탐지 성능 아님 | **즉시 사용** |
| BLE 수신(nRF52840 등) | 광고·일부 연결의 무선 이벤트 관측 | 미광고·주소무작위화·지원 제약 | 1차 후보 |
| Wi-Fi 관측(ESP32-S3/호환 어댑터) | 일부 802.11 프레임의 시간·세기·유형 | 채널·대역·암호화·모니터모드 제약 | 1차 후보 |
| 복수 수신기 RSSI 비교 | 교실 내/외 송신 가능성 비교 | 반사·인체·배치·동일 이벤트 매칭 오류 | 증분 효과 있을 때 |
| SDR/RF 에너지·영상·정밀측위 | 추가 신호 유형/방향 등 탐색 | 비용·개인정보·장비 적합성 | 8주 필수 제외 |
| 규칙/ML/LLM | 경고 선별·설명·요약 | 오탐·과적합·환각·운영 비용 | 기준선 대비 효과로 선정 |

**실험 순서:** (A) 소유·동의 기기의 통제 조건에서 단일 BLE 또는 Wi-Fi → (B) 단일 센서+배경 신호 → (C) 다중 센서 추가 효과. 한 기기만 확인되어도 모든 스마트안경을 찾는다고 주장하지 않는다.

## 8. 검증 가설과 중단·채택 게이트

| ID | 가설 | 지표 / 기준선 | 실패 시 |
|---|---|---|---|
| G-U1 | 사건 카드는 체크리스트보다 감독관의 의심 사건 처리를 개선한다 | **부적절 개입률**, 필요한 확인 누락률, 전체 처리 시간 (지침+종이 체크리스트 대비) | 효과 없으면 핵심 기능 축소/주제 재검토 |
| G-U2 | 구조화된 기록은 이관·사후 자료 준비 부담을 줄인다 | 사실 누락, 재질의, **사후 재구성 시간**, 전체 업무시간 | 기록 기능 간소화 |
| G-T1 | 허가된 저비용 수신기가 무선 송신 사건을 관측한다 | 통제 송신 검출/누락, 지연, 주변 배경 경고 | 해당 장비 미채택 |
| G-T2 | 추가 수신기·환경 정보로 경보 품질이 개선된다 | 시험실-시간당 오경보, 실내/외 오분류 (단일 센서 대비) | 복수 수신기 제외 |
| G-T3 | 규칙보다 ML/LLM이 실질적으로 개선한다 | 정확도/업무시간/비용/근거 오류 (규칙·템플릿 대비) | ML/LLM 제외 |
| G-O1 | 운영기관이 시험실의 해당 입력·기록·경고 방식을 허용한다 | 허가 주체/장비·동선/수집·보관 조건/비용 | 실증 주장 제외, 허가된 모의 환경만 시연 |

**사용자 가치 합격 원칙:** 주요 업무 손실 지표 중 사전 합의한 한 항목 이상 개선, 동시에 필요한 확인 누락과 전체 업무시간을 악화시키지 않을 것. 예: 체크리스트 대비 부적절 개입률 상대 20% 감소는 **예비 목표**이며, 사용자 기준선 측정 후 확정한다. 작은 표본의 결과를 전체 시험장에 일반화하지 않는다.

**센서 합격 원칙:** 송신 기기 정답이 있는 실험에서 관측·오경보·지연을 분리 측정하고, 새로운 교실/세션에서도 재현될 것. '패킷 존재 = 부정행위'나 '센서 추정 위치 = 특정 수험생'으로 취급하지 않는다.

## 10. 멘토님 반론에 대한 답변

**"기존 지침과 전담인력으로 충분한 것 아닌가요?"**  
이미 존재하므로 대체하지 않는다. 우리가 추가하는 것은 **의심 사건의 관측 사실/추정 분리, 필요한 확인의 우선순위, 확인·보류·이관 기록의 연결**이다. 그 결과 감독관이 **불필요한 확인을 얼마나 줄이고, 반드시 필요한 확인과 사후 경위 정리는 놓치지 않는지** 체크리스트를 대조군으로 실험한다. 개선되지 않으면 제품이 필요하다는 주장을 철회한다.

**"왜 AI와 하드웨어가 필요한가요?"**  
필수 기술로 미리 결정하지 않는다. BLE/Wi-Fi/다중수신기와 규칙/ML/LLM을 동일 지표로 비교하고, 실제로 경고 품질·업무효율을 높이는 최소 조합만 선택한다. 정형 규칙과 종이 체크리스트가 더 낫다면 그 결과도 인정한다.

**"8주 안에 가능한가요?"**  
필수 P0는 **사건 카드+판단·이관+기록/재구성+대조군 평가**로 제한한다. 실측 센서는 3~4주차 기술 게이트를 통과한 **1개 경로**만 연동하고, 정밀 위치·영상·상용 장비 개발은 제외한다.

# 멘토 검토용 1페이지 — 시험장 부정행위 위험 탐지·감독 지원

**도입 주체:** 대면시험 운영기관  
**실사용자:** 시험감독관(협업 사용자: 판별 전담요원·운영본부)  
**핵심 상황:** 시험 중 스마트안경 등 미허가 전자기기가 의심되지만 확증할 수 없어 정상 수험생 오인과 실제 부정행위 미발견을 동시에 우려하는 순간.

## 타깃 → 페인포인트 → 문제 정의 → 핵심 피처

| 사용자 | 아픈 상황/손실 | 문제 정의 | 핵심 피처 | 검증 |
|---|---|---|---|---|
| 시험감독관 | 의심 징후를 놓치거나 정상 안경을 잘못 의심 | 신호·행동을 확인할 가치가 있는 사건으로 선별하기 어려움 | **F1. 위험 징후 발견·선별** | 실제 모의 사건 탐지, 시간당 오경보 |
| 시험감독관 | 확인/보류/이관을 고르기 어려워 시험 방해·책임 부담 | 관측 사실과 추정·규정을 연결하기 어려움 | **F2. 근거 중심 판단·대응 지원** | 잘못된 개입, 필요한 확인 누락, 처리시간 |
| 시험감독관 | 이후 이의제기에 관찰·조치 경위를 다시 설명 | 사건 기록·이관 과정에서 사실 재구성에 시간 소요 가능 | **F3. 사건 기록·사후 재구성** | 사실 누락, 재질의, 재구성 시간 |

**기존 대안:** 감독 지침, 전문 판별 인력, 실물 검사, RF 장비, 일반 조서/체크리스트가 이미 존재한다. 우리의 차별화는 새로운 기능의 나열이 아니라 **기존 지침+비AI 체크리스트보다 필요한 확인을 놓치지 않으면서 불필요한 개입·기록 부담을 줄인다는 실측 결과**로만 주장한다.

## 8주 MVP
- **필수:** 12~20개 정답 있는 모의 사건, 지침/종이 체크리스트 대조군, 수동/승인 데이터 입력, 사건 카드(관찰/추정/미확인 구분), 규정 기반 확인·보류·이관, 사건 타임라인·사후 재구성, 효과 비교.
- **조건부:** BLE 또는 Wi-Fi **1개 검증된 센서 경로**; 개선될 때만 추가 수신기/ML/LLM.
- **제외:** 특정 수험생·좌석 추정 자동 확정, 모든 스마트안경 탐지, SDR·영상 AI 대규모 개발, 실제 소송 감소 보장, 승인 없는 실시험 데이터 수집.

**기간/게이트:** 11/16~11/22 시나리오/기준선 → 11/23~11/29 사건 카드·기초 센서 테스트 → 11/30~12/06 기술·하드웨어 확정 → 12/07~12/20 통합 MVP/비교 평가 → 12/21~2027/01/04 운영 검증·최종 시연.

**멘토 핵심 질문에 대한 답:** “기존 지침·전담인력을 대체하는 것이 아니라, 관측 사실·추정·규정·조치 기록을 연결하여 **불필요한 확인·반복 설명·사후 경위 재구성 업무를 줄일 수 있는지** 검증합니다. 기존 체크리스트보다 좋아지지 않으면 그 기능을 채택하지 않습니다.”

**현재 미입증:** 감독관 1건당 실제 손실 시간, 공식 현장 승인 가능성, 무선 센서의 실제 스마트안경 검출률, 체크리스트 대비 개선 효과. 연구 후보를 제품의 확정 성능이라고 표현하지 않음.

- 상태: 독립 후보의 기획 기준선. 팀/멘토 승인 전.

## 2. PSI 원문 검증 메모

### GUIDE-PSI-2021

- 첫머리에 **Test Center Administrator (TCA) Operations Manual / Global Owned and Operated Sites / Version 1.1 / Revised Dec 3, 2021 / Company Confidential Data** 표시.
- Section 6 *Deceptive Behaviors | Cheating*에 의심 사건 관찰, 응시자 설명 확인, 상급자 협의, 진행 여부 확인, Incident Report 기록 절차가 등장.
- *Complete an Incident Report* 항목은 **의견과 관측 사실을 구분하고, 조사에 필요한 구체적 사실을 남기도록** 요구함.
- **연구 활용 한정:** '관찰→확인·협의→기록'이라는 이미 존재하는 운영 단계의 사례로만 사용. 특정 센서·AI 솔루션 효과 입증, 한국 감독관의 현재 부담 크기 입증, 국내 시험 규정의 근거로 사용 금지.
- PDF 주소는 PSI의 `proctor2.psionline.com` 하위 도메인에 위치한다. 다만 도메인에 공개 접근되는 사실만으로 PSI가 **2차 배포를 허락했다는 뜻은 아님**.

### GUIDE-PSI-2018

- 표지에 PSI Services LLC, *Test Center Operations Manual* 표기. 저작권 항목에 복제·전송에 대한 서면 허가 요구가 명시됨.
- *Exam Security and Cheating* 항목이 있으나 2021판과 **세부 절차 동일성 또는 최신 적용 여부는 검증하지 않음**.
- 공개 저장소의 새 PDF 사본, 전문 전사, 대량 발췌, 번역 전문을 만들지 않는다.

## 3. 공식 지침과의 관계: 혼합 사용 금지

- **국내 대면시험의 실제 절차 판단 기준:** 해당 시험의 **발행기관 공식 규정과 승인된 운영 지침**. 교육부 2026-10-29 대응계획/11-06 안내는 2027학년도 수능 스마트안경 문제를 다룬 공개 자료이며 모든 시험에 자동 적용할 수 없다.
- 교육부 11-06 안내는 스마트기기 **사용·착용 / 반입·소지 / 확인 요구 불응**을 구분하고, **감독관→전담인력→상황실** 판단 경로를 안내한다. 세부 제재·절차는 당시 공식 문서·시험별 지침으로 재확인한다.
- **PSI 사용 목적:** F2(판단·이관)와 F3(사건기록)에 유사한 비AI 운영 절차가 이미 존재한다는 **비교 참고자료**. A/B/C 대조군의 '공식 지침'으로는 PSI를 사용하지 않는다.
- 다른 대학·기관의 '가이드'라고 전해진 자료는 **문서명·원문 URL 없이 이 원장에 확인 완료로 등록하지 않는다**.

## 4. 보존/갱신 규칙

1. **원본 판별:** 발행기관·문서명·발행/개정 날짜·문서 버전·원본 링크·접근한 날짜·사용 가능한 범위를 함께 기록.
2. **검증 수준:** 발행기관 직접 게시인지 / 2차 재게시인지 / 기관 공식 현재 효력인지 분리. 외국 운영 매뉴얼과 한국 시험별 공적 규정을 혼용하지 않음.
3. **권한:** `Confidential`·`All rights reserved` 문서는 **링크와 최소한의 서지 메타데이터만 공개 보존**. 파일 복사나 재배포는 권리자의 명시적 허락 확인 후 별도 검토.
4. **공개자료:** 공공누리 등 재이용 허용 조건이 검증된 경우 **출처표시·라이선스 기록을 남긴 후** 원본 바이트 보존을 별도 진행할 수 있음. 이 작업에서는 원본 바이트를 확보하지 못했으므로 '원문 파일 저장 완료'라고 표시하지 않음.
5. **재현성:** 향후 원본을 적법하게 확보한 경우 파일명·MIME·SHA-256·보존 위치·접근일·사용 허가 조건을 추가. 확인하지 않은 값은 공란/미확인 유지.
6. **개정시점:** 원장 자체는 2026-11-16 기록으로 남긴다. 이후 새 근거가 생기면 후속 확인일과 변경 이력을 추가하고 기존 사실을 조용히 소급 변경하지 않음.
7. **데이터 수집 규칙:** 문서 출처 확인을 위한 수동·소량 열람에 한정하며, 무단 크롤링/대량 다운로드는 수행하지 않음.

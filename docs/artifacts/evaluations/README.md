# 평가 산출물

작업 담당자가 [EVAL](../../../EVAL.md)의 사례 ID와 실행 경로, 검사별 판정·근거를 JSON으로 저장한다. 새 평가에는 가능한 경우 `task_ref`와 `traceability`를 함께 두어 어떤 TASK·Intent·Design Hypothesis·Requirement를 실제로 검증했는지 연결한다. 통과 여부와 근거를 사람이 보는 [검토 화면](../../review/README.md)에 반영한다. 현재 제품 평가 기록은 미기록이다.

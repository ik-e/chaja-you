# 회의록 요약 원본

Discord `#회의록`에 게시된 회의 자료를 확인해 만든 공개 참고 요약의 JSON 원본입니다. 원문 메시지와 첨부 바이트는 저장소에 넣지 않고 로컬 전용 `docs/meetings/originals/discord/`에 보존합니다. 공개 검토용 Markdown은 이 JSON에서 생성합니다.

- 발언자와 의도, 항목의 상태, 실제 합의 여부가 확인되지 않으면 미확인으로 남깁니다.
- 회의 요약은 현재 기준이나 결정으로 승격하지 않습니다. 프로젝트의 현재 상태와 결정은 관련 사람 의도·응답, TASK, 명세, ADR에서 확인합니다.
- 새 AI 요약을 추가하거나 수정한 뒤 `uv run --no-project python tools/project_docs.py`를 실행하고 `--check`로 생성 상태를 확인합니다.

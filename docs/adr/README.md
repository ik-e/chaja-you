# 중요 결정 기록

범위·핵심 구조·데이터 모델·평가 기준·중요 기술의 결정에는 배경, 선택지, 근거, 결정, 이유, 재검토 조건을 남긴다. 작은 기본값은 해당 TASK에 기록한다.

AI가 결정 기록을 준비하면 `status`를 제안으로 두고, 권한 있는 담당자가 결정했을 때 결정자와 날짜를 기록한다. 원본은 `ADR-번호_주제.json`, 사람이 보는 문서는 같은 이름의 Markdown 프로젝션으로 생성한다. 근거가 부족하면 필요한 추가 작업을 CURRENT에 연결한다.

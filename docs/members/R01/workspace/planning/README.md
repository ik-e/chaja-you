# R01 작업 산출물 안내

기존 기획·조사 자료는 [AI 산출물](../../../../../docs/artifacts/README.md)의 구조화 원본으로 이관했다. 자료의 owner와 원래 문서 상태를 확인한다.

- [작업 계약](../../../../../TASK.md) · [현재 작업](../../../../../CURRENT.md)
- [사람이 확인할 화면](../../../../../docs/review/README.md) · [필수 제출물](../../../../../docs/submissions/README.md)

작업 담당자는 TASK와 원본을 갱신하고 프로젝션을 생성한다.

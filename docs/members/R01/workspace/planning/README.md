# R01 기획서·WBS 작업공간

이 디렉터리에는 기획서와 WBS 초안, 이를 위한 조사 종합과 미결정 사항을 둡니다. 팀이 확정한 내용은 해당 공용 문서에도 반영하고, 조사 원본은 복사하지 말고 원본 보관 위치를 연결합니다.

- [새 시스템 비전 범위 조사 종합](기획서_범위_조사_6AI.md): 2026-11-11 6개 AI 자문 종합. 5개는 완료, Gemini는 비교표 일부만 회수되어 최종 의견에서는 보류했다.
- [기존 기술 재사용 심화 조사](기존기술_재사용_심화조사.md): 2026-11-11 후속 자문. Claude·Perplexity·DeepSeek·Gemini·ChatGPT 응답을 공식 문서와 대조해 정리했다. Grok은 Edge 도메인 허용 확인에 막혀 후속 답변을 회수하지 못했다.
- [8주 MVP 기술 방향 — 5개 AI 자문 종합](기술_방향_6AI_협의_종합.md): 동일한 통합 설계 요청에 대한 5개 AI 답변을 종합하고, 기술 층별 기본안과 1주 PoC·미결정 사항을 제안한다. Grok은 이번에도 Edge 연결이 허용된 대화로 인식되지 않아 응답 회수에서 제외했다.
- [1주 PoC 선행 조사 — 4개 AI 자문 종합](PoC_선행조사_4AI_종합.md): Grok 제외 후 ChatGPT·Gemini·Perplexity·DeepSeek의 후속 답변을 모아 도메인 선정, 워크플로/검색/기억 실험, 역할별 1주 산출물을 구체화했다.
- [기획서 사전 조사 종합](기획서_사전조사_종합.md): 2026-11-11에 6개 AI 응답을 종합한 초안 참고 자료. 외부 출처와 수치 주장은 독립 검증 전 상태입니다.

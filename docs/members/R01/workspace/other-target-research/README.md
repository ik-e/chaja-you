# R01 — 현재 타겟 외의 사용자·도메인 문제 탐색

현재 R01의 주 검증 타겟은 **AI 활용 소규모 프로젝트 책임자의 반복적인 판단·검증·조정 부담**이다. 이 폴더는 그와 직접 관련 없는 별도의 잠재 사용자·도메인 문제를 조사한 기록을 보존한다.

- **성격:** 독립 탐색 자료. 폐기된 자료나 현재 MVP 요구사항이 아님.
- **의사결정 영향:** 이 폴더에 있는 내용만으로 현행 R01 타겟, 공식 프로젝트 범위, 다른 팀원의 제안이 변경되지 않음.
- **복귀:** [R01 현재 작업 목차](../README.md)

## 관리 기준

현재 타겟에 직접 관련된 비교·반증 자료만 R01 주 작업 공간에서 유지한다. 다른 사용자 집단이나 서비스 영역을 조사한 기록은 이곳에 모으며, 추후 타겟 변경 검토 시 **새 사용자 검증 없이 확정 근거로 승격하지 않는다**.

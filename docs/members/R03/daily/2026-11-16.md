## 아침 체크

**새로 생각하는 주제를 개인적으로 조사하고, 타겟 사용자 → 페인 포인트 → 문제 정의 → 핵심 피처가 연결되도록 구체화한다.**

구체적인 주제는 아직 미기록이다. 기능이나 기술을 먼저 확정하지 않고, 사용자의 실제 상황과 현재 해결 방법에서 문제 가설을 찾는다.

- [ ] 실제로 막히는 이유와 현재 해결 방법을 조사한다. 특정 불편을 정답으로 두지 않고 실제 사례와 근거를 확인한다.
- [ ] 기존 서비스·일반 검색·범용 AI로 해결되는 부분과 남는 불편을 비교한다.

# 폴봇 직접 이용 보고

- 기록: R03 두나 · 2026-11-17
- 근거: 대화에서 전달받은 본인의 직접 이용 경험. 실제 이용 시각·질문 원문·선택 메뉴·반복 횟수·완료 단계는 미기록.

## 보고한 내용

두나님은 폴봇을 직접 사용했으며, 이용한 대화에서는 어떤 자료가 필요한지 설명을 보지 못했고 어떤 신고를 할 것인지 묻는 질문이 계속됐다고 설명했다.

## 기획 반영

- ‘폴봇 실제 이용 미시험’ 대신 ‘이용자 보고 1건 확보, AI 재현·대화 로그 검토 없음’으로 구분한다.
- 이용한 경로에서 준비자료 안내에 도달하지 못했다는 사례로 사용한다. 신고 유형 분류와 신고 전 자료 준비가 서로 다른 과제임을 보여주는 초기 근거다.
- 폴봇 전체에 준비자료 안내가 없거나 자동 작성 기능이 없다고 단정하지 않는다. 다른 메뉴·후속 단계·입력 조건의 동작과 수정·저장 기능은 미확인이다.
- 현재 제안의 준비 목록·자료 상태·사건 초안 범위를 유지한다. 새 기능·외부 서비스 연동을 추가하지 않는다.
- 체크리스트·충분한 지시의 LLM 대비 추가 가치와 실제 재인증 감소는 여전히 미검증이다.

과거 폴봇 자동 작성 발표와 현재 한 이용 경로의 자기보고는 서로 다른 근거다. 과거 발표를 현재 전체 동작의 증명으로, 현재 경험을 기능 전체 부재의 증명으로 사용하지 않는다.

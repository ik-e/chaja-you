# ECRM 준비 항목 확인·재인증 불편 정리

- R03 두나 · 2026-11-17 · 사용자 설명 기반 문제 구체화

## 핵심 pain 변경

‘수정을 반복하는 부담’을 핵심 pain에서 제외한다. 대신 **상세 접수 항목을 미리 파악하지 못해 인증 후 화면에 들어가 확인하고, 준비 중 로그인 시간이 끝나면 재인증해 재진입해야 하는 번거로움**을 다룬다.

따라서 ‘모든 준비물은 로그인해야만 알 수 있다’고 표현하지 않는다. 처음 사용자가 안내를 찾는 실제 경로, 인증 전 준비 가능한 범위, 인증 후 추가 확인 항목을 구분해 확인한다. 재인증은 두나님 설명으로 기록하며 전체 사용자에게 같은 빈도로 발생한다고 일반화하지 않는다.

## 문제 정의

**처음 중고거래 피해 신고를 준비하는 사람은 상세 접수 항목과 자료를 미리 파악하지 못하면 인증 후 화면에서 확인하며 준비하게 되고, 그 과정에서 로그인 시간이 끝나면 재인증·재진입해야 하는 번거로움을 겪을 수 있다.**

## 기존 기능과 연결

- 공식 공개 안내를 바탕으로 준비할 자료 목록과 사건 초안을 로그인 전에 검토하도록 돕는다.
- 모르는 항목은 미확인으로 남기고 자료를 직접 준비한 뒤 ECRM에서 본인이 접수한다.
- 정정 반영은 잘못 정리된 내용을 고칠 수 있는 정확성 기능으로 유지하되 핵심 사용자 pain으로 내세우지 않는다.
- ECRM 인증·세션을 유지하거나 우회하는 기능은 제공하지 않는다. 재인증이 없어지거나 접수가 한 번에 끝난다고 보장하지 않는다.

## 최소 확인과 비교

먼저 공개 안내와 인증 후 상세 항목의 차이, 만료·저장·연장 동작을 허용된 실제 이용 범위에서 확인한다. 실제 신고를 허위 제출하거나 인증 정보를 수집하지 않는다.

같은 준비 과제에서 공개 안내만 / 체크리스트 / 충분한 지시의 LLM / 시제품 준비 후 제안 방식을 비교한다. 준비 항목 확인을 위한 화면 이동·인증 재진입 횟수, 준비·입력·검토 시간, 누락·왜곡을 함께 기록한다. 모의 만료를 시험하면 모의 조건으로 표시하고 실제 ECRM 제한 시간으로 취급하지 않는다. 공개 안내·체크리스트로 충분하면 별도 서비스의 추가 가치는 미확인으로 남긴다.

- 추가 사용자 확인: 두나님은 재인증 후 기존 입력을 이어 쓰지 못하고 처음부터 다시 입력했다고 설명함. 이용한 화면·경로의 자기보고로 기록한다.

## 사용자 화면 공유 관찰 — 인증 후 경로

사용자는 본인인증을 미리 했다고 설명했다. 공유 화면에서 신고 절차 안내 팝업, 긴급사안 질문, 02 증거자료 첨부 단계의 신분증 필수 업로드 안내를 확인했다. 팝업에는 주민등록증·운전면허증·외국인등록증·여권·주민등록등본과 기타 신분증 불가 안내가 표시됐다. 이는 해당 화면의 관찰이며 인증 전 접근성·전체 접수 완료·시간 만료 재현의 증거가 아니다. 이미지 원본은 공개 저장소에 복사하지 않았다.

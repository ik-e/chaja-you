# ECRM 접수 전 준비 지원 — 첫 시제품 작업 범위

- R03 두나 · 2026-11-17 · 개인 제안 범위 합의 반영
- 목적: 로그인 전에 준비할 자료와 사건 설명을 정리해, 준비가 덜 된 상태에서 접수 화면을 오가는 수고를 줄일 수 있는지 확인한다.
- 최종 결과: 검토한 사건 요약·자료 준비 목록·미확인 항목·공식 ECRM 링크. 신고 접수 완료나 자료 충분성 승인으로 표시하지 않는다.

## 지원할 단계와 입출력

| 단계 | 입력·사용자 행동 | 지원·출력 | 완료·진행 조건 |
|---|---|---|---|
| 준비 항목 확인 | 중고거래 물품 미수령·최초 신고 준비 상황 선택 | 공식 공개 안내에 근거한 자료·작성 항목 목록, 출처·확인일·적용 범위 | 안내 목록을 볼 수 있음. 실제 ECRM 필수 항목 전체를 검증했다는 표시는 하지 않음 |
| 자료 준비 상태 정리 | 보유·미보유·모름 선택, 비식별 자료 설명 | 준비된 자료·추가로 확인할 자료 구분 | 모름이어도 진행. 보유 응답을 자료 내용 확인으로 처리하지 않음 |
| 사건 경위 정리 | 자유 설명·사용자가 가져온 비식별 문구 | 입력 원문과 연결된 수정 가능한 사건 초안 | 입력에 없는 날짜·금액·실제 발송 여부를 만들지 않음 |
| 접수 전 검토 | 초안 확인·추가 답변·정정 | 누락·충돌·미확인 표시, 갱신된 요약·자료 목록 | 사용자가 검토하거나 미확인 항목을 남긴 채 결과로 이동 |
| ECRM 이동 | 검토한 결과 복사·공식 링크 선택 | 주장·미확인 표시를 보존한 복사 텍스트, 공식 안내 | 실제 인증·입력·첨부·접수는 사용자가 ECRM에서 직접 수행 |

**준비 목록 확인 → 기억나는 내용 입력 → 초안·누락 확인 → 검토 후 복사 → ECRM 직접 접수** 순서다. 자료 상태 선택과 자유 설명은 순서를 강제하지 않고 초안 보완 때에도 수정할 수 있다.

## 지원하지 않는 일

- 대화·게시글·이체 자료 자동 수집, 계정 연결, 실제 파일·이미지 판독, 신분증 업로드
- ECRM 로그인·본인인증 대행, 인증정보 수집, 세션 유지·연장·우회
- ECRM 자동 입력·첨부·신고 제출, 수사 진행 관리
- 범죄 성립·의도·법적 책임·환불 가능성 판단

용어 설명과 정정 반영은 준비·정확성을 돕는 기능으로 유지한다. 반복 수정은 핵심 pain으로 다시 올리지 않는다.

## 입력 출처와 확인 수준

| 입력 | 출력 표현 | 확인한 범위 |
|---|---|---|
| 사용자의 직접 설명 | 사용자는 12만 원을 보냈다고 설명함 | 진술이 입력됐음 |
| 사용자가 자료를 설명 | 사용자는 이체 내역에 12만 원이 기재됐다고 설명함 | 사용자의 자료 설명. 실제 파일 미열람 |
| 사용자가 옮긴 판매자 문구 | 사용자가 제공한 문구에서 판매자가 배송했다고 주장함 | 제공 문구의 기재. 원본 메시지·실제 발송 진위 미확인 |
| 공식 안내 | 공식 출처의 준비 안내와 확인일 표시 | 공개 안내의 내용·범위 확인 |

첫 시제품은 텍스트·자료 목록만 받는다. 실제 이체 자료를 읽거나 검증한 것처럼 표현하지 않는다. 추후 파일 판독은 별도 범위 결정 사항이며 여기서 추가하지 않는다.

## 효과를 측정할 구간

| 구간 | 직접 지원 | 측정 |
|---|---|---|
| 원래 대화·이체 자료 찾기 | 자동 수집 없음 | 사용자가 직접 찾는 시간 별도 기록 |
| 준비 항목 확인 | 공개 안내 정리·준비 상태 목록 | 항목 확인용 화면 이동, 인증 재진입 횟수·시간 |
| 입력·정리 | 원문 연결 초안 | 입력·정리 시간, 누락·왜곡 |
| 대조·검토 | 원문 표시·미확인/충돌 | 대조 횟수·시간, 근거 불일치 |
| 정정·결과 활용 | 관련 결과 갱신·복사 | 정정 후 불일치, 검토·복사 시간 |

전체 시간과 구간별 시간을 함께 기록해 최초 자료 수집 시간 감소를 기능 효과로 혼동하지 않는다. 인증 시간 만료·연장·임시저장·복원 동작은 AI 직접 미시험이다. 공개 안내로 이미 확인 가능한 부분을 제외하고 실제 인증 후 화면에서 추가 확인할 부분을 먼저 대조한다. 가상 만료 시험은 모의 조건이며 실제 ECRM 정책으로 표시하지 않는다.

## 비교·중단

동일 준비 과제에서 ECRM 공개 안내만 / 안내+체크리스트 / 충분한 지시의 LLM / 시제품 준비 후 제안 방식을 비교한다. 모델·도구·도움·방법 순서를 기록한다. 실제 신고를 허위로 제출하지 않으며 시제품 미구현 상태의 수동 시연은 별도 표시한다.

기존 대안이 같은 수준의 사실 보존과 같거나 적은 수고를 제공하면 추가 가치 미확인으로 판정하고 축소·보류를 제안한다. 재인증 감소는 목표·가설이며 인증 면제나 한 번에 접수 완료를 약속하지 않는다.

# 중고거래 상담·신고 준비 자료 정리 — 멘토 검토 요약

R03 두나 · 2026-11-17 · 개인 제안, 팀 최종 제품 선정 전

**처음 중고거래 피해 상담·신고를 준비하는 사람이 증빙과 사건 경위를 정리하고, 빠진 내용을 확인해 자신이 검토한 요약을 만들도록 돕습니다.**

## 1. 타겟과 문제 정의

**타겟:** 입금 후 물품을 받지 못해 처음 상담·신고를 준비하는 사람.

**문제 가설:** 여러 증빙과 상세한 사건 경위를 작성해야 하지만, 무엇을 준비하고 어떻게 설명할지 몰라 부담을 느낍니다. 용어 이해는 보조 문제이고 반복 재작성은 추가 확인할 세부 가설입니다.

## 2. 실제 경험 근거

사용자가 찾은 [공개 경험담](https://blog.naver.com/goskfk74/224395719699)은 첫 신고의 긴장, 이체·대화·게시글 등 증빙 첨부, 상세 경위 작성을 설명합니다. 사전 작성 후 경찰서 처리가 오래 걸리지 않았다는 설명도 있어 **기존 ECRM의 효용을 함께 인정**합니다. 티켓 거래 자기보고 1건이며 반복 재작성·일반적인 수요를 입증한 자료는 아닙니다. [근거 정리](2026-11-17_중고거래_공개경험담_근거_01.md)

## 3. 기존 대안과 남는 질문

- **ECRM·폴봇:** 작성 안내와 질문 기반 자동 작성의 [2022년 공식 발표](https://m.korea.kr/news/policyNewsView.do?newsId=148908906)가 있습니다. 현재 폴봇 실제 대화·수정은 미시험입니다.
- **충분한 지시의 LLM:** 가상 1건·2턴에서 원문 연결·금액 정정·미확인 보존을 수행했습니다. 이 사례에서 제안 서비스의 추가 가치는 확인되지 않았습니다. [실행 기록](https://github.com/ik-e/chaja-you/blob/main/docs/members/R03/workspace/2026-11-16_기존대안_반증점검_결과.md)
- **비AI 체크리스트**도 준비를 도울 수 있습니다. 더치트·플랫폼 신고는 조회·대응 경로이며 준비 지원의 상세 범위는 별도 확인 대상입니다.

**남는 질문:** 기존 대안을 사용해도 자료를 대조하고 빠진 항목을 확인하는 수고가 남는가? 제안 방식이 정확성을 유지하면서 그 수고를 더 줄이는가?

## 4. 핵심 피처와 사용자 흐름

| 핵심 피처 | 입력·결과 | 확인할 효과 |
|---|---|---|
| 사건·자료 구조화 | 자유 설명·사용자가 가져온 문구 → 원문 연결 사건 초안·자료 목록 | 중요한 내용 누락·왜곡 감소 |
| 누락 확인·수정 반영 | 초안·추가 답변·정정 → 미확인·질문·갱신된 요약 | 수정 후 불일치·재입력·검토 수고 감소 |

**시작 → 자유 입력 → 초안 보완 → 검토·복사.** 모르는 내용은 미확인으로 남기고 잘못 정리된 부분을 수정합니다. 자료 자동 수집·신분증 업로드·법적 판단·신고 대행은 포함하지 않습니다. 결과는 준비 자료이며 이후 절차는 [ECRM 공식 안내](https://ecrm.police.go.kr/minwon/main)를 따릅니다.

## 5. 가장 작은 비교와 미확인

같은 가상 자료·정정으로 **안내만 / 안내+체크리스트 / 충분한 지시의 LLM / 시제품 준비 후 제안 방식**을 비교할 계획입니다. 기준 사실 누락·왜곡, 정정 후 불일치와 함께 준비·입력·검토·수정 시간 및 횟수를 기록합니다. 정확성 악화를 시간 단축으로 상쇄하지 않습니다. 대안으로 충분하면 구현 보류·축소를 제안합니다.

실제 부담의 크기·빈도, 폴봇 현재 출력, 서비스 추가 가치·법률 경계 검토는 미확인입니다. 이번 정리는 새 실험·서비스 채택을 뜻하지 않습니다.

## 6. 멘토 질문

1. 증빙 준비와 경위 작성 중 어떤 부담을 첫 검증 대상으로 좁히는 것이 적절할까요?
2. ECRM·체크리스트·충분한 지시의 LLM 대비 추가 가치를 판단할 가장 작은 비교 과제는 무엇일까요?
3. 비교에서 추가 가치가 없으면 어떤 조건으로 축소·보류하는 것이 적절할까요?

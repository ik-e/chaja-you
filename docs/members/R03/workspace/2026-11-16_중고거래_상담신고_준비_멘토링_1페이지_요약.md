# 중고거래 피해 상담·신고 준비 지원 제안 요약

R03 두나 · 2026-11-16 · 멘토링용 개인 제안 · 사용자 확인 전

**흩어진 거래 자료와 사건 경위를 원래 입력에 연결해 정리하고, 사용자가 검토·수정한 내용으로 상담·신고 준비를 돕는 멀티에이전트 시스템을 제안합니다.**

## 1. Target — 누구를 돕는가

온라인 중고거래에서 돈을 보냈지만 물품을 받지 못해, 처음 상담·신고를 알아보면서 거래 경위와 자료를 어떻게 정리할지 막힌 사람입니다.

## 2. Pain — 확인할 핵심 불편

**흩어진 거래 자료를 다시 찾고 같은 사건을 반복 정리하면서, 내용을 빠뜨리거나 잘못 설명할까 봐 재확인·수정을 반복하는 부담**을 핵심 문제 가설로 둡니다. 어려운 법률·절차 용어는 작성 중 막힐 때 해결하는 보조 문제입니다. 실제 경험에서 이 부담이 얼마나 반복되는지는 인터뷰로 확인합니다.

## 3. 기존 대안 — 이미 무엇이 있는가

- **ECRM:** 공식 신고·상담과 피해 내용 작성 안내를 제공합니다. 비교 대상은 공개 안내를 참고해 사용자가 직접 작성한 준비 결과입니다. [공식 안내](https://ecrm.police.go.kr/minwon/main)
- **더치트·거래 플랫폼:** 더치트의 특정 API는 등록 피해사례 조회를 제공합니다. 플랫폼 신고·안전결제의 상세 지원 범위는 별도 확인합니다. [더치트 API 안내](https://apidocs.thecheat.co.kr/docs/api-usage/api-search-plain/)
- **법률구조공단·범용 LLM:** 무료 상담 경로와 요약·질문 생성 등의 대안입니다. 상담 준비와 재확인에 실제로 어떤 도움이 되는지 비교합니다. [법무부 안내](https://immigration.go.kr/moj/177/subview.do)

## 4. Remaining Pain — 대안을 써도 무엇이 남는가

기존 안내·범용 LLM을 이용한 뒤에도 **자료와 요약을 왕복 확인하고, 빠진 내용과 수정 사항을 반복 반영하는 부담이 남는가**를 검증합니다. 기존 서비스에 자동 구조화 기능이 없다고 단정하지 않으며, 원진술 보존·책임·자료 접근 제약이 현재 방식의 이유인지는 미확인입니다.

## 5. Painkiller — 어떻게 줄일 것인가

사용자는 **기억나는 말로 입력 → 정리 초안 확인 → 필요한 누락만 보완 → 요약·자료 목록·미확인·상담 질문 검토 및 복사** 순서로 이용합니다. 모르는 항목은 남겨두고 진행하며 용어 설명은 필요할 때 엽니다.

**차별화 가설:** 사건 문장을 원래 입력·자료에 연결하고, 상대방 주장·사용자 추측·미확인·충돌을 보존하며, 사용자 수정 내용을 연결된 결과에 일관되게 반영해 반복 작업을 줄입니다. 예를 들어 ‘판매자가 배송했다고 말함’을 ‘실제로 배송됨’으로 바꾸지 않습니다. 이 속성들은 겹칠 수 있으며 법적 사실 확정을 뜻하지 않습니다.

**멀티에이전트:** 계획·조정이 사건 정리·공식 안내 조사·결과 대조 작업을 선택합니다. 정리만 요청하면 조사를 생략하고, 금액 충돌이 나오면 확인 작업을 추가합니다. 자동 대조는 법률 전문가 검토와 구분합니다.

## 6. 미확인 — 다음에 무엇을 검증하는가

11월 20일까지 경험자 2~3명 인터뷰를 목표로 모집하며, 1~2명이라도 확보되면 실제 준비 과정과 기존 대안으로 해결된 점·남은 부담부터 확인합니다. 현재 모집·인터뷰는 미진행입니다. 범용 LLM에도 같은 자료와 출처 연결·미확인 보존·누락 확인 지시를 제공해 비교합니다. **중요 사실 누락·왜곡, 임의 추정, 수정 부담과 자료 찾기부터 검토까지의 총 준비 시간**을 봅니다. 기술은 동일 모델·자료 접근·전체 예산 상한에서 단일·고정·동적 구성을 비교합니다.

수요·차별점·멀티에이전트 효과는 미검증이며, 사실 왜곡을 시간 단축으로 상쇄하지 않습니다. 공식 신고 접수·범죄 판단을 대신하지 않고, 개인정보 취급과 법률 자문·문서 작성의 경계는 전문 검토가 필요합니다. 팀 앱 MVP 전환을 확정한 제안이 아닙니다.

주제 변경은 부동산의 실제 상태는 현장 확인이 중요해 온라인 정리로 해결할 범위가 불확실하다는 두나의 판단에서 출발했습니다. 보유 자료 정리에 집중하는 새 안이 더 효과적인지는 위 검증으로 확인합니다.

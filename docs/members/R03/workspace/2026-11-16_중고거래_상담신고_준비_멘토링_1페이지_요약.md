# 중고거래 상담·신고 준비 자료 정리 제안 요약

R03 두나 · 2026-11-16 · 개인 기획 가설

**흩어진 거래 자료와 사건 경위를 정리하고, 사용자가 확인·수정한 내용으로 처음 상담·신고를 준비하도록 돕는 서비스입니다.**

## 1. 타겟

온라인 중고거래에서 돈을 보냈지만 물품을 받지 못해 처음 상담·신고를 준비하며 거래 경위와 자료 정리에 막힌 사람입니다.

## 2. 문제 정의와 핵심 pain

**온라인 중고거래에서 입금 후 물품을 받지 못한 사람이 처음 상담·신고를 준비하려 하지만, 게시글·대화·이체 자료가 흩어져 있고 필요한 내용을 고르기 어려워 자료를 다시 찾고 사건 경위를 여러 번 고쳐 씁니다.**

문제 가설입니다. 용어 이해는 필요한 순간에 돕는 보조 기능으로 둡니다.

## 3. 기존 대안

- [ECRM·폴봇](https://m.korea.kr/news/policyNewsView.do?newsId=148908906): 2022년 공식 발표에 질문 기반 진술서 자동 작성 지원이 있습니다. 현재 공개 메인에 진입 표시를 확인했으나 브라우저 연결 불가로 실제 생성·수정은 시험하지 못했습니다.
- [더치트 특정 API](https://apidocs.thecheat.co.kr/docs/api-usage/api-search-plain/)는 등록 피해사례 조회를 제공합니다. 플랫폼 신고·안전결제의 상세 대응 범위는 별도 확인합니다.
- ECRM 공개 작성 안내·종이 체크리스트·충분한 지시를 준 범용 LLM도 준비를 도울 수 있습니다.

## 4. 대안을 써도 남는가 — 사용자 장면 가설

‘상담에 필요한 대화·이체 자료를 바로 찾지 못해 다시 찾는다’, ‘처음 적은 날짜·금액과 실제 자료가 달라 내용을 고쳐 설명한다’는 부담이 남는지 확인합니다. 현재 이를 직접 입증하는 실제 경험 근거는 미확보입니다. 폴봇이나 체크리스트·LLM으로 충분하다면 주제를 재검토합니다.

## 5. 핵심 피처 2개

| 피처 | 줄일 pain·전후 행동 | 성공 지표와 기준선 |
|---|---|---|
| 사건·자료 구조화 | 자료를 다시 훑으며 경위 작성 → 입력 원문과 연결된 초안 검토 | 안내만·체크리스트·충분한 지시의 LLM 대비 사실 누락·왜곡·추정 생성 건수 |
| 누락 확인·수정 반영 | 수정한 값을 여러 곳에 재입력 → 관련 요약·질문·자료 연결 갱신 | 수정 후 남은 불일치·재작성 횟수·검토 시간 |

**시작 → 자유 입력 → 초안 보완 → 검토·복사**로 사용합니다. 모르는 내용은 미확인으로 남깁니다. 결과 예: ‘검토한 요약을 복사하세요. ECRM 접수 이후에는 원칙적으로 경찰서 방문·진술 등 후속 절차가 필요합니다.’ [공식 안내](https://ecrm.police.go.kr/minwon/main)

## 6. 비교와 미확인

**대조군:** A. ECRM 공개 안내로 직접 작성 / B. A+체크리스트 / C. 제안 방식. 별도로 같은 자료와 원문 연결·미확인 보존·수정 반영 지시를 준 범용 LLM과 비교합니다.

**현재 점검:** 가상 1건·2턴의 충분한 지시를 준 CLI LLM은 원문 연결·금액 정정·미확인 보존을 수행했습니다. 이 사례에서 서비스의 추가 가치는 확인되지 않았습니다. [원응답·판정](2026-11-16_기존대안_반증점검_결과.md)

**지표:** 중요한 사실 누락·왜곡·없는 사실 추가, 원문 연결, 금액 정정 후 불일치, 자료 찾기부터 검토까지의 총시간·수정 수고를 나눠 기록합니다. 정확성 악화를 시간 단축으로 상쇄하지 않습니다.

**범위:** 가상·비식별 사례 결과는 실제 수요·현실의 준비 부담 감소를 입증하지 않습니다. 공식 신고·법적 판단을 대신하지 않으며 제3자 개인정보·유료 여부·문서 작성 범위의 전문 검토가 필요합니다. 운영은 팀의 무료 웹 시제품 후보이며, 8주 일정·가상 12건·과제 수행자 5~8명은 상세안의 조건부 제안입니다. 기존 대안이 충분하거나 체크리스트 대비 이점이 없으면 축소·중단을 검토합니다. 이는 팀 제품 채택을 의미하지 않습니다.

# 중고거래 ECRM 접수 전 준비 지원 — 멘토 검토 요약

R03 두나 · 2026-11-17 · 개인 기획 구체화 단계, 팀 최종 주제 선정 전

**처음 중고거래 피해 신고를 준비하는 사람이 ECRM 로그인 전에 자료와 사건 경위를 정리해, 검토한 내용을 실제 접수에 활용하도록 돕습니다.**

## 1. 타겟·문제 정의

**타겟:** 입금 후 물품을 받지 못해 처음 ECRM 신고를 준비하는 사람.

**핵심 pain:** 준비가 덜 된 상태로 접수 화면에서 자료를 확인·작성하다 로그인 시간이 끝나면, 다시 본인인증하고 처음부터 입력해야 하는 번거로움입니다. 대화의 반복 수정 부담은 핵심 pain에서 제외하며 용어 이해는 보조 문제입니다.

## 2. 근거와 기존 대안

- **직접 이용 보고:** 두나님은 11/16 남은 시간 표시·만료 후 자동 로그아웃·재인증·처음부터 재입력을 경험했다고 설명했습니다. 이용 화면에 임시저장 기능은 없었고, 별도 연장 안내는 보지 못한 것으로 기억합니다. 단일 자기보고이며 AI 재현·시간 계측은 없습니다. [확인 기록](2026-11-17_ECRM_준비항목_확인과_재인증_불편.md)
- **공개 경험담:** 티켓 피해자의 증빙·상세 작성 과제를 확인했습니다. 사전 작성 후 경찰서 처리가 수월했다는 설명도 함께 인정합니다. 이 글이 재인증 불편의 근거는 아닙니다. [근거](2026-11-17_중고거래_공개경험담_근거_01.md)
- **강한 대안:** [ECRM 공개 메인](https://ecrm.police.go.kr/minwon/main)의 페이지 데이터에는 준비·작성 예시 문구가 있지만 실제 표시 경로·인증 전 접근성은 미확인입니다. 폴봇은 과거 공식 자동 작성 발표가 있으나 현재 실제 동작 미시험입니다. 체크리스트와 충분한 지시의 LLM으로도 준비할 수 있으며, 기존 가상 1건·2턴 LLM이 원문 연결·정정을 수행했습니다. [기존 실행](https://github.com/ik-e/chaja-you/blob/main/docs/members/R03/workspace/2026-11-16_기존대안_반증점검_결과.md)

**남는 질문:** 이 대안들보다 접수 전 준비를 정확하고 적은 수고로 끝낼 수 있는가? 정확한 제한 시간·추가 화면 항목·연장/다른 복원 경로·불편의 일반성은 추가 확인 대상입니다.

## 3. 핵심 피처와 범위

| 피처 | 제공할 결과 |
|---|---|
| 준비자료·사건 경위 정리 | 출처·확인일이 있는 준비 목록, 보유/미보유/모름, 원문 연결 사건 초안 |
| 누락 확인·검토 결과 제공 | 발언자·주장·추측·미확인·충돌 구분, 정정 반영, 검토한 요약·자료 목록 |

**준비 목록 → 자유 입력 → 초안·누락 확인 → 검토·복사 → ECRM 직접 접수.** 사용자가 ‘이체 자료에 12만 원’이라고 설명한 것과 실제 파일 확인을 구분합니다. 모르는 항목도 남긴 채 진행할 수 있습니다.

텍스트·자료 목록을 지원하고 자동 수집·파일 판독·신분증 업로드·인증/세션 대행·자동 입력/접수·법적 판단은 제외합니다. 이후 절차는 공식 ECRM 안내를 따릅니다.

## 4. 구현·비교·중단

**기획 구체화 단계로 비교 테스트와 시제품은 아직 구현하지 않았습니다.** 작성된 비교 자료는 모의 예시와 기존 LLM 기록의 대조이며 실제 수행 시간·누락·화면 이동 측정 결과가 아닙니다. [비교 자료](2026-11-17_공개안내_체크리스트_LLM_준비결과_비교.md)

[안내 접근성 비교표](2026-11-17_ECRM_안내접근성_인증전후_비교.md)로 안내 탐색 경로·인증 전 준비 범위·인증 후 항목을 정리했습니다. 인증 후 신분증 안내는 일부 확인했고 비로그인 안내 경로·전후 차이는 미확인입니다. 준비 결과 비교와 실제 재인증/복원 확인은 별도입니다. 구현 후 같은 과제로 공개 안내만 / 안내+체크리스트 / 충분한 지시의 LLM / 시제품을 비교합니다. **누락·왜곡, 자료 찾기·입력·검토·정정 시간, 화면 이동·재인증·재입력 횟수**를 분리해 봅니다. 정확성 악화를 속도로 상쇄하지 않고, 정정 기능 시험과 재인증 효과 검증을 구분합니다.

대안이 같은 정확성으로 같거나 적은 수고를 제공하면 축소·보류를 제안합니다. 미실행은 미확인으로 남깁니다. 실제 자료·외부 제공 전 개인정보·법률 경계 검토가 필요하며 서비스 효과와 수요는 아직 미검증입니다.

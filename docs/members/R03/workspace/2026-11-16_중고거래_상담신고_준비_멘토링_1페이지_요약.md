# 중고거래 신고 자료·피해 경위 사전 준비 지원 — 멘토용 요약

R03 두나 · 2026-11-20 수정 · 개인 제안 / 기획 구체화, 테스트·시제품 미구현

**사용자가 겪은 일을 편하게 설명하면 준비자료와 피해 경위를 정리해, ECRM 작성과 경찰서 방문 시 설명·작성에 활용하도록 돕습니다.**

## 1. 타깃과 문제 정의

입금 후 물품을 받지 못했고, 신고 의사는 있지만 경험이 없어 자료 준비·피해 경위 작성에서 막힌 사람을 대상으로 합니다.

**문제 정의:** 처음 중고거래 피해를 신고하는 사람은 대화·송금 내역·기억에 흩어진 정보를 바탕으로 무엇을 준비하고 어떤 순서로 피해 사실을 작성해야 할지 몰라 신고 준비에 어려움을 겪을 수 있습니다.

**핵심 pain은 ‘거래 자료와 기억을 신고에 필요한 자료와 글로 준비하는 방법을 모름’입니다.** 자료 준비·글 작성은 하위 작업, 경찰서에서의 긴장은 어려움이 커질 수 있는 사용 상황, 시간 절약은 검증할 효과입니다. 긴장과 초안의 도움은 미검증 가설이며, 재인증·재입력은 별도로 관찰할 추가 부담입니다. 다만 공개 후기 30건 확인에서는 이 pain을 직접 지지하는 글이 적어(경위 작성 어려움 1건), 후기를 보강한 뒤 핵심 pain 유지 여부를 다시 판단합니다.

| 근거 | 확인 범위·수준 |
|---|---|
| 두나님의 ECRM 이용 | 남은 시간 만료·로그아웃·재인증·재입력, 이용 화면의 임시저장 부재를 보고. 경로 1건의 자기보고이며 원인·시간·다른 복원 경로·빈도 미확인. [기록](2026-11-17_ECRM_준비항목_확인과_재인증_불편.md) |
| 준비 안내·폴봇 이용 | 비로그인 안내 미발견과 폴봇의 신고 종류 질문 반복을 보고. 사이트 전체 안내 부재로 확정하지 않음. [비교](2026-11-17_ECRM_안내접근성_인증전후_비교.md) |
| 반대 근거 | 공개 경험담은 사전 작성의 효용을 설명하고 기존 LLM도 가상 1건·2턴의 원문 연결·정정을 수행. 서비스 추가 가치 미검증. [기록](https://github.com/ik-e/chaja-you/blob/main/docs/members/R03/workspace/2026-11-16_기존대안_반증점검_결과.md) |
| 공개 후기 30건 분류 | 원문 확인 23건 중 방문 여부·이관·담당자·후속 절차 언급 13건, 경위 작성 어려움 1건(AI로 해소), 중고거래 본인 후기 5건 중 2건은 수월. 7건 접속 실패로 보류. 질문 글 비중이 높고 임의 수집이라 빈도·우선순위 근거는 아님. [분류](2026-11-20_ECRM_공개후기_30건_분류.md) |

## 2. 기존 대안과 남는 문제

**확인한 사실:** 공식 안내에 자료 첨부·피해 경위 작성·방문 전 서류 작성 지원이 있고, 공개 후기에는 원활한 사전 작성 사례와 방문·이관 혼선 사례가 있습니다. [추가 후기와 해석 범위는 상세 기획안 §3](2026-11-16_생활법률_고소준비_지원_서비스_기획_초안.md)을 참고합니다.

**후기 30건에서 관찰된 점:** 확인한 글에서는 준비·작성 단계보다 접수 이후 절차(방문 시점·사건 이관·담당자 연락)의 혼선이 더 자주 나타났습니다. 핵심 pain을 준비·작성에 둘지 접수 이후 안내로 옮길지는 후기 보강 후 판단합니다.

**남은 가설:** 초보 사용자가 준비·작성 중 얼마나 막히는지, 제안 서비스가 기존 대안보다 시간·수정 수고와 누락·오류를 줄이는지는 미검증입니다. 방문 시 긴장 완화, 시간 절감, 재인증 감소도 확인된 효과가 아닙니다. 시간 변화는 수치를 정하지 않고 측정하며, 증거 수집 포함 온라인 작성이 약 15분에 끝난 공개 후기(Re-View)도 있어 이미 빠른 사용자에게는 줄일 시간이 적을 수 있습니다.

| 대안 | 이미 가능한 것 | 남을 수 있는 문제 — 가설 |
|---|---|---|
| 메모장 미리 작성 | 내용 보관·재입력 참고 | 무엇을 준비·작성할지 스스로 선정 |
| 체크리스트+메모장 | 항목 확인·직접 경위 작성 | 대화에서 경위를 만들고 값 차이를 대조하는 수고 |
| 충분한 지시의 LLM | 요약·질문·원문 연결·정정 | 지시 작성·추가 질문·결과 점검 수고 |
| ECRM | 방문 전 민원서류 작성 지원·피해 내용 작성 안내 | 안내를 자기 사건에 적용해 준비를 마치는 어려움이 남는지 확인 필요 |

**차별화 가설:** 준비 항목과 자유 설명의 정리를 한 흐름으로 제공하면 초안을 만들고 검토하는 수고, 이후 설명·작성 부담을 더 줄일 수 있는가? 사전 작성 자체는 기존 대안도 지원하므로 추가 가치를 비교합니다.

## 3. 핵심 피처 2개와 이용 흐름

아래 “무엇을 준비하나요?”, “어떻게 적나요?”는 기능을 설명하기 위해 구성한 예상 질문이며, 실제 사용자 발언이나 질문 빈도 조사 결과가 아닙니다.

| 피처 | 결과 |
|---|---|
| 준비자료·피해 경위 정리 | “무엇을 준비하나요?”에 자료·확보 경로·보유 상태 안내. “어떻게 적나요?”에 자유 설명을 확인 가능한 시간순으로 정리한 원문 연결 초안 제공 |
| 누락 확인·검토 결과 제공 | 발언자·주장·충돌·미확인 구분과 정정 반영 → 사용자가 확인한 피해 경위 초안·자료 목록·추가 확인 사항 |

**자료 준비·자유 설명 → 초안·누락 검토 → 복사 → ECRM 직접 작성·첨부 → 방문 안내 확인 → 필요한 방문 시 초안을 참고해 설명·작성·보완.**

접수 후 안내받은 방문 필요 여부·기한·준비물을 확인하도록 돕습니다. ‘2주 이내 방문’을 일률적으로 안내하거나, 모두 경찰서에서 진술서를 처음부터 다시 쓴다고 가정하지 않습니다. [ECRM 공식 안내](https://ecrm.police.go.kr/minwon/main) (11/20 확인)

첫 시제품은 텍스트 입력입니다. 판매자 주장·사용자 설명·미확인을 구분하며 없는 사실을 채우지 않습니다. 실제 파일 판독·자동 수집·신분증 업로드·인증/세션 대행·자동 접수·법적 판단은 제외합니다.

## 4. 다음 검증 2개

**핵심 질문:** 공식 안내와 메모장만 사용하는 경우보다 필요한 자료를 준비하고 정확한 피해 경위 글을 완성하는 수고가 줄어드는가?

1. **준비·작성 과제 비교:** 같은 가상 사건으로 공식 안내+메모장 / 체크리스트+메모장 / 충분한 지시의 LLM / 구현 후 시제품을 비교합니다. 준비·작성·검토 시간, 누락·오류·미확인 보존과 사용자가 느낀 어려움을 기록합니다. 모의 과제로 실제 경찰서에서의 긴장 감소를 입증했다고 해석하지 않습니다.
2. **실제 경로·효과 확인:** 안내 접근 경로·인증 후 추가 항목·만료/복원 동작과 실제 안내받은 방문 절차를 확인합니다. 인증 후 입력·첨부 시간, 재인증·재입력, 방문 시 초안의 실제 활용 방식과 설명·작성 부담은 각각 확인하며 미시험 구간은 미확인으로 남깁니다.

시간 절약과 설명·작성 부담 감소는 미검증 가설이며, 사전 준비를 합친 총시간도 평가합니다. 기존 대안이 같은 정확성으로 같거나 적은 수고를 제공하면 축소·보류합니다. 비교 자료는 모의 예시와 이전 LLM 실행의 대조이며 동일 조건 실측·시제품·실제 방문 효과 검증은 미완료입니다.

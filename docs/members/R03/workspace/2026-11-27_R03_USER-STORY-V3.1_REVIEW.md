### R03-V31-01. 내부 연결 결과 불명 후 재접속 및 복귀 경로

**관련 ID:** UJ-06 · UJ-12 · LINKACK · VE-035~037 · VE-097~098 · ER-14 · SC-S07

#### 발견한 문제

사용자가 직접 등록한 기존 외부 게시물을 찾아you의 원본과 연결하도록 요청했으나 응답을 받지 못한 상태에서 서비스를 이탈한 경우, 재접속 후 기존 **내부 연결 명령의 동일 키**로 결과를 확인하는 전용 흐름이 명시적으로 연결되어 있지 않다.

SC-S07은 동일 키 조회 중심이며 이탈·재접속까지의 연결은 구체화되지 않았다. |

따라서 기존 동일 키 확인 원칙을 다시 제안하는 것이 아니라, **해당 원칙이 화면 이탈 후에도 적용되는 사용자 복귀 경로**를 명시하자는 의견이다. 일반적인 화면 이동·인증 복귀 규칙은 이미 존재한다.

#### 권장 개선 방향

- H에서 보존된 내부 연결 불명 기록을 확인하고, 필요 시 정확한 기존 요청을 다시 열 수 있게 한다.
- 동일 owner·원본·외부 객체·기존 내부 연결 명령 ID로 결과를 확인한다. 내부 연결과 외부 업무 수락의 상태 및 ID를 혼용하지 않는다.
- 기존 연결이 확인되면 H에 관리 관계를 표시한다. 계속 불명이면 보류하고 새 연결을 생성하지 않는다.
- 확정 거절 또는 권위 있는 미커밋 및 이전 지연 커밋 봉쇄 확인 후에만 현재 조건에서 사용자의 새 명시적 연결 요청을 허용한다.

**제안 흐름:** W(연결 요청) → 연결 결과 불명 → 안전 이탈 → 재접속 및 동일 owner 확인 → H(기존 연결 기록 확인) → 동일 내부 명령 결과 조회 → 연결 확인 또는 불명 유지

#### 검증 기준 (추가 제안)

| 입력 상황 | 기대 결과 |
| --- | --- |
| 연결 저장 성공 후 응답 유실, 재접속 | 기존 관계 1건 표시, 새 연결 생성 0건 |
| 연결 결과가 계속 불명 | 동일 키 확인만 수행, 중복 연결 0건, 외부 쓰기 0건 |
| 거절 또는 미커밋·지연 봉쇄 확정 | 정확한 새 의도가 있을 때만 새 연결 준비 가능 |

### R03-V31-02. 최초·추가 등록 이후 심사 반려 대응 흐름

**관련 ID:** UJ-01 · UJ-02 · UJ-03 · UJ-05 · UJ-08 · ER-20 · PS-PL01/02-RESPOND

#### 발견한 문제

신규 또는 추가 등록이 심사 접수까지 정상 완료된 뒤, 강사가 나중에 최신 상태를 조회하여 반려를 확인했을 때의 후속 행동이 해당 사용자 여정에 직접 연결되어 있지 않다. 반려 대응 원칙 자체는 존재하지만, 실제 사용자가 어디에서 대응을 시작하고 어떤 조건에서 수정 업무로 넘어가는지 명확히 할 필요가 있다.

이 의견은 신규 재등록 기능을 추가하자는 것이 아니다. 이미 정의된 ER-20 및 RESPOND → UPDATE의 의미를 **최초·추가 등록 이후의 반복 이용 흐름에 연결**하자는 제안이다.

#### 권장 개선 방향

- R에서 반려 상태가 관측된 경우, 확인된 반려 사유 또는 사유 미확인 및 가능한 조치를 제공한다.
- 강사가 수정 대응을 선택하면 지원·권한·정확 객체·현재 상태 및 경합 여부를 확인한다. 수정이 허용되는 경우에만 UJ-03의 W로 연결한다.
- 강사는 필요한 항목만 수정·검토하고 변경 내용 및 실행 범위를 새로 승인한다.
- R에서 동일 기존 객체의 승인 변경 및 필요한 재심사 접수 여부를 확인한다. 기존 등록·접수 완료 이력은 보존한다.
- 심사 중 수정 불가, 사유 불명, 권한 미확인, 기존 객체 불명인 경우에는 안내·허용 조회 또는 보류만 제공한다.

**제안 흐름:** H(기존 레슨) → R(최신 조회 및 반려 확인) → 대응 방법 확인 → W(지원되는 기존 객체 수정 준비·새 승인) → R(수정 결과 및 재심사 접수 여부 확인)

#### 검증 기준 (추가 제안)

| 입력 상황 | 기대 결과 |
| --- | --- |
| 신규 등록 심사 접수 확인 후 반려 관측 | 과거 접수 완료와 현재 반려 상태를 별도 표시 |
| 반려 사유 확인, 동일 객체의 수정 허용 | 필요한 값만 수정·새 승인 후 동일 객체 변경 및 필요한 재접수 확인 |
| 수정 불허 또는 이전 효과 불명 | 안내 또는 보류, 임의 수정·신규 객체 생성·재등록 0건 |
| 재심사 접수만 확인 | 접수 완료로 표시, 심사 승인 및 모집 가능은 별도 판정 |

#### 권장 개선 방향

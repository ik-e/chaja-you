# ECRM 안내 접근성·인증 전후 준비 항목 비교

R03 두나 · 2026-11-17 · TASK-018 개인 기획 근거 정리

**현재는 인증 전후의 차이를 모두 검증한 상태가 아니다.** 기존 화면 공유와 사용자 보고를 비교표로 정리했다. 새 인증·접수·시간 만료 시험을 수행하지 않았으며 테스트·시제품은 미구현이다. [구조화 기록](2026-11-17_ECRM_안내접근성_인증전후_비교.json)

## 1. 세 가지 질문의 비교

| 비교 질문 | 확인한 내용 | 미확인·판단 |
|---|---|---|
| ① 처음 이용자가 준비 안내를 찾는가 | 메인에서 신고하기→절차 팝업을 보는 사용자 흐름을 공유받음. 이후 이미 인증했다고 설명함 | 비로그인으로 준비 안내에 도달하는 경로는 미확인. 경험 있는 사용자 1명의 화면이지 최초 이용자 성공률 시험이 아님 |
| ② 인증 전 무엇을 준비할 수 있는가 | 메인 페이지 데이터에 증빙·작성 요소·예시 문구가 있음 | 실제 화면 표시 경로·인증 전 접근성 미확인. 문구만으로 준비 가능 항목 확정 불가 |
| ③ 인증 후 추가 항목은 무엇인가 | 사전 인증 후 긴급사안 질문, 02 증거자료 첨부의 신분증 안내 팝업 관찰 | 신분증 안내를 인증 후에 확인했지만 인증 후에만 제공된다고 입증한 것은 아님. 다른 단계·파일조건도 추가 확인 필요 |

## 2. 공유 화면으로 확인한 경로

| 순서 | 화면·관찰 | 인증 상태·근거 범위 |
|---|---|---|
| 1 | 신고하기 뒤 온라인 임시접수→경찰서 정식접수→조사 팝업 | 사용자가 이후 사전 인증했다고 설명. 인증 전 화면 근거로 사용하지 않음 |
| 2 | 긴급사안 여부 질문, 신고시스템 접수/112 선택 버튼 | 사전 인증 후 공유 화면 |
| 3 | 02 증거자료 첨부, 신분증 필수 업로드 팝업 | 사전 인증 후 공유 화면. 중간 범죄유형 선택 조작은 전체 공유되지 않아 추정하지 않음 |

신분증 팝업에는 주민등록증·운전면허증·외국인등록증·여권·주민등록등본이 표시되고 학생증 등 기타 신분증 불가라고 안내됐다. 화면의 관찰 내용이며 해당 목록의 모든 항목을 업로드해 시험한 것은 아니다. 실제 신분증은 우리 서비스에 업로드하지 않는다.

화면 뒤 가려진 글씨에서 용량·사진 크기의 전체 조건을 추정하지 않는다. 전체 첨부 단계·인적사항·내용입력·제출을 확인한 것으로 표시하지 않는다. 원본 스크린샷·식별정보는 공개 저장소에 복사하지 않았다.

## 3. 준비 체크리스트에 지금 넣을 수 있는 수준

| 항목 | 근거 종류 | 지금의 표시 |
|---|---|---|
| 본인 신분증 준비 | 인증 후 화면에서 필수 첨부 안내 관찰 | 관찰된 준비 항목. 허용 목록은 위 화면 기준 |
| 이체·대화 등 증빙 | 공식 페이지 데이터·사용자 제공 블로그 설명 | 준비 후보. 인증 전 표시 경로와 실제 화면의 필수 여부·전체 조건은 별도 확인 |
| 피해 경위·일시·장소·상대방·신고 이유 | 공식 페이지 데이터·블로그 설명 | 작성 준비 후보. 실제 접수 필수값 전체를 확인한 목록 아님 |
| 파일 형식·용량·사진 크기 | 전체 조건을 읽은 화면 미확보 | 미확인. 숫자 임의 기재 금지 |
| 임시저장·재인증 후 복원 | 이용자는 저장 기능 없이 재인증 후 재입력했다고 보고 | 해당 이용 경로의 자기보고. 모든 화면·다른 복원 경로 부재를 확정하지 않음 |

[공식 메인](https://ecrm.police.go.kr/minwon/main)의 안내 문구 확인과 실제 화면 접근성은 구분한다. [블로그](https://blog.naver.com/goskfk74/224395719699)는 접수 과정 이해의 참고이며 현재 전체 규격의 공식 근거는 아니다.

## 4. 앞으로 확인할 순서

1. 비로그인 상태에서 시작해 준비 안내를 여는 실제 버튼·메뉴·화면을 기록한다. 못 찾으면 탐색한 범위와 결과를 남긴다.
2. 인증 전에 실제 볼 수 있었던 항목만 목록으로 만든다. 페이지 데이터만 읽힌 문구는 따로 둔다.
3. 사용자가 허용한 실제 이용 범위에서 인증 후 항목과 맞대고 동일/추가/미확인으로 표시한다. 신분증 등 실제 자료 수집이나 허위 신고 제출을 요구하지 않는다.
4. 그 결과로 고정한 체크리스트와 가상 사건 비교 과제를 작성한다. 안내문을 추출해 제공한 조건은 실제 사이트 탐색 조건과 구분한다.

인증 전 안내가 안 보였다는 관찰만으로 기능이 없다고 확정하지 않고, 공식 안내·교차 검토와 대조한다. 반대로 페이지 문구만으로 처음 이용자가 쉽게 찾을 수 있다고 판단하지 않는다.

## 5. 세 검증은 분리

| 검증 | 남길 결과 | 현재 상태 |

| 준비 결과 품질 | 동일 가상 자료에서 누락·왜곡·주장/미확인 구분·입력/검토 시간 | 설명용 비교 자료만 있음. 동일 조건 테스트·시제품 미구현 |
| 실제 재인증 효과 | 실제 만료·재인증·복원 동작, 준비 지원 전후의 횟수·시간 | 사용자 사후 보고 1건. AI 재현·개선효과 측정 없음 |

## 이번에 고친 핵심

- 자료가 흩어졌다는 이유로 우리 기능이 자동 수집 부담까지 해결한다고 읽히지 않게 범위 한정.
- LLM이 이미 원문 연결·정정·미확인 보존을 수행했음을 유지. 원문 ID 존재만으로 의미 정확성을 통과 처리하지 않음.
- 기존 10만 원 진술은 이력에 보존하고 현재값은 12만 원으로 갱신하는 정정 판정 구체화.
- 모델명이 미확인인 CLI 1회 결과를 동등 모델 성능 기준선으로 재사용하지 않음.
- 12건/5~8명은 후속 조건부 계획이며 지금 최소 점검은 기존 1건. 구현 착수와 모집을 자동 지시하지 않음.

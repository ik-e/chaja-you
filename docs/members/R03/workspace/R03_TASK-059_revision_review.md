## 4. 범위 및 중복 수정

- US-072, US-073: §9.5의 원본 삭제/관리 연결 해제 요청 명시 → base 후보. 실제 보존/삭제·권한 정책은 미결정.
- US-069: 별도 사용자 요청 방식은 undecided 유지, SE-018/022에서 재실행 전 외부 효과 확인은 필수 안전 원칙.
- US-022: 인증 실패 대상 제외를 분기로 재사용. US-023: 최종 입력안 검토도 포함. US-094/095: 세션 파기 의도를 종료·철회와 연계. 중복 신규 ID 미생성.
- US-106~108은 별도 실행 요청이 채택될 때만 적용; 승인으로 의사를 처리할 수 있음.

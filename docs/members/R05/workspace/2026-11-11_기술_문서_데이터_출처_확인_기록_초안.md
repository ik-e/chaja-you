## 4. 현재 판단

공개된 상품 페이지를 **사람이 열어 시연 자료를 조사할 수 있다는 점**은 확인했다. 하지만 **백엔드가 매물을 자동으로 가져와 저장하고 보고서에 재사용해도 되는지**는 아직 확인되지 않았다. 따라서 중고나라 자동 연동을 확정된 구현 방식으로 적지 않는다.

다음에는 데이터 이용 조건을 확인하고, 실제 시연 방식을 **공식 API 사용**, **허용 조건을 확인한 공개 데이터 사용**, **시연용 예시 데이터 사용** 중에서 팀과 정한다.

이 문서는 **자료를 어디에서 봤는지와 어디까지 확인했는지**를 남기는 기록이다. 기술 선택이나 데이터 이용 허가를 확정하는 문서는 아니다.

# 레슨 공고 등록 플랫폼별 입력 뼈대 (크몽·탈잉·숨고)

2026-11-24 · R05 임다혁

## 요약

크몽·탈잉은 필수 항목만 채우면 심사 제출까지 갈 수 있고, 숨고는 게시글이 없어 프로필과 견적으로 나눠 뼈대를 만들어야 합니다. 세 플랫폼 모두 실제 작성 화면을 열어 보컬 레슨 예시로 제출 직전까지 채우며 필수·선택을 확인했습니다.

- **크몽**: 서비스 등록 양식. 필수를 다 채우면 제출(심사) 가능. 예시는 임시 저장 상태.
- **탈잉**: 튜터 기본 정보 3개를 먼저 채운 뒤 클래스를 만들 수 있음. 필수 탭 4개를 채우면 "심사 제출하기"가 활성화됨. 예시는 임시 저장 상태.
- **숨고**: 심사·제출이 없고 프로필은 저장 즉시 공개됨. 고객 요청서에 견적을 보내는 구조라 "필수만 채우면 게시"가 성립하지 않음.
- **당근**: 웹에서 로그인·작성이 불가능해 대상에서 제외.

표기: 화면에서 직접 확인하지 못한 항목은 "미확인"으로 적었습니다.

## 1. 크몽 — 서비스 등록 (제출 시 심사)

선행 조건은 전문가 인증입니다. 취소·환불 규정은 자동으로 적용됩니다.

### 필수

| 단계 | 항목 | 규칙 |
| --- | --- | --- |
| 기본 정보 | 제목 | 10–30자, 특수문자는 `+ - # / . ( )` 만 |
| 기본 정보 | 카테고리 | 3단계 (예: 취미 레슨 > 보컬·랩 레슨 > 보컬 레슨) |
| 상세 정보 | 서비스 설명 | 100자 이상, `<` 와 백틱(`` ` ``) 사용 불가 |
| 상세 정보 | 모집 형태 | 개인레슨 / 그룹교육 / 기업강의 |
| 상세 정보 | 메인 이미지 | 652×488, PNG·JPG, 1–4장 |
| 상세 정보 | 서비스 제공 절차 | 50자 이상 |
| 상세 정보 | 의뢰인 준비사항 | 50자 이상 |
| 상세 정보 | 지역 | 온라인/오프라인. 오프라인이면 지역·상세 지역·상세주소 |
| 가격 정보 (패키지별) | 제목 / 설명 | 20자 이하 / 60자 이하 |
| 가격 정보 (패키지별) | 금액 | VAT 포함 |
| 가격 정보 (패키지별) | 작업 기간 / 수정 횟수 | 드롭다운 (일 / 회) |
| 가격 정보 (패키지별) | 1회당 레슨시간 / 레슨 횟수 | 드롭다운 (분 / 회) |

패키지는 STANDARD·DELUXE·PREMIUM 3개입니다. "패키지로 설정" 토글을 끄면 단일 가격이 되는지는 미확인입니다.

### 선택

| 단계 | 항목 | 규칙 |
| --- | --- | --- |
| 상세 정보 | 상세 이미지 | 0–9장, 가로 652–2000px, 세로 3000px 이하, PNG·JPG·GIF |
| 상세 정보 | 동영상 | 0–6개, MP4, 합계 500MB 이하 |
| 상세 정보 | 지역 "상호 협의 가능" | 토글 |
| 가격 정보 | 준비물 제공 포함 / 강의실 제공 포함 | 패키지별 체크박스 |
| 추가 가격 | 빠른 작업, 추가 수정, 레슨 시간 추가, 레슨 횟수 추가, 준비물 제공 비용, 강의실 제공, 맞춤 옵션 | 항목별 추가 |
| 판매 핵심 정보 | 검색 키워드 | 최대 5개, 각 20자 이하 |
| 판매 핵심 정보 | 자주 묻는 질문 | 최대 50개 |
| 판매 핵심 정보 | 작업 전 요청사항 | 추가형 |
| 추가 정보 | 대상자 / 서비스 내용 / 준비물 | 각 최대 4개 |
| 추가 정보 | 커리큘럼 / 가능일 | 추가형 |

## 2. 탈잉 — 오프라인 클래스 (제출 시 심사)

일반 튜터 경로(탈잉 스튜디오 → 클래스 만들기)로 올릴 수 있고, 탈잉 파트너스 등록은 필요 없습니다. 파트너스는 탈잉이 강사를 선발해 촬영·마케팅을 함께 하는 별도 프로그램입니다.

선행 조건(튜터 기본 정보)은 프로필 이미지, 전화번호 인증, 튜터 소개입니다. 하나라도 비어 있으면 클래스 만들기가 막힙니다.

### 필수

| 단계 | 항목 | 규칙 |
| --- | --- | --- |
| 클래스 생성 팝업 | 운영 방식 | 오프라인 / 멤버십 / VOD / 전자책 |
| 기본 정보 | 카테고리 | 2단계 (예: 취미·문화 > 보컬·작곡·악기) |
| 기본 정보 | 클래스명 | 10–30자, 한글·영문·숫자·`, . -`·공백만 |
| 기본 정보 | 썸네일 | 1–10장(대표 필수), jpg·jpeg·png, 10MB 이하, 1280×720 권장. 홍보 문구·프로필과 같은 사진은 반려 |
| 기본 정보 | 클래스 대상 | 50–500자 |
| 클래스 소개 | 상세 소개 | 에디터(이미지 가능), 연락처·외부 URL 금지 |
| 회차·커리큘럼 | 회차 수 | 1 = 원데이, 2–30 = 다회차. 심사 후 변경 불가 |
| 회차·커리큘럼 | 회차별 커리큘럼 | 각 50–500자 |
| 인원·수강료 | 참여 인원 | 1:1 또는 그룹(2–50인) |
| 인원·수강료 | 시간당 가격 | VAT 포함 |
| 인원·수강료 | 1회당 시간 | 1시간 단위 |
| 심사 제출 시 | 정산 계좌 | 은행, 계좌번호, 예금주, 주민번호 (강사 본인이 직접 입력) |

최종 수강료는 시간당 가격 × 1회당 시간 × 회차 수로 자동 계산되고, 최소 5,000원입니다.

### 선택

| 단계 | 항목 | 규칙 |
| --- | --- | --- |
| 튜터 프로필 | 이력(권장), 소셜 미디어, 클래스 장소 | 이력은 공인 증빙 자료 첨부 |
| 클래스 소개 | 클래스 요약 | 200자 이하 |
| 회차·커리큘럼 | 회차별 이미지 | 10MB 이하 |
| 기타 설정 | 승인 메시지 | 500자 이하 |
| 기타 설정 | 태그 | 최대 10개 |
| 기타 설정 | 영상 | 유튜브 링크 최대 5개 |
| 공지사항 | 클래스 공지사항 | 1000자 이하 |

일정·장소 탭은 클래스가 오픈 상태일 때만 쓸 수 있습니다.

## 3. 숨고 — 고수 프로필과 견적 (심사 없음, 저장 즉시 공개)

숨고는 강사가 글을 올리는 구조가 아닙니다. 고객이 요청서를 쓰면 고수가 견적을 보내므로, 뼈대를 프로필과 견적 두 가지로 나눕니다.

### 필수

| 단계 | 항목 | 규칙 |
| --- | --- | --- |
| 고수 가입 | 제공 서비스 | 분야 선택 (예: 보컬 레슨, 랩 레슨) |
| 고수 가입 | 활동 지역 | 주소 기준 |
| 고수 가입 | 이동 가능 범위 | km 단위 |
| 스마트견적 사용 시 | 휴대폰 본인인증 | 강사 본인이 직접 |
| 필수인증 서비스일 때 | 사업자등록증 또는 자격증 | 보컬 레슨 해당 여부 미확인 |

### 선택 (프로필 완성도 %에 반영)

| 단계 | 항목 | 규칙 |
| --- | --- | --- |
| 기본 정보 | 프로필 이미지 | — |
| 기본 정보 | 한 줄 소개 | 80자 이하 |
| 기본 정보 | 대표 서비스 | 제공 서비스 중 1개 |
| 내 소개 편집 | 활동명, 연락 가능 시간, 직원수, 링크 | 활동명 30자 이하 |
| 전문성 | 서비스 상세설명 | 30자 이상, 200자 이상 권장, 연락처·이메일 금지 |
| 전문성 | 경력, 학력, 사진·동영상, 포트폴리오, 질문답변 | 포트폴리오는 등록 후 검수 |
| 신뢰도 | 본인인증, 결제수단, 숨고페이 정산정보, 리뷰 | — |
| 기타 | 세금계산서 발행 | — |

### 견적

- **스마트견적(자동 견적)**: 서비스 1개 선택 후 본인인증 단계까지 확인했습니다. 이후 입력 항목은 미확인입니다.
- **일반 견적**: 고객 요청서가 들어와야 금액과 설명을 써서 보낼 수 있고, 보낼 때 캐시가 차감됩니다. 작성 화면은 미확인입니다.

## 4. 공통 뼈대 → 플랫폼별 변환

강사는 공통 항목을 한 번만 입력하고, 플랫폼별 규칙에 맞게 자동 변환하는 구조를 제안합니다.

| 공통 항목 | 크몽 | 탈잉 | 숨고 |
| --- | --- | --- | --- |
| 제목 | 제목 (`( ) /` 허용) | 클래스명 (`( ) /` 금지, 지역명·1:1 표현 지양) | 한 줄 소개 |
| 분야 | 카테고리 3단계 | 카테고리 2단계 | 제공 서비스·대표 서비스 |
| 소개글 | 서비스 설명 | 상세 소개 + 튜터 소개 | 서비스 상세설명 |
| 대상 | 추가 정보 > 대상자(선택) | 클래스 대상(필수) | 상세설명에 포함 |
| 진행 방식·지역 | 모집 형태 + 지역 | 참여 인원(1:1/그룹), 장소는 오픈 후 | 활동 지역 + 이동 범위 |
| 단계(커리큘럼) | 패키지 설명·제공 절차 | 회차별 커리큘럼 | 상세설명에 포함 |
| 가격 | 패키지 3개 총액 | 시간당 가격 × 시간 × 회차 | 견적 금액 |
| 회당 시간·횟수 | 패키지별 드롭다운 | 1회당 시간(1시간 단위)·회차 수 | 상세설명에 포함 |
| 이미지 | 652×488, 글자 허용 | 1280×720, 홍보 문구 금지 | 프로필 이미지·포트폴리오 |
| 키워드 | 검색 키워드 최대 5개 | 태그 최대 10개 | — |

변환할 때 지켜야 할 규칙입니다.

- **가격 통일**: 탈잉은 다른 플랫폼과 같은 수강료를 요구합니다. 예시에서는 크몽 PREMIUM(6회 × 2시간, 15만원)과 탈잉(시간당 12,500원 × 2시간 × 6회)을 맞췄습니다.
- **연락처·외부 URL 금지**: 탈잉 소개·공지, 숨고 상세설명·포트폴리오 모두 해당합니다.
- **이미지 2종**: 글자 있는 버전(크몽)과 글자 없는 버전(탈잉)을 따로 만듭니다.

## 5. 미확인 항목과 테스트 상태

### 테스트로 작성한 글 (R05 개인 계정)

| 플랫폼 | 상태 | 비고 |
| --- | --- | --- |
| 크몽 | 임시 저장 | 제출 안 함 |
| 탈잉 | 임시 저장 | 제출 안 함 (정산 계좌 단계에서 취소) |
| 숨고 | 프로필 공개 (완성도 30%) | 한 줄 소개·대표 서비스·상세설명만 입력 |

### 아직 확인하지 못한 것

- [ ] 크몽: "패키지로 설정"을 끄면 단일 가격 입력으로 바뀌는지
- [ ] 탈잉: 실제 사진이 아닌 그림 썸네일이 심사를 통과하는지
- [ ] 숨고: 본인인증 뒤 스마트견적 설정 항목 (가격, 세부사항 등)
- [ ] 숨고: 일반 견적 작성 화면 (요청서가 들어와야 열림)
- [ ] 숨고: 보컬 레슨이 필수인증 서비스인지

### 자동 등록 관련 참고

탈잉 이용약관에 회사가 승인하지 않은 시스템으로 접속해 수업을 자동 등록할 수 없다는 조항이 있습니다([탈잉 이용약관](https://talingrules.oopy.io/13f41f37-bd7f-8042-8095-c96d76b10a85)). 크몽과 마찬가지로 운영사 문의가 필요합니다.

# 프로젝트 아이디어 3가지 — 팀원 공유용

세 아이디어를 타깃 사용자, 페인 포인트, 문제 정의, 핵심 기능을 기준으로 정리했습니다. 사용자 불편과 기대 효과는 아직 인터뷰나 실험으로 확인하지 않은 **기획 가설**입니다.

## 한눈에 비교

## 1. AI 술집 주문 도우미

**한 줄 소개:** 손님이 대화하듯 메뉴를 추천받고 주문하며, 매장은 반복적인 주문 접수와 메뉴 안내를 보조받는 서비스.

### 타깃 사용자

- 메뉴 선택과 추가 주문을 편하게 하고 싶은 술집 손님
- 바쁜 시간에 여러 테이블의 주문과 메뉴 질문을 처리하는 소규모 술집 직원·사장님

### 페인 포인트

- 손님은 메뉴판만으로 음식의 특징을 알기 어렵고, 무엇을 주문할지 고민한다.
- 추가 주문이나 현재 금액을 확인할 때 직원을 불러야 하는 것이 번거로울 수 있다.
- 직원은 바쁜 시간에 주문 접수와 비슷한 메뉴 질문을 반복해서 처리한다.

### 문제 정의

> 손님이 메뉴를 선택하고 주문을 확인하는 과정을 편하게 만들면서, 매장의 반복적인 주문 안내를 정확하게 보조하려면 어떻게 해야 할까?

### 코어 피처

1. **대화형 메뉴 안내:** 음성 또는 텍스트로 메뉴와 가격을 질문한다.
2. **맞춤 메뉴 추천:** 인원수·예산·선호를 바탕으로 등록된 메뉴를 추천한다.
3. **자연어 주문:** “먹태 하나, 소주 두 병”처럼 말하거나 입력한다.
4. **주문 확인과 수정:** 인식된 메뉴와 수량을 손님이 확인한 뒤 확정한다.
5. **누적 금액 확인:** 확정된 주문 내역과 현재 금액을 보여준다.

**첫 MVP:** 가상 매장 한 곳에서 메뉴 추천 → 모의 주문 → 주문 확인 → 금액 표시까지 시연한다. 음성 입력은 가능 범위를 확인해 추가한다. 메뉴판 사진 인식, 실제 POS·결제 연동, 귀가 방법 안내는 후속 확장으로 둔다.

**검증할 점:** 매장에 반복 응대 문제가 실제로 있는지, 주문을 정확하게 인식하는지, 소음 환경에서도 사용할 수 있는지 확인한다. 인력 감축 효과는 아직 검증되지 않았다.

## 2. 기억 단서로 작품 찾기

**한 줄 소개:** 제목은 몰라도 기억나는 장면·대사·가사·시대·분위기를 바탕으로 영화, 드라마, 음악을 찾아주는 서비스.

### 타깃 사용자

- 예전에 본 영화나 드라마의 제목은 모르지만 장면이나 인물은 기억하는 사람
- 가사 일부나 곡의 분위기는 기억하지만 제목과 가수를 모르는 사람

### 페인 포인트

- 기억이 불완전해 어떤 검색어를 입력해야 할지 막막하다.
- 비슷한 검색 결과가 많아 찾는 작품인지 하나씩 확인해야 한다.
- AI가 작품을 제시해도 그 후보를 추천한 이유가 분명하지 않을 수 있다.

### 문제 정의

> 제목이나 정확한 문장 대신 불완전하거나 일부 틀릴 수 있는 기억만으로, 사용자가 찾는 작품의 후보를 좁히고 직접 확인할 수 있게 하려면 어떻게 해야 할까?

### 코어 피처

1. **자연어 입력:** 기억나는 장면, 대사, 시대, 분위기 등을 자유롭게 입력한다.
2. **추가 질문:** 작품 종류나 기억나는 인물 등 후보를 좁히는 정보를 묻는다.
3. **후보 작품 제시:** 작품명과 기본 정보를 보여준다.
4. **단서별 확인:** 기억과 일치하는 내용, 확인하지 못한 내용, 관련 출처를 구분한다.
5. **후보 재탐색:** 사용자가 틀린 후보를 제외하거나 기억을 수정해 다시 찾는다.

**첫 MVP:** 영화·드라마를 대상으로 텍스트 입력 → 추가 질문 → 후보 최대 3개와 확인 가능한 근거를 제시한다. 음악은 이후 확장으로 검토한다.

**검증할 점:** 같은 질문을 일반 검색이나 기존 AI에 입력했을 때보다 후보를 찾고 확인하기 쉬운지 비교한다. 작품 기본 정보와 장면·대사를 확인할 수 있는 출처 및 이용 조건도 확인해야 한다.

## 3. MBTI 페르소나 기반 6:6 AI 가상 소개팅

**한 줄 소개:** 사용자 1명과 서로 다른 페르소나를 가진 AI 참가자 11명이 6:6 가상 소개팅을 진행하고, 사용자가 다양한 대화를 경험하는 서비스.

### 타깃 사용자

- 소개팅이나 새로운 사람과의 첫 만남을 연습하고 싶은 성인
- 연애 예능처럼 여러 참가자가 대화하고 서로를 알아가는 과정을 즐기는 사람
- MBTI와 성격 유형을 소재로 한 대화형 콘텐츠에 관심이 있는 사람

### 페인 포인트

- 처음 만난 상대와 무슨 이야기를 해야 할지 막막할 수 있다.
- 실제 소개팅 전에 다양한 상대와 부담 없이 대화할 기회가 부족할 수 있다.
- 여러 사람이 함께하는 소개팅 분위기에서 자연스럽게 발언하고 대화를 이어가는 연습이 어렵다.

### 문제 정의

> 사용자가 다양한 성향의 가상 참가자들과 단체 및 1:1 대화를 경험하며, 첫 만남을 부담 없이 연습하고 자신의 대화 방식을 돌아볼 수 있게 하려면 어떻게 해야 할까?

### 코어 피처

1. **랜덤 MBTI 페르소나:** 게임 시작 시 AI 참가자 11명에게 MBTI를 무작위로 부여하고, 이름·관심사·가치관·대화 스타일도 설정한다.
2. **6:6 단체 소개팅:** 사용자 1명과 AI 11명이 자기소개와 공통 주제 대화를 진행한다.
3. **1:1 대화:** 단체 대화에서 더 알아보고 싶은 상대를 선택해 대화한다.
4. **선택형 힌트:** 사용자가 원할 때 대화를 이어갈 질문이나 표현을 제안한다.
5. **대화 피드백:** 사용자의 실제 발화를 바탕으로 잘 이어진 대화와 다시 시도해볼 표현을 보여준다.

**MBTI 활용 원칙:** MBTI는 캐릭터를 만드는 재미 요소로 활용한다. 같은 유형이라도 관심사와 대화 스타일을 다르게 구성하며, 특정 유형의 성격이나 실제 연애 궁합을 확정적으로 판단하지 않는다. 유형 중복 허용 여부는 기획 단계에서 정한다.

### 멀티에이전트 구성 제안

| 역할 | 하는 일 |
| --- | --- |
| 참가자 | 개별 페르소나와 대화 맥락을 바탕으로 반응 |
| 진행 | 소개팅 단계와 발언 순서를 관리하고 다음에 반응할 참가자를 선택 |
| 기록 | 참가자 설정과 앞서 나눈 대화 내용 정리 |
| 피드백 | 사용자의 실제 대화를 바탕으로 대안과 연습할 점 제시 |

참가자 11명의 페르소나는 각각 유지하되, 11명을 모두 독립된 에이전트로 구현할지는 호출 비용과 대화 품질을 검토한 뒤 결정한다.

**첫 MVP:** 6:6 구도를 유지하면서 자기소개 → 단체 대화 1회 → 선택한 상대와 1:1 대화 → 선택형 피드백까지 한 라운드를 완성한다.

**검증할 점:** 사용자가 대화 연습과 시뮬레이션의 재미 중 무엇을 더 원하는지, 여러 AI가 맥락을 유지하면서 사용자에게 충분한 발언 기회를 주는지 확인한다. MBTI가 대화의 재미나 이해에 실제로 도움이 되는지도 검증한다.

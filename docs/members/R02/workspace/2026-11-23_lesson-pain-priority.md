## 결론과 문제 정의

최초 등록을 우선 검증할 문제로 제안한다. 첫 타깃은 기존 모집 원고·사진·수업 조건을 보유하고, 현재 한 곳 이상에서 홍보하면서 다른 채널로 확장하려 하지만 등록 작업에 쓸 시간이 부담인 음악 강사다. AI를 이미 사용하는 강사도 포함한다.

문제 정의는 ‘모집 채널을 늘리려는 음악 강사가 기존 원고를 플랫폼별 항목과 제약에 맞춰 재구성하고, 사실 확인·입력·첨부·제출까지 직접 수행해야 해 창작과 수업 시간을 쓰고 등록을 미루게 된다’로 제안한다.

R02는 결국 모든 등록을 완료했지만 최초 등록을 가장 먼저 맡기겠다고 답했다. 강사 A는 추가 등록의 번거로움과 창작 시간 침해를 이유로 한 채널만 사용했다. 최초 등록 지원의 기대 가치는 직접 작업·감독 부담 감소와 채널 확장이다. 노출 증가가 수강생 증가로 이어지는 효과는 미확인이다.

반대 근거와 한계도 있다. 최초 등록은 일회성인 반면 후기·상담은 반복되므로 장기간 누적 부담은 더 클 수 있다. R02는 직접 등록을 끝냈고 현재 AI로 문구 작성 부담도 줄였다. 강사 B의 가격 경쟁 우려는 등록 편의만으로 해소될지 미확인이다. 표본은 본인 1명과 지인 2명이며 일반화에는 추가 검증이 필요하다.

## 크몽 최초 등록 사례와 AI 사용

기존 원고와 사진이 있어도 서비스 제공 절차, 준비사항, FAQ, 패키지, 회차별 커리큘럼 등으로 내용을 나누는 일이 막막했다. 커리큘럼은 평소 쓰던 방식을 1~4회로 나눴다. 수업은 원래 수준·목표에 맞춰 운영했다.

회당 90분·월 4회 기본 수업과 회당 3시간·월 40만 원, 4시간 30분·월 50만 원 수업은 크몽 등록 전부터 운영했다. 3시간은 원하는 학생이 여러 명 있었고 강사에게 연강·모집 인원 감소의 이점이 있었다. 4시간 30분은 원하는 한 명이 있었다. 다른 플랫폼에서는 기본 요금만 공지하고 상담에서 다른 요금을 설명했다. 크몽 패키지는 선택 사항으로 STANDARD만 등록할 수도 있다고 사용자와 제공 화면에서 확인했다.

작성 중 임시저장 후 미뤘으며 개인정보 포함으로 반려됐던 것으로 기억한다. 정확한 반려 통지와 사유는 미확인이다. 수정·재제출 후 승인·게시됐다는 본인 진술을 확보했다. 당시 AI 사용 없이 직접 작성했다.

최근에는 AI로 원고와 크몽 항목 문구를 작성했다. 사용자는 ChatGPT 사용을 진술했고, 추가로 Gemini 대화 화면을 제공했다. 문구 생각 시간은 줄었지만 총시간은 미측정이다. 조건 검토·복사 입력·사진 첨부·제출은 직접 수행했다. AI가 제안한 발매 추가 비용 없음과 최소 2일 전 일정 변경 규정은 실제 운영과 달라 직접 제거했다고 확인했다.

제공된 AI 대화와 공개 공고 비교에서 입문자 90% 표현이 ‘대부분’으로 바뀌고, 위 비용·변경 조건이 빠진 것을 확인했다. 각 수정의 이유는 사용자가 확인한 범위까지만 해석한다. 공고 조회 결과에는 60·120·180분과 15·25·35만 원이 표시됐고 제공 스크린샷에는 90·180·270분과 25·40·50만 원이 보여 버전 차이가 있다. 과거 등록 경험과 현재 실제 판매 조건의 동일성은 미확인이다. [공개 크몽 공고](https://kmong.com/gig/775029)

## R02가 원하는 이용 흐름과 확인 기준

1. 레슨 조건과 사진을 제공하고 로그인·본인인증을 직접 수행한다.
2. 사이트별 문구와 공고 포스터 시안을 확인한다.
3. 가격, 회당 시간·횟수, 추가 비용, 일정 변경 조건, 제공 서비스 범위를 우선 검토하고 승인한다.
4. 승인 후에는 화면을 지켜보지 않아도 입력·사진 첨부·최종 제출이 진행되기를 원한다.
5. 승인 내용대로 입력할 수 없거나 새 결정이 필요하면 멈추고 사용자에게 질문한 뒤 결정에 따라 계속한다.
6. 사이트별 공고 링크와 게시 완료·심사 중·실패 상태를 확인한다. 실패 사유와 사용자가 확인하거나 수행할 조치도 받는다.

첫 이용 희망은 크몽·탈잉·숨고 세 곳이다. 이 흐름에 유료 이용 의향이 있으나 금액은 미정이다. 로그인·본인인증, 자료 제공, 초안 검토, 추가 질문 답변을 포함한 세 곳의 직접 작업 시간이 총 20~30분 이내이기를 원한다. 이는 희망 성공 기준이며 달성 실험은 수행 전이다. 서비스 처리 시간과 심사 대기 시간은 별도 관측한다.

반려 수정·재제출, 최신글 갱신, 견적·상담 대행도 추가 희망으로 제시했다. 초보 가능 여부·커리큘럼·시간 변경 가능 여부는 기존 답변 재사용이 가능했고 시작일·평일 시간은 개별 조율이 필요했다. 기능과 MVP 채택은 R01 통합 판단에 필요한 입력으로 남긴다.

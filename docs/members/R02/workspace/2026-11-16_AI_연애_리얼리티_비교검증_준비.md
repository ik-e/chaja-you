# AI 연애 리얼리티 비교 검증 준비

- 작성: R02 작업 지원 · 2026-11-16 (KST)
- 상태: 기존 제타 1회 기록 검토 및 공개 자료 확인. 아래 통제 비교·자체 PoC는 미실행.

## 기존 관찰

사용자가 제공한 제타 대화 1건에서 진행자는 남성 5명이 등장했다고 말했으나 장면에는 사용자 외 6명의 이름이 묘사됐다. 여성 7명 입장 안내 뒤에는 5명의 이름이 묘사됐다. 지명 목록에서는 영철→정숙, 영식→순자, 상철·광수→영자였지만 후속 설명은 영호·정숙, 순자·영자를 중복 지명으로 서술했다. 여성 7명 안내와 5명 묘사만으로 실제 여성 인원 자체가 잘못됐다고 단정할 수는 없다. 사용자가 활동을 중단하자 캐릭터가 압박하는 반응도 관찰됐다. 정정 횟수·소요 시간은 기록되지 않았다. 이 사례는 동일 조건 실험, 다른 콘텐츠의 문제나 반복률을 의미하지 않는다. 대화 원문은 민감한 내용을 포함하므로 공개 기록에 복제하지 않는다.

## 비교 실행 카드 — 미실행

- 대상: 제타 유사 콘텐츠와 이용 가능한 범용 LLM, 이후 동일 조건으로 자체 PoC. 계정·기능·설정·모델·시각·제약을 기록한다. 실제로 접근할 수 없는 대상은 미실행.
- 가상 참가자: 사용자 U, 참가자 A(가명 다온), B(가명 하린), C(가명 서우). A의 직업은 자기소개 전 비공개. A만 U의 비공개 대화 내용 ‘좋아하는 계절은 겨울’을 들었다. 공개 선택 U→A, B→C, C→B. 규칙 및 참가자 수를 시작 전 기록한다.
- 정보 전달 조건을 구분한다: 단일 대화에 비밀을 넣으면 모델 자체가 해당 정보를 보므로 등장인물 연기 수준만 시험한다. 별도 권한 분리로 정보가 전달되지 않는지는 PoC에서 확인하며 동일한 검증으로 취급하지 않는다. 제타 콘텐츠 설정이 고정되어 시나리오 삽입이 안 되면 차이를 기록하고 해당 항목을 미실행 처리한다.
- A 공개 전 질문: 자기소개 전 A의 직업을 묻는다. 기대: 미공개로 유지. 설정을 임의로 생성하는지 기록한다.
- B 비공개 질문: A에게만 말한 계절을 B에게 질문한다. 기대: B가 알고 있다고 단정하지 않음. 공개·전달 맥락을 함께 기록한다.
- C 선택 상태: 정해진 선택을 기록한 뒤 날짜 선택·최종 선택으로 진행하고 각 단계의 선택과 결과를 다시 묻는다. 기대: 변경 사건 없이 선택이 바뀌지 않음. 최종 선택은 새 선택이므로 첫인상과 같아야 한다고 가정하지 않는다.
- D 장면 중단: 대화 중 ‘이 장면을 중단하고 쉬고 싶다’고 말한다. 기대: 진행을 멈추고 사용자의 선택을 존중함. 오류 복구는 해당 서비스에서 안전하게 재현 가능한 경우에만 별도 시험한다.
- 각 사례별 기대 결과, 실제 응답의 비식별 요약, 불일치·정정 횟수, 가능한 경우 시간, 실패·미실행 이유를 기록한다. 최초 응답과 정정 후 응답을 구분한다. 반복 횟수와 합격선은 실험 전에 정한다. 실제 이용자 피드백과 내부 테스트를 구별한다.

- [제타 이용약관](https://zeta-ai.io/ko/policy/terms): 사전 승낙 없는 자동화 접근 및 답변 스크립트의 무단 학습 데이터 사용을 제한하는 조항이 있다. 서비스 원문을 대량 수집하거나 모델 학습에 사용하지 않고 수동 시험과 최소 요약을 우선한다. 연구용 공개·공유 범위, 별도 라이선스와 현행 적용 조건은 추가 확인 필요. 확인일 2026-11-16.

- 연구 자료에는 가상 인물만 사용하고 비공개·민감한 원문은 공개 저장소에 올리지 않는다. 저장 기간·삭제와 사용자 동의는 제품 정책으로 아직 미정이다.

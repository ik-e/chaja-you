## 1. 타깃 사용자

연애 예능형 AI 콘텐츠에서 직접 참가자로 대화하고, 여러 참가자의 선택이 이어지는 한 회차를 즐기고 싶은 성인. 제안자는 제타를 1회 이용했다. 주변 시청자도 참여를 원한다는 제안자의 의견은 있으나 인원·질문 방식과 실제 이용 빈도는 미확인이다.

## 2. 페인포인트 — 관찰과 가설

제타 1회 플레이에서 참가자 수와 등장 묘사, 첫인상 지명과 중복 지명 설명이 맞지 않는 부분이 있었다. 장면 중단 의사에 캐릭터가 압박하는 반응도 있었다. **상태가 어긋나면 사용자가 다시 확인·정정해야 하고 몰입이 깨질 수 있다는 것은 가설**이다. 정정 횟수·시간·반복 빈도와 다른 사용자 경험은 미확인이다.

## 3. 기존 대안

해당 제타 콘텐츠에서 가명 부여, 첫인상 선택, 데이트와 캐릭터 대화가 가능했다. 범용 LLM도 지침을 이용한 역할극에 활용할 수 있다. 기존 서비스를 계속 쓰는 이유는 간편한 접근과 기존 대화 기능일 수 있으나 사용자 조사 전 **가설**이다.

## 4. 잔여 문제

기존 대안 이후에도 여러 참가자의 선택과 관계를 한 회차 동안 확인하고 일관되게 이어가는 데 정정 부담이 남는지는 **미확인**이다. 반대로 제타의 기존 경험만으로 충분할 수 있다. 비공개 대화·장기 기억 혼동과 범용 LLM의 동작은 이번에 시험하지 않았다.

## 5. 문제 정의 — 검증 가설

> 연애 예능형 AI 콘텐츠 이용자가 여러 참가자와 한 회차를 이어가려 할 때 참가자·선택 상태가 어긋나면 이를 다시 확인하거나 정정하는 부담을 겪을 수 있다.

## 6. 핵심 피처와 지표 — 제안

| 피처 | 줄이려는 문제 | 측정 지표 / 기준선 |
| --- | --- | --- |
| 참가자별 정보·기억 구분 | 알 수 없는 정보가 대화에 섞임 | 공개 전·비공개 정보 노출 건수 / 같은 질문의 제타·범용 LLM |
| 공개 선택·관계 목록과 상태 연결 | 인원·선택 혼동과 정정 | 인원·선택 불일치와 정정 횟수 / 같은 선택 시나리오의 기존 대안 |
| 장면 중단·오류 후 복구 | 원치 않는 장면 지속·진행 중단 | 중단 적용·상태 복구 성공 여부와 시간 / 가능한 동일 요청·상황의 기존 대안 |

6:6, 가명, 무작위 MBTI와 데이트는 콘텐츠 규칙이다. MBTI는 재미 요소이며 실제 성격·궁합 판정이 아니다. 위 기능의 효과와 정량 합격선은 미확인이다.

## 7. 근거·검증과 8주 MVP

- **근거:** 제타 직접 플레이 기록 1건(2026-11-16). 제타가 이미 대화·데이트를 제공한다는 점은 별도 서비스 필요성에 대한 반대 근거이기도 하다.
- **공식 조건 확인:** [제타 이용약관](https://zeta-ai.io/ko/policy/terms)은 사전 승낙 없는 자동화 접근과 답변 스크립트의 무단 학습 사용을 제한한다. 수동 최소 확인을 우선하고 공개·재사용 허용 범위는 추가 확인한다. [비교 준비 기록](2026-11-16_AI_연애_리얼리티_비교검증_준비.md) (2026-11-16 확인).
- **비교 실험 — 미실행:** 제타·범용 LLM과 자체 PoC에 가능한 같은 설정으로 ① 공개 전 직업 질문 ② A만 아는 내용을 B에게 질문 ③ 첫인상→데이트→최종 선택 유지를 시험한다. 설정·정보 접근 차이를 기록한다.
- **8주 MVP — 제안:** 입장→첫인상→자기소개→단체·1:1 대화→최종 선택의 짧은 한 회차와 위 세 기능. 6:6의 비용·속도가 감당되지 않으면 소수 참가자로 상태 연결부터 시험한다. 사용자 고통이 확인되지 않으면 문제 정의를 재검토한다.
- **접근·도입:** 가상 데이터를 사용한다. 서비스별 자료 저장·재사용 조건, 대화 보존·삭제 정책, 실제 이용 빈도·비용·지불 의향은 미확인이다. 실제 사용자 자료는 권한과 동의 확인 전 수집하지 않는다.
- **추가 확인:** 과정 2번 주제의 일정·자산 관리 요건과 축소 PoC의 적합성은 강사·운영 담당자 확인 전이다. 사용자 수요·차별성·비용·효과는 검증 전이다.

## 아침 체크

**오늘의 목표**

강사가 여러 플랫폼에 레슨을 등록하며 겪는 반복 작업과 직접 개입 부담을 실제 사례로 확인하고, 가장 먼저 해결할 문제와 핵심 타깃을 구체화해 11월 25일 기획안 통합에 필요한 근거를 제공한다.

**오늘 할 일**

- [ ] **기존 자료를 모아 네 가지 업무를 비교한다.** 11월 18일 기획안과 19일·20일 일지를 바탕으로 최초 등록, 공고 갱신, 후기 재게시, 문의 대응을 같은 표에 정리한다. 업무별 발생 상황, 반복 빈도, 소요 시간, 직접 수정·대기, 작업 포기와 손실, 현재 쓰는 대안과 남는 불편을 적는다.
- [ ] **기록된 수치의 근거를 확인한다.** 크몽 최초 등록 약 20분과 당근 모임 개설·첫 글 약 15분은 기존 추정값으로 표시한다. 후기의 추가 네 곳 게시 약 20분, 문의 대응 하루 약 1시간도 당시 조건과 기억의 범위를 확인한다. 본인 회상·동료 진술·최근 실측·추정을 표시하고, 측정하지 못한 값은 미측정으로 둔다.
- [ ] **접근 가능한 음악 강사에게 추가 확인한다.** 가능하면 1~2명의 최근 모집 사례를 듣고 사용 채널 수, 채널 선택 이유, 최초 등록과 반복 관리 중 가장 부담스러운 일, 실제 AI 활용 방식과 이용을 꺼리는 이유를 묻는다. 기존 원고·사진 보유 여부, 게시처 확장 의향, 맡기고 싶은 범위와 이용·지불 조건도 확인한다. 응답 일시·표본 수·한계를 남긴다.
- [ ] **첫 타깃과 이용 순간을 좁힌다.** 현재 채널 수, 기존 원본 보유 여부, 다른 게시처로 확장하려는 의향을 기준으로 첫 사용자의 조건을 적는다. 어떤 상황에서 서비스를 찾고, 무엇을 제공하며, 어떤 결과를 받아야 수고가 줄었다고 느끼는지 구체화한다.
- [ ] **우선 문제를 한 문장으로 제안한다.** 네 업무의 부담과 기존 대안 이후 남는 일을 비교해 최초 등록 우선·다른 업무 우선·판단 보류 중 하나를 제안한다. 선택 이유와 반대 근거를 함께 적고, 사용자 → 상황 → 불편 → 원인 → 기대 가치가 이어지도록 정리한다.
- [ ] **팀 통합에 필요한 자료를 준비한다.** 알고 있는 레슨 플랫폼 목록과 실제 사용 경험을 정리해 R04의 대안 조사와 R05의 권한·기술 조사에 연결한다. R03에게는 사용자 입력·기대 결과·실패 시 불편을, R01에게는 우선 문제 제안과 남은 결정 사항을 전달할 수 있도록 정리한다.

**오늘 완료 목표**

네 업무 비교표, 1차 타깃과 핵심 이용 순간, 우선 문제 제안, 근거와 미확인 목록을 TASK-028 지정 산출물인 `docs/members/R02/workspace/2026-11-23_lesson-pain-priority.md`에 정리한다. 확인하지 못한 항목에는 이유와 다음 검증 방법을 적는다. 실제 작업 완료 시 TASK-028의 `result`에 결과·근거 경로·검증 내용·남은 결정 요청을 기록하고 GitHub 링크를 공유한다.

추가 강사 섭외와 최근 작업 시간 확인이 필요하다. 기존 동료 강사의 5만 원 지불 의향은 공고 한 건을 10곳에 최종 제출하는 조건이므로, 두 곳 지원 시 이용·지불 의향은 추가로 질문한다. 기술·권한 조건은 R05 조사 결과와 연결하고, 최종 MVP와 과금 방식은 R01의 통합 판단에 필요한 질문으로 남긴다.

## 점심 체크

- 진행 상황 — TASK-028 문답을 통해 네 업무 부담과 지인 강사 2명의 사례를 정리했다. 크몽 첫 작성·제출은 회상 기준 1~2시간, 반려 수정은 5~10분이다. 뮬 갱신은 회당 2~3분, 후기 재게시 주 40~60분, 견적·문의 대응 주 약 60분으로 정리했다.
- 결과 — 최초 등록을 우선 검증할 문제로 제안했다. 기존 원고가 있어도 항목 구성·사실 확인·입력·첨부·제출 부담이 남았다. AI가 실제와 다른 추가 비용·일정 변경 조건을 생성해 직접 삭제한 사례를 확인했다.
- 이용 조건 — 크몽·탈잉·숨고 세 곳의 문구·포스터 승인 후 최종 제출까지 희망한다. 로그인·본인인증을 포함한 직접 작업 목표는 총 20~30분이다. 조건 변경은 사용자 확인 후 진행하고 사이트별 상태·링크·실패 사유·필요 조치를 받기를 원한다.
- 막힘·필요한 도움 — 시간은 실측 전이며 자동화 권한·기술 가능성은 R05 확인이 필요하다. 강사 B의 대화 날짜와 이용 의향은 미확인이다. A는 11월 20일 통화에서 10곳 최종 제출에 약 5만 원 지불 의향을 밝혔다. 실제 결제와 세 곳 가격은 미확인이다.
- 다음 작업 — R03 요구사항·검증 기준과 R01 기획 통합에 활용할 결과를 정리했다. [TASK-028 결과 문서](../workspace/2026-11-23_lesson-pain-priority.md)를 기준으로 후속 검증과 범위 결정을 진행한다.

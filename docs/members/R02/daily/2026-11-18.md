# 2026-11-18 일일 상태

- 팀원: R02 (상옥)
- 보고 상태: TASK-022에서 새 주제 탐색을 선택했다. 음악 레슨 선생님의 여러 플랫폼 등록을 돕는 서비스를 1차 기획안으로 정리했다. 팀의 최종 주제는 선정 전이다.

## 아침 체크

- 오늘 할 일: 아침 회의와 멘토링 피드백을 정리하고, 직접 겪은 일에서 사용자와 불편이 분명한 프로젝트 후보를 찾는다.
- 오늘 완료 목표: 토요일에 설명할 수 있도록 누가 어떤 일을 반복하는지, 지금 쓰는 방법으로도 무엇이 번거로운지, 어떻게 확인할지를 한 문서에 담는다.
- 의존 작업/예상 막힘: 기존 AI 연애 리얼리티 후보는 기존 서비스 이용 후에도 어떤 불편이 남는지 확인이 필요했다. 이번에는 탐색과 모집 양쪽을 직접 경험한 음악 레슨에서 사례를 찾기로 했다.

## 점심 체크

- 진행 상황: 멘토 피드백과 아침 회의를 바탕으로 대시보드용 작업 요약을 정리했다. 팀원이 제안한 점포 인수 지원안의 세 사용자 후보를 읽고, 처음 가게를 인수하는 사람이 계약 전에 확인하기 어려운 정보가 무엇인지 검토했다.
  - 음악 레슨에서는 미디·믹싱 수업을 알아볼 때 여러 사이트에서 같은 동네의 공고를 따로 찾아야 했던 경험에서 출발했다. 배우고 싶은 분야를 고르면 지도에서 근처 수업의 시간당 가격을 비교하고, 가격이 공개되지 않은 수업은 ‘가격 문의’로 표시하는 안을 검토했다.
- 막힘/필요한 도움: 기존 검색이나 일반 AI로 후보를 모은 뒤에도 어떤 불편이 남는지, 다른 레슨생도 지도 비교를 원하는지는 확인이 필요하다.
- 일정 조정: 기획 회의에서 선생님이 같은 수업을 여러 곳에 등록하는 절차를 먼저 구체화하기로 했다. 플랫폼마다 수업 소개와 가격 옵션을 다시 구성했던 경험을 바탕으로 비교 실험을 설계할 수 있어서다. 지도 탐색안은 후속 후보로 남겼다. 체크별 실제 시각은 미기록이다.

## 저녁 체크

- 완료한 일: 회의록과 전사 내용을 반영해 음악 레슨 등록 지원 1차 기획안을 작성했다. 선생님이 장소·가격·커리큘럼을 한 번 입력하면, 서비스가 플랫폼별 필수 항목과 빠진 정보를 찾아 초안을 만들고 선생님이 확인한다. 직접 게시까지 지원할 수 있는지는 플랫폼별로 확인하기로 했다.
- 남은 일과 사유: 다른 선생님도 여러 플랫폼을 쓰는지, 최초 등록에 얼마나 걸리는지, 템플릿을 복사하거나 일반 AI를 쓸 때보다 수고가 줄어드는지는 아직 검증 전이다. 경험상 하루 약 1시간은 견적·상담 답장에 쓴 누적 시간이다. 최초 등록 시간은 따로 측정해야 한다.
- 다음 작업: 다른 음악 레슨 선생님에게 최근 공고를 어디에 어떤 순서로 올렸는지 묻는다. 우선 한 플랫폼의 필수 항목·가격 옵션·게시 허용 범위를 확인하고, 같은 수업 자료를 수동 복사와 등록 지원 초안에 각각 적용해 걸린 시간, 누락, 가격 오류를 비교할 준비를 한다. 11월 21일에는 그 결과로 첫 구현 범위를 논의한다.

## 1. 작성 규칙

- 컬럼과 길이 제한은 마이 AI 오피스 화면목록 검증 규칙을 따른다: 화면 ID 40자, 1~5뎁스 각 60자, 화면명 100자, 영문 화면명 60자, 화면구분·화면유형·로그인레벨·신규구분 40자, 비고 1000자. 영문 화면명·화면명·1뎁스는 필수이고, 뎁스는 앞에서부터 연속으로 채운다. 영문 화면명은 중복될 수 없다.
- 화면구분: 메인·서브·팝업 / 화면유형: 페이지·모달·드로어 / 로그인레벨: 비로그인·로그인·운영자 / 신규구분: 기존(이전 mock 화면 대응, 재설계 대상)·신규.
- 같은 내용을 마이 AI 오피스로 가져올 수 있는 screenCatalog 형식 JSON으로도 저장했다: [2026-11-26_R04_레슨등록지원_화면목록_screenCatalog.json](2026-11-26_R04_레슨등록지원_화면목록_screenCatalog.json). 비고 앞의 [범위]와 기능 ID는 이 문서에서 덧붙인 정보다.

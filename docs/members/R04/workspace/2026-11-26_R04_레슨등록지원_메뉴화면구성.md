## 1. 구성 원칙

- 마이 AI 오피스 「메뉴화면구성」과 같이 **메뉴 구조(트리)와 화면목록을 같은 화면 ID로 읽는다.** 상세 트리는 [메뉴구조도](2026-11-26_R04_레슨등록지원_메뉴구조도.md), 13개 컬럼 표는 [화면목록(IA)](2026-11-26_R04_레슨등록지원_화면목록_IA.md)에 있다.
- 화면 유형은 「화면배치설계」 분류를 따른다: 메인 화면 · 서브 화면 · 풀팝업 · 모달팝업(확인·삭제·간단한 입력) · 우측 드로워(현재 항목의 속성·참고자료·이력).
- 대상 플랫폼은 **웹**이다. 웹 배치 기준: 헤더 높이 56~64px(서비스 로고·화면 제목·브레드크럼 좌측, 주요 액션 우측), 좌측 네비게이션, 중앙 콘텐츠 영역, 우측 드로워.
- 버튼 위계는 마이 AI 오피스 공통규칙(CTA)을 따른다: 영역당 Primary 1개(파란색), 삭제·거절은 빨간색 채움, 취소는 빨간색 외곽선.
- 플랫폼 작업(SCR-020~029)은 단계형 흐름이다. 상단 단계 표시로 현재 위치를 보이고, 오류·예외(ERR-xx)는 해당 단계 안에서 처리한 뒤 정해진 지점으로 되돌아간다.

## 4. 이전 Web UI(5화면)와의 관계

이전 mock Web UI의 source·prepare·auth·review·result 5개 화면은 각각 SCR-011/020, SCR-022, SCR-024, SCR-027, SCR-029에 대응한다(화면목록의 신규구분 '기존'). 이전 API(H1~H8)·원격 뷰어 방식은 현행 기준이 아니므로 이 화면들도 새 범위에 맞춰 재설계 대상이다.

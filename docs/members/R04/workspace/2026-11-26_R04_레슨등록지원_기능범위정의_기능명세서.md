## 1. 목적

서비스 기능 범위를 정하기 위해 기획 피처와 서비스 운영에 필요한 추가 기능을 한 표에서 비교한다. 각 기능은 메뉴와 화면 ID로 연결해 [메뉴구조도](2026-11-26_R04_레슨등록지원_메뉴구조도.md)·[화면목록(IA)](2026-11-26_R04_레슨등록지원_화면목록_IA.md)와 대조할 수 있다.

| 범위 표기 | 의미 |
|---|---|
| MVP | 기획 11.4의 제품 MVP 제안: 동일 원본 재사용, 신규·추가 등록, 대표 기존 정보 수정, 통합 결과 확인 (최소 2개 플랫폼) |
| 확장 | 기획 11.4의 제품 확장: 공고 갱신, 사용자 요청 기반 상태 관리 확대 |
| 조건부 | 기획 5.9·11.2의 자동 모니터링 (MVP 제외) |
| 추가 후보 | 기획 피처 목록에는 없으나 서비스 운영에 필요하다고 R04가 제안하는 기능 (근거 표기, R01 결정 필요) |

# 팀 엑셀 대시보드 자동 작성 및 동기화 표준 규칙

사용자가 **"팀 엑셀 대시보드 작성해줘"** 또는 일일 대시보드 정리·입력을 요청할 때 적용하는 정본 작성 규칙입니다.

---

## 1. 내용 구조 및 줄바꿈 규칙
* **3대 섹션 헤더**:
  * `[한 일]`
  * `[이슈]`
  * `[내일 할일]` (또는 `[내일]`)
* **줄바꿈 및 간격**:
  * 섹션 헤더와 하위 항목 사이는 개별 줄로 줄바꿈됩니다.
  * 각 하위 항목은 반드시 개별 줄(`\n`)로 줄바꿈 처리합니다.
  * 섹션 사이는 빈 줄(`\n\n`)로 1줄 띄워 가독성을 확보합니다.

## 2. 글머리 기호 (불릿) 표준
* **반드시 대시(`- `) 사용**:
  * 올바른 예: `- 레슨 등록 논리 설계 채택 및...`
  * 금지 예: `· 레슨 등록 논리 설계...` (가운데 점 사용 금지)

## 3. 외부 공유용 정제 (보안 및 가독성)
* **내부 식별자 완전 배제**:
  * `TASK-xxx` (예: `TASK-048`, `TASK-051` 등) 제거
  * 역할 ID (예: `R01~R05`, `R04` 등) 제거
* **역할·기능 중심 명칭 사용**:
  * `R04` → `프론트엔드/숨고 어댑터`
  * `TASK-051` → `웹 UI 5대 핵심 화면 컴포넌트`
  * `TASK-052` → `숨고 Adapter 및 오퍼레이션`
  * `R03` → `백엔드 공통 API`
  * `R05` → `원격 브라우저 런타임/뷰어`

## 4. 구글 스프레드시트 셀 서식 및 반영
* **셀 병합**:
  * 일일 진행 내용(G열)은 해당 날짜 행의 G열부터 I열까지 병합 (`G{row}:I{row}`).
* **다중 행 줄바꿈 커밋**:
  * Google Sheets 수식 입력줄(`#t-formula-bar-input .cell-input`)에 `insertLineBreak` 명령을 통해 셀 내부 줄바꿈(`\n`)을 보존하여 커밋하거나, 쌍따옴표로 감싼 TSV 클립보드 붙여넣기를 수행합니다.
  * 입력 후 공용 CSV 내보내기 엔드포인트를 통해 줄바꿈 보존 및 행 분할(spill) 없음, 식별자 미포함 여부를 검증합니다.

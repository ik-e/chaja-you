## 1. R05(원격 브라우저 Viewer) 연동 협의 아젠다

### 1.1 `postMessage` 생명주기 및 메시지 규격 확정
Web UI의 H6(인증) 컴포넌트는 iframe 내부에 R05의 원격 브라우저 뷰어를 마운트합니다. 양방향 통신을 위한 표준 메시지 규격을 제안합니다.

| 방향 | 메시지 타입 (`type`) | Payload 필드 | 설명 |
| :--- | :--- | :--- | :--- |
| **UI ➔ Viewer** | `r04:viewer:mount` | `{ sessionId, targetPlatform: "soomgo"|"kmong", theme: "light" }` | 뷰어 초기화 및 타깃 세션 연결 요청 |
| **Viewer ➔ UI** | `r05:viewer:ready` | `{ viewerVersion, status: "ready", capabilities: ["vnc", "input"] }` | 뷰어 로드 완료 및 사용자 조작 가능 상태 통지 |
| **Viewer ➔ UI** | `r05:viewer:auth_completed` | `{ sessionId, platform, status: "success", timestamp }` | 사용자가 뷰어 내에서 캡차/2차인증/로그인 완료 시 통지 |
| **Viewer ➔ UI** | `r05:viewer:error` | `{ code: "TIMEOUT"|"CRASH"|"DISCONNECTED", message }` | 뷰어 비정상 종료 또는 타임아웃 통지 |
| **UI ➔ Viewer** | `r04:viewer:dispose` | `{ sessionId, reason: "user_cancel"|"completed" }` | 인증 종료 후 뷰어 자원 해제 및 언마운트 |

### 1.2 협의 요청 사항
1. **타깃 도메인 보안:** iframe 통신 시 `targetOrigin`을 와일드카드(`*`) 대신 배포 도메인(예: `window.location.origin`)으로 상호 한정할 것인지 여부.
2. **세션 타임아웃 정책:** 사용자가 인증 화면을 방치할 경우 뷰어 세션 만료 시간(권장: 300초) 및 UI 폴백 화면 처리 기준.

## 2. R03(공통 백엔드 API) 연동 협의 아젠다

### 2.1 팀장 8대 기준 준수 상태 및 H7/H8 상세 규격
R04 Web UI 비동기 클라이언트(`web/api/client.py`)는 팀장 추가 지시 8대 기준을 이미 구현 완료하였습니다.

1. **H7 (작업 요청) 202/200 분기:**
   - 최초 요청 시: HTTP 202 Accepted 반환 및 `job_id` 응답.
   - 동일 `request_key` 재전송 시: HTTP 200 OK 및 기존 진행 중인 `job_id` 반환.
2. **H8 (작업 상태 및 진행률) 폴링 필드:**
   - UI는 1.5초 지수 백오프(최대 5초)로 H8을 폴링합니다.
   - 응답 내 `progress` 객체에 아래 3종 표준 키의 포함 여부 확인 요청:
     - `current_stage`: 현재 진행 단계 (예: `"s2_fill_fields"`, `"s6_readback"`)
     - `completed_stages`: 완료된 단계 목록 (예: `["s1_nav", "s2_fill"]`)
     - `percent`: 0~100 사이의 정수 진행률
3. **unknown 결과 대응:**
   - API가 `verdict: "unknown"`을 반환할 경우, UI는 자동 재실행을 완전히 차단하고 "수동 점검 필요" 팝업 및 직전 S6 검증 스냅샷을 표시합니다.
4. **인증 정보 격리:**
   - H6 응답의 `AuthGrant`는 UI 메모리 상에서만 일시 유지되며, 로컬 스토리지/로그에 절대 저장되지 않습니다.

### 2.2 협의 요청 사항
1. **Mock API 서버 배포 일정:** 공통 API mock 서버(H1~H9)가 가동되는 예상 시점.
2. **통합 E2E 리허설:** Web UI ➔ R03 Mock API ➔ R04 숨고 어댑터 파이프라인의 통합 테스트 일정.

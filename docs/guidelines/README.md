# 프로젝트 가이드라인

교육 과정의 최신 가이드와 샘플은 원문에서 확인하고, 이 저장소에는 팀 작업에 필요한 요약과 적용 결정을 기록합니다. 비공개 대시보드·즐겨찾기 URL과 재배포 권한이 확인되지 않은 원본 사본은 저장소에 넣지 않습니다.

## 원문 출처

- [Gitea 자료 위치 안내](final_project_repository/README.md)

- [Gitea FinalProject](https://gt.isitsoft.kr/publicproj/aio-01d4-stu/src/branch/main/Lecture/FinalProject)
- [Gitea FinalProject Doc](https://gt.isitsoft.kr/publicproj/aio-01d4-stu/src/branch/main/Lecture/FinalProject/Doc)
- Notion 자료 제목과 접근 방법은 [Notion 원문 참고](Notion_원문_링크.md)를 참고합니다. 비공개 URL은 문서에 포함하지 않습니다.

## 팀 적용

일정·제출물의 실시간 상태는 팀에서 접근 권한을 받은 대시보드에서 확인합니다. 대시보드 URL과 스냅샷을 공개 저장소에 올리지 않습니다. 적용된 규칙은 [팀 헌장](../charter/팀_헌장.md), 진행 문서는 [프로젝트 라우트](../project/README.md)에 반영합니다.

TEAM LEADER

팀장은 신중하게 정합니다

팀장이 하는 일

  • 운영 매니저와의 주 소통 창구 — 일정, 산출물 제출, 지원 요청
  • 멘토와 멘토링 일정 협의 → 디스코드 팀 채널에 공유
  • 팀 일정과 대시보드 현황 챙기기

정하는 방법

  • 가위바위보 금지 — 책임감과 의지가 있는 사람
  • 정해지면 대시보드 ‘팀원 및 역할’에 ‘팀장’ 표시
  • 최종 1등 상금 100만 원은 팀장에게 우선 지급

팀장 = 모든 일을 혼자 하는 사람이 아니라, 일이 굴러가게 만드는 사람

GROUND RULES · 예시

그라운드 룰 — 거창한 목표 말고 실천할 약속

어떻게 소통할까

  • 팀 대화는 디스코드에서
  • 수업 시간 중 메시지는 2시간 안에 응답
  • 30분 넘게 막히면 바로 공유
  • 피드백은 사람이 아니라 코드·문서에

어떻게 행동할까

  • 매일 시작 10분 스탠드업
  • main 브랜치 직접 push 금지
  • PR은 1명 이상 리뷰 후 머지
  • 회의 결과는 그날 문서로 남김

무엇을 지킬까

  • 마감 하루 전 팀 내부 초안 공유
  • 지각·불참은 미리 공지
  • 일일 진행 기록은 당일 작성
  • 맡은 일을 못 하면 빨리 말하기

위 내용은 예시입니다. 팀이 직접 토론해서 5~10개로 정하고, 지키지 못했을 때 어떻게 할지도 함께 정하세요.

TOPICS · 에이전트 구성 예시

주제별로 그려 보는 멀티 에이전트

#에이전트 협업 흐름 (예시)Auto-Healing 초점 (가이드)
1모니터링 → 진단 → 복구 실행 → 보고장애 자동 진단 · 복구
2요청 분석 → 일정 관리 → 자산 관리 → 조율일정 충돌 자동 조정
3의도 분류 → 상담 → 자산 분석 → 응답 검수상담 오류 자동 교정
4조사 계획 → 웹 수집 → 분석 → 보고서 작성데이터 누락 자동 보완
5요구 분석 → 코드 생성 → 테스트 → 리뷰·수정코드 오류 자동 수정

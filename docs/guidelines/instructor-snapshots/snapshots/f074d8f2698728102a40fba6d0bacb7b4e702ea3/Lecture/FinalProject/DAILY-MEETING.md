# 팀 대시보드 작성과 강사 미팅 안내

**팀원은 돌아가며 팀의 진행 상황을 기록하고, 강사와는 결과·막힌 점·오늘의 실행 계획을 이야기합니다.** 아래 대시보드 작성은 매니저 가이드 기준, 미팅 질문은 강사와 함께 확인할 내용입니다.

## 1. 팀 대시보드는 이렇게 작성해 주세요

### 처음 시작할 때와 팀 정보가 바뀔 때

- `0팀(작성예시)`을 먼저 읽고 자기 팀 입력칸을 작성해 주세요.
- **팀 정보:** 팀명·프로젝트 주제·세부 주제·기술 스택·멘토·GitHub·협업툴·팀 드라이브를 입력해 주세요.
- **팀원 및 역할:** 이름·팀장/팀원·담당 업무·GitHub ID를 정확히 적어 주세요. 이 이름이 일지 작성자 선택과 작성 횟수 집계에 사용됩니다.
- 팀의 소통·협업 약속인 **그라운드 룰**을 함께 정해 주세요. 팀장은 일정·제출·지원 요청을 운영 매니저와 연결합니다.

### 한 주의 작성 순서

| 언제 | 무엇을 하나요? |
|---|---|
| 월요일 | 이번 주 마감 산출물을 확인하고 **목표·완료 기준·요일별 계획·담당자**를 적습니다. |
| 매일 수업 종료 전 | 오늘 날짜 행에 **진행 단계·오늘 진행 내용·작성자**를 입력합니다. |
| 다음 날 아침 | 강사 피드백을 읽고 **피드백 확인**에 체크합니다. 반영한 내용은 다음 일지에 남깁니다. |
| 금요일 | **잘한 점·아쉬운 점·개선할 점·다음 주 작업·지원 요청**을 주간 회고에 적습니다. |

### 일지는 돌아가며, 팀 전체의 결과를 적어 주세요

팀에서 순번을 정하고 **팀원 각자 주 1회 이상** 작성해 주세요. `이번 주 작성` 횟수를 확인해 빠진 사람이 없도록 합니다. 작성자는 다른 팀원의 결과도 모아 적고, 팀원들은 자기 작업 내용과 링크를 전달해 주세요.

인원수·휴강 등으로 순번 운영이 어려우면 강사·매니저에게 작성 방법을 확인해 주세요. 작성 횟수를 맞추려고 임의로 행을 늘리거나 작성자 이름을 다르게 적지 마세요.

아래 세 가지면 됩니다. 이슈가 없으면 이슈 항목은 생략해도 됩니다.

```text
[한 일]
- 실제로 끝낸 작업·결정한 내용과 확인할 링크

[이슈]
- 막힌 점·시도한 방법·필요한 도움

[내일]
- 누가 무엇을 어디까지 할지
```

“회의함·개발 중” 대신 “상담 조회 화면 초안 작성, 예약 기능은 다음 작업”처럼 적어 주세요. 문서·PR·화면·테스트 결과로 확인할 수 있으면 좋습니다. 아직 하지 않은 일을 완료라고 쓰지 마세요.

### 산출물 제출과 보완은 일지와 별도로 처리해 주세요

1. 팀 Drive 또는 GitHub에 산출물을 올리고, **강사·매니저가 열 수 있는 공유 권한**을 확인합니다.
2. 산출물 제출 표에 링크를 넣고 상태를 **제출완료**로 바꿉니다. 작업 중에는 **작성중**으로 표시하고 초안 링크를 미리 공유해도 됩니다.
3. 강사의 **1차 의견·보완요청**을 확인해 수정합니다.
4. 수정본과 **최종 수정일**을 반영하고 **보완완료**로 바꿉니다. 이후 강사가 **2차 의견**을 남깁니다.

일지의 피드백 확인 체크, 산출물 보완완료, 매니저 제출 확인은 서로 다릅니다. 읽었다고 수정까지 끝난 것은 아니며, 강사 의견과 매니저 확인칸은 직접 작성하지 마세요. 마감 변경이 필요하면 강사·매니저와 상의해 주세요.

## 2. 강사가 팀에 오기 전에 다섯 가지를 준비해 주세요

팀장만 이야기하지 말고 **해당 작업을 맡은 팀원도 직접 설명**해 주세요. 문서·코드·화면·로그를 열어 두고, 아래 질문에 짧게 답할 준비를 하면 됩니다. 별도 문서를 매일 새로 만들 필요는 없고 팀 메모나 일지를 활용해도 됩니다.

- [ ] **어제 하기로 한 일 중 실제로 끝난 것은 무엇이고 어디에서 볼 수 있나요?**
  - 답변·결과 링크:

- [ ] **지금 가장 막힌 것은 무엇이며, 어떤 방법을 시험했나요?**
  - 막힌 점·시도 결과·필요한 도움:

- [ ] **다음 산출물 마감까지 꼭 끝낼 기능과 나중으로 미룰 기능은 무엇인가요?**
  - 이번 마감까지 할 것 / 이후로 미룰 것:

- [ ] **누구의 작업을 기다리고 있고, 주고받을 입력·출력은 합의했나요?**
  - 협업 상대·의존 작업·입출력 합의 여부:

- [ ] **오늘 누가 무엇을 어디까지 하고, 무엇을 보여 주면 완료라고 볼까요?**
  - 담당자·오늘 작업·완료 기준:

미팅이 끝나면 **다음 행동·담당자·완료 기준·다시 확인할 시점**을 팀이 함께 확인해 주세요. 합의한 내용을 일지와 필요한 기획서·WBS에 반영하고, 다음 미팅에서 실제 결과를 보여 주세요.

## 3. 멘토링과 대시보드 사용 시 기억할 것

- 팀장이 멘토와 일정을 정해 **Discord 팀 채널**에 공유하고, 질문·자료를 미리 올려 주세요. 멘토 피드백의 반영 내용도 일지에 남겨 주세요.
- 멘토링은 팀당 온·오프라인 합산 최대 20시간이며, 인정 온라인 시간은 오프라인 시간을 넘을 수 없습니다. 시작·종료 때 날짜·시간이 보이는 사진이나 화면 캡처를 남기고, 개인 멘토링은 사람별로 증빙해 주세요.
- 주요 소통·지원 요청은 매니저가 확인할 수 있는 Discord에서 진행해 주세요. 개인정보가 담긴 문서는 공개 채널에 올리지 말고 개별 전달합니다. 교육 범위 밖 기술이 필요하면 강사·매니저와 먼저 상의해 주세요.
- **자기 팀 노란 입력칸만** 작성해 주세요. 회색 자동 계산칸·파란 강사 의견칸·다른 팀 시트는 수정하지 않습니다. 행을 추가·삭제하거나 순서를 바꾸지 마세요.
- 회색 날짜 행은 수업이 없는 날, 초록은 오늘·이번 주, 빨간 칸은 미작성 등 확인이 필요한 표시입니다. 경고가 뜨면 수정할 입력칸이 맞는지 먼저 확인해 주세요.

세부 운영 기준은 [매니저 공통 가이드](MANAGER-GUIDE.md), 강사와의 순회 진행 방식은 [강사 일일 지도 운영안](INSTRUCTOR-DAILY-GUIDE.md)을 참고해 주세요.

# 산출물 작성 방법

산출물을 작성할 때 자주 묻는 질문을 정리했습니다. 산출물별 안내와 제공된 양식·샘플을 함께 확인해 주세요.

## Q&A

### Q. 꼭 주어진 목차로 작성해야 하나요?

네. **제공된 목차를 기본으로, 각 항목의 내용을 빠짐없이 작성해 주세요.** 팀 프로젝트에 필요한 설명·표·그림이나 추가 항목은 더 넣어도 됩니다.

샘플의 주제·날짜·수치·구현 결과는 예시이므로 자기 팀의 내용으로 바꿔 주세요. 아직 결정하거나 구현하지 않은 부분은 현재 상태와 작성 예정 내용을 표시해 주세요.

### Q. 꼭 Word(.docx)로 작성해야 하나요?

아니요. **작성 도구는 자유지만, 강사·매니저가 열어 확인할 수 있는 문서 형태로 제출해야 합니다.**

- Word 등으로 작성했다면 `.docx` 또는 PDF 파일을 팀 Drive나 GitHub에 올려 주세요.
- Google Docs로 작성했다면 문서의 공유 링크를 제출해도 됩니다.
- 제출 전 글자·표·그림이 잘 보이는지, 강사·매니저에게 열람 권한이 있는지 확인해 주세요.

문서를 준비한 뒤 **팀 대시보드의 산출물 제출 표에 링크를 등록하고 상태를 `제출완료`로 바꿔 주세요.** 파일 업로드나 링크 생성만으로 제출 절차가 끝나는 것은 아닙니다. WBS처럼 별도 제출 방식이 안내된 산출물은 해당 안내를 따라 주세요.

제출 후 피드백 확인과 보완 방법은 [팀 대시보드 작성과 강사 미팅 안내](DAILY-MEETING.md), 공통 운영 기준은 [매니저 공통 가이드](MANAGER-GUIDE.md)를 참고해 주세요.

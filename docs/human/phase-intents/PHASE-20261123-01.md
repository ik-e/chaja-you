## 목적
멘토링 후 R02 음악 레슨 강사의 업무 부담 해소 방향을 **12개 항목의 기획**으로 구체화하여, 타깃·Pain·원인·핵심 피처·직접 가치·비즈니스 모델·요구사항을 하나의 추적 가능한 흐름으로 연결한다.

## 수행 범위
- 기존 조사·경험·정책 조사를 출처와 확인/추정/미확인을 구분해 재활용한다.
- **R02**는 사용자/실제 Pain/업무 우선순위, **R04**는 기존 대안/가격, **R05**는 기술·인증·정책 제약, **R03**는 기능 계약·검증 기준, **R01**은 문제·가치·BM·MVP·12항목 통합을 담당한다.
- 대표 등록 시나리오와 예외·출력·완료 판정은 기획 요구사항 수준까지만 구체화한다.
- 기존 강사용 최초 등록 우선 가설은 유지하되, 후기 재게시·문의 업무의 반복 손실과 비교한 뒤 범위를 결정한다.
- 기술 조사에는 서버/로컬/일회성 인증/범용 AI/Browser Use가 포함되지만 정식 도구·실행 구조를 확정하는 단계는 아니다.

## 제외와 안전
- 별도 설계 승인 전 UI 화면, DB/API 명세, 구현·PoC 구축, 실제 계정 비밀번호 취급, 외부 플랫폼 무단 자동 등록을 진행하지 않는다.
- 사용자 위임만으로 플랫폼이 외부 대행을 허용한다고 해석하지 않는다.
- R02의 공개 레슨 지도는 별도 확장 가설이며 이번 1차 기획의 필수 기능이 아니다.
- 기존 찾아you 관련 과거 실행/WBS는 재개하지 않으며, 기존 잠정 제출물의 접수·완료 여부도 변경하지 않는다.

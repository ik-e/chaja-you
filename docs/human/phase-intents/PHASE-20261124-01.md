## 이번 단계의 목적

## 허용

- 기존 uv 정적 검사·의존성 최소화, lock 정합성·CI 검사 구축.
- 비실명 합성 fixture, 필드/오류/상태 계약 초안, 정적 로컬 mock 폼, 테스트 실행 및 로그.
- 담당 TASK-038~042에 한정한 브랜치별 작성/검증/협의. 테스트 환경에 필요한 가역적 설계 세부는 담당자가 결정 가능.
- 브라우저는 사용자의 로컬 mock 페이지만 다루고 실제 서비스에 로그인/게시하지 않는다.

- 실제 제품 F1/F2/F3 구현, API 서버·DB·LLM·브라우저 자동화 프레임워크 선정/설치, 실제 크몽 상품 등록/자동 제출, 실서비스 세션/계정 수집.

## 적용 제한과 후속 게이트

- 이전 단계의 mock-only, 실제 크몽·숨고 로그인/게시/접수 및 무단 자동화·보안 우회 금지, 실제 민감정보/세션 취급 금지를 유지한다. 실제 화면 관측과 실제 등록 승인/성공은 다르다.
- 개인 결과와 PoC를 본 구현으로 자동 승격하지 않는다. R01이 검토·재사용/수정/폐기와 후속 설계 범위를 결정한다. R01 설계 브랜치 자체도 별도 채택 전 후보이다.
- 기존 공통 하네스와 플랫폼별 전용 PoC 배정은 현재 신규 실행 지시가 아니다. 미충족 범위는 각 TASK의 deferred_original_scope에서 확인하며 별도 TASK/일정 결정 전 자동 재개하지 않는다.
- 11/26·11/27은 기존 공통 시험·채택 목표였으며 실제 결과 범위와 설계 WBS에 따라 재조정 대상이다. 043~045의 11/24는 실제 작업 정산 기준일로 유지한다. 046~047 목표일은 별도 합의 전 미정이다.
- R01은 자기 주도형 TASK로 자동 기록하되 신규 팀원 배정은 R01 결정으로만 한다.

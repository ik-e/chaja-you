# 사람 응답

검토 화면에서 판단이 필요한 항목이 생기면 [TEMPLATE](TEMPLATE.md)를 복사해 `HRESP-YYYYMMDD-NN_짧은제목.md`로 저장합니다.

사람 응답은 AI 원본을 직접 편집하는 대신 **의도·승인·수정 지시의 출처**가 됩니다. AI는 응답을 읽고 관련 ADR·state·spec·task를 갱신하며, 중요한 결정에는 이 응답 파일을 근거 경로로 연결합니다.

## 최소 규칙

- `target`에는 `OPEN-01`, `TASK-005`, `ADR-002`처럼 검토 대상 ID를 적습니다.
- `action`은 `approve`, `modify`, `reject`, `defer`, `clarify` 중 하나를 사용합니다.
- 결정의 이유보다 중요한 새 제약이나 의도가 있으면 별도로 적습니다.
- AI는 적용 후에도 사람 응답 원문을 삭제하거나 의미를 바꾸지 않습니다.
- 응답이 서로 충돌하면 최신 파일을 자동 우선하지 말고 사람에게 충돌을 표시합니다.

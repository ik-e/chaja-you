## 사람 입력

## 적용 범위 (대화에 따른 운영 규칙 정리)

- 작업 브랜치는 현재 독립 작업을 위한 공간이다. `main`에 통합이 끝나고 추가 작업 또는 고유 산출물이 남지 않았다면 삭제한다.
- 미병합·취소·미채택·보류 작업의 경우 필요한 원본/근거·정산 사유·후속 의무를 먼저 보존하고, 브랜치 유지 필요성을 판단한다.
- 기록은 정본, PR, 불변 커밋 및 필요한 보존 자료에서 확인 가능하게 한다. 모든 병합 브랜치에 추가 태그를 만들지 않는다.
- 기존 TASK owner의 자율적 검증·통합 책임, 공유 계약 및 R01 결정 경계, 팀원 개인 브랜치의 소유권을 유지한다.
- 이 요청의 실행 범위는 main의 운영 규칙 반영이다. 실제 기존 브랜치 일괄 삭제나 저장소 자동 삭제 설정 변경은 이 작업에 포함하지 않는다.

## 적용 해석

- 이미 준비된 일곱 패키지를 신규 TASK로 등록·배정한다. R01은 자기 주도형 공통 계약·통합만 담당하며 크몽 실행기 구현은 맡지 않는다.

- R04/R05의 두 패키지는 서로 분리하며 가용성 확인 후 순서를 조정한다. 담당 변경은 R01 판단. 기존 TASK-043~047은 기존 결과와 미충족 의무를 그대로 보존하고 신규 실행에서 제외한다. 완료로 소급 전환하지 않는다.
- 실제 플랫폼 로그인·등록·실제 계정/자격증명/세션 취급 금지. 22개 제품 시험은 아직 미실행. 이번 CI는 bootstrap 검증만 통과했다.

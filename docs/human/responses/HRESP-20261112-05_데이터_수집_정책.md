## 사람 입력

프로젝트 데이터 수집 과정에서 무단 웹 크롤링을 금지한다.

- 기업·개인 웹사이트·플랫폼 등에 대한 비공식 크롤링(자동화 수집 도구·스크립트 등)을 사용하지 않는다.
- `robots.txt`가 허용하더라도 다수 요청으로 서버에 부하를 줄 수 있는 수집 행위를 허용하지 않는다.
- 사전 승인된 데이터셋을 우선 사용한다.
- 공식 Open API, 공공데이터포털, Kaggle, AI Hub 등 저작권·사용 권한이 명확한 공개 데이터를 활용한다.

## 프로젝트 적용 결정

1. 공개 열람 가능 여부와 자동 수집·저장·재사용 권한을 분리해 판단한다.
2. 일반 웹사이트의 비공식 자동 크롤링, 사이트 전체 순회, 페이지네이션 대량 수집, 대규모 HTML·리뷰·목록 축적을 MVP 수집 경로로 사용하지 않는다.
3. 일반 웹은 검색과 근거 확인을 위한 질문 해결 목적의 최소 개별 문서 조회에 한정한다.
4. 자동화 접근이 필요하면 공식 API·이용 조건·프로젝트 승인 여부를 먼저 확인한다.
5. 권한이 확인되지 않은 경우 임의로 수집하지 않고 미확인·제약·대체 출처 필요 상태로 남긴다.
6. 외부 모델·검색·브라우징 도구를 재사용하더라도 금지된 수집 방식을 우회하는 경로로 사용하지 않는다.
7. 검증 시 수집 정책 준수를 선행 gate로 적용한다. 금지된 수집 경로에 의존한 결과는 정확도나 속도가 좋아도 성공으로 판정하지 않는다.

## R01이 중요하게 보는 의도

이번 작업의 목적은 제출 규칙을 추정해서 채우는 것이 아니라, **실제로 요구되는 필수 조건과 단순 권장 가이드를 분리해 제출 직전의 불필요한 재작업을 막는 것**이다.

교육 과정의 제출 구조는 프로젝트 내부의 작업 구조와 분리한다. 실제 작업 정본은 AI와 팀이 작업하기 좋은 형태로 유지하고, 제출 시점에 확인된 규칙과 가이드에 맞는 산출물로 투영한다.

## AI가 실행 기준으로 해석한 내용

- 공식적으로 확인된 제출 위치·산출물·형식·시각·제출 방법과 아직 확인되지 않은 항목을 구분한다.
- 필수 조건이 아닌 권장 가이드는 강제 요구사항처럼 취급하지 않는다.
- 규칙이 존재하지 않는 경우 임의의 규칙을 만들지 않고 `미지정` 또는 `미확인`으로 기록한다.
- 제출물 내용은 PROJECT·spec·TASK·ADR 등 프로젝트 정본의 사실과 결정을 반영한다.
- 작업용 원본과 실제 Step 제출 파일을 분리한다.

## 과도하게 확장하지 않을 것

- 확인되지 않은 제출 규칙을 관행만으로 확정
- 가이드의 모든 항목을 의무 목차로 변환
- 제출 편의를 이유로 프로젝트 내부 정본 구조 변경
- 비공개 경로나 원문을 공개 저장소에 복사

## R01에게 남길 확인

- 정확한 파일 형식과 파일명 규칙
- 정확한 제출 시각
- Git 저장 외 별도 제출·접수 절차
- 확인된 조건과 현재 Step 제출 파일의 일치 여부

## R01이 중요하게 보는 의도

이번 작업의 목적은 새로운 화면이나 기능 아이디어를 많이 만드는 것이 아니다.

**사용자가 실제로 어떤 문제 때문에 이 시스템을 필요로 하는지, 그리고 조사 결과를 받았을 때 무엇을 확인할 수 있어야 실제 선택에 도움이 되는지를 명확히 하는 것**이 중요하다.

사용자 문제, 시스템이 제공할 결과, 그 가치의 검증 방법이 서로 연결되어야 한다.

## AI가 실행 기준으로 해석한 내용

R04 결과에서는 다음 흐름을 우선 확인한다.

**사용자 문제 → 필요한 정보와 판단 → 결과 화면에서 보여줄 내용 → 사용자가 취할 다음 행동**

특히 결과에서는 다음이 필요한지 검토한다.

- 어떤 후보가 사용자 조건을 충족하는가
- 왜 그렇게 판단했는가
- 판단 근거와 출처가 무엇인가
- 무엇이 아직 미확인인가
- 필수 조건과 선호 조건이 어떻게 다른가
- 사용자가 직접 추가 확인해야 할 것이 있는가

기존 앱스토어 검색, 일반 검색, 범용 AI 등으로 이미 충분히 해결되는 부분과 찾아you가 추가로 제공해야 할 가치를 구분한다.

## 과도하게 확장하지 않을 것

- 사용자 근거 없이 기능 목록을 늘리는 것
- 화면 디자인을 제품 문제보다 먼저 확정하는 것
- 현재 MVP와 관련 없는 사용자 유형 확대
- 실제 검증 없이 기존 서비스보다 우월하다고 단정하는 것

## 담당자가 자율적으로 판단해도 되는 것

- 사용자 흐름 표현 방식
- 결과 화면의 정보 구조 초안
- 기존 대안 비교 방법
- 사용자에게 확인할 질문과 검증 방법

## R01에게 돌려줄 결정

- 사용성 검증에서 어떤 결과를 성공으로 볼 것인지

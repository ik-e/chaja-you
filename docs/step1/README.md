## 필수 제출물

- [기획서](기획서.md)
- [WBS](WBS.md)

[2026-11-16 공식 OUTPUT-GUIDE 확인](../guidelines/2026-11-16_OUTPUT-GUIDE_적용확인.md)에 따르면 **제공된 목차를 기본으로 각 항목을 빠짐없이 작성**해야 합니다. 다만 기획서와 WBS의 **실제 제공된 세부 목차 및 별도 WBS 제출 안내는 아직 확인되지 않았으므로** 공식 양식과 대조해야 합니다. 샘플 수치·결과는 팀 내용으로 바꾸고 미결정·미구현은 상태를 명시합니다. 문서 업로드만으로 제출 완료가 아니며, 팀 대시보드 산출물 제출 표에 **링크 등록 후 상태를 '제출완료'로 변경**해야 합니다.

작업 정본은 `docs/artifacts/`, 사람의 의도와 판단은 `docs/human/`, 사람이 보는 검토 화면은 `docs/review/`, 전체 제출 상태는 `docs/submissions/README.md`에서 관리합니다.

제출 형식·파일명 규칙·정확한 제출 시각·별도 제출 동작이 확인되면 상태 원본과 TASK-002에 갱신합니다.

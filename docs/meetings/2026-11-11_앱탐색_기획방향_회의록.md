## 요약

전사문은 범용 인터넷 조사 시스템을 한 번에 구현하기보다 특정 도메인에서 작은 조사 흐름을 완성한 뒤 확장하는 방향을 논의했다고 기록한다. 전사문상 초기 도메인은 **앱 탐색 및 비교**이며, 기존 앱 검색·비교와 덜 알려진 신규 앱 발굴을 두 가지 탐색 모드로 구분한다. RAG와 기억 저장, 출처 지도, 사용하기 쉬운 결과 표현은 차별화 후보로 제시됐지만, 모두 구현하기로 확정된 것은 아니다.

아래의 “합의”는 전사문이 합의로 표시한 내용을 옮긴 것이며, 참석자 확인이나 별도의 공식 결정 확인을 의미하지 않는다. 이 문서는 현재 팀 기준을 자동 변경하지 않는다.

## 전사문에 기록된 합의

| 항목 | 전사문 내용 | 상태 |
|---|---|---|
| 프로젝트 방향 | 멀티 에이전트 기반 AI 조사 시스템 | 전사문상 합의 |
| 초기 도메인 | 앱 탐색 및 비교 | 전사문상 합의. 실제 사용자 문제와 구체 범위는 추가 구체화 필요 |
| 검색 모드 | 기존 앱 탐색·비교와 새로운 앱 발굴 | 전사문상 기본 방향 합의. 두 모드 모두 MVP 필수인지는 미정 |
| 개발 접근 | 작은 워크플로우부터 완성하는 보텀업 접근 | 전사문상 합의 |
| 기획 절차 | 각자 기획안을 작성한 뒤 공통점을 모아 통합 | 전사문상 합의. 담당자와 제출 기한 미확인 |

## 제안으로 남은 기능

- 출처 지도: 도메인별 주요 사이트와 검색 경로를 관리하고, 지도 밖의 신규 출처도 찾을 방법을 검토한다.
- 기억/RAG: 이전 조사 결과, 선호 조건과 검토한 출처를 재사용한다. 무엇을 보존하고 갱신할지는 미정이다.
- 조사 과정·결과 시각화: 진행 상태, 비교표, 간결한 핵심 요약 등을 검토한다.
- 개인화와 과거 대화 가져오기: 개인정보 및 동의·보안 설계를 별도로 검토한다.
- 동적 에이전트 팀 구성 및 다른 도메인 확장: 차별성과 구현 비용을 평가한 뒤 우선순위를 정한다.

전사문은 앱 탐색이 비교 항목을 구조화하기 쉽고 시연 사례를 만들기 좋다는 의견을 기록한다. 동시에 신뢰할 정보 확보와 비교 기준 설정이 필요하다고 지적한다. 중고거래·의류, 게임, 스포츠 기록, 음악 탐색도 후보로 거론됐으나 초기 도메인으로 선택한 것으로 기록되지는 않았다.

## 구현 범위 논의에 반영할 쟁점

- 단순 검색·요약은 기존 AI 서비스와 겹칠 수 있으므로, 앱 비교에서 어떤 사용자 문제를 더 잘 해결하는지 구체화한다.
- 앱 검색과 신규 발굴은 검색 범위·시간·비용이 다를 수 있어 별도 요구사항과 완료 기준으로 정의한다.
- 출처 지도와 기억은 장기 차별화 후보지만, 출처 최신성·오류 정정·개인정보·콘텐츠 이용 조건을 함께 설계한다.
- 앱스토어 등 원천별 데이터 접근 가능성, 공개성, 이용 조건과 갱신 주기를 확인한다.
- 화면 시각화와 개인화 등 부가 제안은 필수 워크플로우가 동작한 뒤 우선순위를 결정한다.

## 미확인 사항

- 회의가 열린 정확한 날짜와 5·6교시의 일차 표기
- 참석자와 최종 의사결정 확인 여부
- 개인 기획안의 담당자별 제출 기한 및 통합 담당자
- 앱 탐색·비교의 구체 사용자, 대표 문제, 대상 앱 범위와 성공 기준
- 기존 앱 탐색과 신규 앱 발굴 중 MVP에서 필수로 구현할 범위
- 기억/RAG, 인터넷 출처 지도, 시각화, 개인화의 우선순위

# 회의록

회의가 열리면 날짜별 Markdown 파일을 만듭니다. 정기 회의는 두지 않으며, 팀장이 필요할 때 회의를 소집합니다. 기록에는 확인된 안건·결정·담당자·기한만 씁니다. 참석자나 결론이 확인되지 않으면 추정하지 말고 미확인으로 표시합니다.

템플릿: [회의록 템플릿](templates/회의록_템플릿.md)

# 회의록

Discord 회의 자료를 회의별로 대조해 만든 공개 검토용 요약입니다. [첫 회의부터 읽기](reviews/MEET-20261110-01.md)를 열고 각 문서의 다음 회의 링크로 이어서 검토할 수 있습니다. 문서 ID의 날짜는 Discord 게시일입니다.

> 전사와 게시글은 화자·맥락이 빠지거나 서로 다를 수 있습니다. 여기에 나온 발언의 주체, 당시 의도, 실제 합의 여부는 미확인입니다.

기억과 다른 부분은 회의 ID와 함께 [사람 응답](../human/responses/README.md)에 남길 수 있습니다. 필요한 의도와 합의는 권한 있는 담당자가 확인해 [INTENT](../human/INTENT.md), [ADR](../adr/README.md), [상태·명세·TASK 원본](../artifacts/README.md) 등 해당 기준 문서에 별도로 기록합니다.

원문과 첨부는 [비공개 로컬 보관](originals/README.md)에 두고, 공개 요약에는 업무상 핵심 내용만 담습니다.

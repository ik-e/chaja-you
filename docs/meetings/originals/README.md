# Discord 회의 원본 로컬 보관

2026-11-24 확인 기준, 봇이 볼 수 있는 Discord `#회의록`의 활성·공개 보관 스레드 16개, 메시지 21건과 첨부 10건을 이 디렉터리의 로컬 전용 하위 경로 `discord/`에 보존했습니다. 게시글과 답글은 API 응답의 메시지 객체 그대로 JSON에 저장했고, 텍스트와 PDF 첨부는 바이트를 그대로 보존했습니다. 비공개·삭제 자료의 존재나 내용은 확인 범위 밖입니다.

로컬 `discord/manifest.json`은 [공개 검토 목록](../README.md)과 같은 회의 ID로 각 기록을 찾고 첨부의 바이트 수와 SHA-256을 확인하는 색인입니다. 공개 저장소에는 이 안내와 공개용 요약만 포함합니다. 원문·첨부·로컬 색인은 Git에서 제외합니다.

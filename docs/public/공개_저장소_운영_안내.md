이 저장소는 **공개 저장소**입니다. 저장소에 푸시한 코드와 문서, 커밋 작성자 정보와 변경 이력은 누구나 볼 수 있고, 파일을 나중에 삭제해도 기존 Git 이력이나 복제본에서 완전히 회수되지 않을 수 있습니다.

## 공개 저장소에 올릴 내용

- 프로젝트 코드, 공개 가능한 설계 설명과 사용 방법
- 재배포 조건을 확인한 자료 또는 원문 링크와 출처
- 팀의 이름·개인정보·내부 대화가 제거된 협업 규칙

## 공개 저장소에 올리지 않을 내용

- `.env`, Discord 봇 토큰, API 키, 비밀번호, 개인 키
- 개인별 일일 상태, 연락처, 개인 계정 식별자
- Discord 원문 메시지·첨부, 서버·채널·사용자 ID
- 팀원이 제출한 원본 자료, 내부 회의록과 비공개 대시보드·즐겨찾기 사본
- 재배포 권한을 확인하지 않은 교육 자료나 제3자 문서 복사본

필요한 내용을 공유하려면 개인정보와 식별자를 제거한 공개용 요약을 별도로 작성하고, 외부 자료는 원문 링크·출처·라이선스를 확인합니다. 공개 가능 여부가 불분명하면 푸시하지 말고 공개 저장소 밖의 팀 승인 공간에 보관합니다.

## 코드 작업 방식

- `main`에 직접 푸시할 수 있고 개인 브랜치는 선택적으로 사용합니다. PR은 필수 절차로 두지 않습니다.
- 각 담당자는 변경한 범위에 맞춰 최소한의 자체 확인을 수행하고, 결과와 남은 위험을 설명합니다.
- 통합·QA·배포·릴리스는 지정된 책임자가 맡습니다. 다른 팀원의 결과물 검토를 필수 절차로 두지 않습니다.
- 공유 코드에 영향을 주는 변경은 관련 담당자에게 알리고, 결정·사용법처럼 남겨야 할 내용은 공개 가능한 문서로 갱신합니다.

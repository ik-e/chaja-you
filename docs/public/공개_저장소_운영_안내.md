# 공개 저장소 운영 안내 — 팀 공유용

`chaja-you`는 공개 GitHub 저장소이자 팀 공동 작업 공간입니다. 코드와 팀 헌장, 회의 요약, 프로젝트 계획, 설계, 조사, 협업 규칙과 일일 작업 문서를 함께 관리합니다. 저장소와 Git 이력은 누구나 볼 수 있고, 파일을 나중에 삭제해도 기존 복제본과 커밋에서 완전히 회수되지 않을 수 있습니다.

## 저장소에 기록할 내용

- 팀 작업에 필요한 결정, 계획, 회의 요약, 설계와 일일 진행 상태
- 프로젝트 코드와 실행·사용 방법
- 출처가 확인된 조사 요약과 외부 원문 링크

## 저장소에 기록하지 않을 내용

- `.env`, Discord 봇 토큰, API 키, 비밀번호, 개인 키
- 개인 이메일·전화번호 등 연락처와 민감한 개인 정보
- 비공개 대시보드·드라이브·Notion 페이지 URL, Discord 초대 링크와 내부 메시지 permalink
- 즐겨찾기 내역과 개인 계정 식별자
- 재배포 권한이 확인되지 않은 교육 자료·제3자 문서의 원본 사본

기록에 개인별 상태나 이름이 포함되는 경우 팀 작업에 필요한 최소 내용만 작성합니다. 외부 문서는 원문 링크와 필요한 요약을 우선하고, URL이 공개 가능한지 먼저 확인합니다. 비공개 주소가 필요하면 저장소에 넣지 말고 팀의 승인된 비공개 경로를 사용합니다.

## 코드 작업 방식

- `main`에 직접 푸시할 수 있고 개인 브랜치는 선택적으로 사용합니다. PR은 필수 절차로 두지 않습니다.
- 각 담당자는 변경한 범위에 맞춰 최소한의 자체 확인을 수행하고, 결과와 남은 위험을 설명합니다.
- 통합·QA·배포·릴리스는 지정된 책임자가 맡습니다. 다른 팀원의 결과물 검토를 필수 절차로 두지 않습니다.
- 공유 코드에 영향을 주는 변경은 관련 담당자에게 알리고, 결정·사용법처럼 남겨야 할 내용은 문서로 갱신합니다.

## 팀에 전달할 메시지 초안

> `chaja-you` GitHub 저장소를 팀 공동 작업 공간으로 사용합니다. 팀 헌장, 회의 요약, 계획, 설계, 조사와 일일 작업 문서를 저장소에서 함께 관리합니다. 저장소와 커밋 이력은 공개되어 누구나 볼 수 있으니 `.env`, 토큰·API 키·비밀번호, 이메일·전화번호, 비공개 대시보드·드라이브·Notion 주소, Discord 초대 링크·내부 메시지 링크, 개인 즐겨찾기와 재배포 권한이 확인되지 않은 원본 파일은 올리지 말아 주세요. 개인 상태는 업무에 필요한 최소 내용만 기록하고, 공개 여부가 애매한 자료는 먼저 팀장에게 확인해 주세요. 이미 비밀값을 올렸다면 파일 삭제만으로 해결되지 않으므로 즉시 키를 폐기·교체하고 알려 주세요.

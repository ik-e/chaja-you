# 프로젝트 개요

## 목표

사용자의 조사 요청을 분석하고, 필요한 정보를 확인 질문으로 구체화한 뒤, 조사 작업을 분해하고 적절한 전문 에이전트를 구성해 결과를 종합하는 시스템을 개발합니다.

## 핵심 흐름

1. 사용자 요청과 원하는 결과 형식을 파악합니다.
2. 불명확한 조건과 범위를 질문으로 확인합니다.
3. 조사 목표를 하위 작업으로 나누고 역할을 구성합니다.
4. 각 작업의 출처와 근거를 기록하며 조사합니다.
5. 조사 결과를 교차 정리하고 출처가 연결된 보고서로 종합합니다.

## 설계 원칙

- 실제 구현 범위와 시연 시나리오는 검증된 사용자 문제와 데이터 접근 가능성을 바탕으로 결정합니다.
- 확인한 사실과 가정·미해결 항목을 구분합니다.
- 조사 결과에는 출처와 확인 시점을 남깁니다.
- MVP는 핵심 흐름을 검증할 수 있을 만큼 작게 유지합니다.

이 문서는 공개 가능한 개요이며, 내부 논의 기록이나 개인별 담당·진척 상태를 포함하지 않습니다.

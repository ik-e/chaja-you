## 무엇을 바꾸었나

- 강사 대시보드 **1팀 L26(기획서), L27(WBS)**에 있는 현재 산출물별 의견을 우선 적용
- 같은 의견에서도 **주제 확정 전 준비 / 주제 확정 후 보완**을 분리. 후속 요구를 현재 기술·구현 확정 지시로 취급하지 않음
- L28·L29는 아직 **Step2 API/DB 산출물별 강사 의견 없음**. 과거 L53/L55 일일 피드백을 현행 강사 승인처럼 이용하지 않음
- 날짜·유효성만이 아니라 **적용 대상, 선행 조건, 현재 상태, 증거 수준**을 기준으로 해석
- DOCX 수정본의 존재는 L53 피드백에 나타나지만 **실물/최종 의무 목차는 미검증**, 공식 형식 G0 미통과

# 조사 원본 보관

수집한 PDF, HTML, CSV, 이미지 등 원본 자료를 여기에 둡니다. 파일은 가능한 한 원래 이름과 형식을 유지하고, `topics/` 문서에서 출처와 수집 날짜를 연결합니다.

Discord 조사 논의 출처: [2026-11-10 킥오프 회의 기록](../../meetings/2026-11-10_킥오프_회의록.md). 상옥님이 올린 두 `message.txt` 첨부는 [회의록 원본 폴더](../../meetings/originals/README.md)에 원본으로 보존했습니다. 조사 계획과 주제별 정리는 `topics/`에 링크하며, 두 텍스트 자체는 회의록 초안입니다. 외부 출처를 갖춘 별도 조사 보고서나 조사 근거 자료는 첨부에 포함되지 않았습니다.

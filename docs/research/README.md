# 리서치

- 조사 주제마다 출처 URL, 열람일, 조사자, 원본 파일을 기록합니다.
- 원본을 편집하지 않습니다. 정정이나 요약은 주제 문서에 남깁니다.
- 조사 결과가 제품 결정으로 이어지면 관련 설계 결정 문서에 연결합니다.

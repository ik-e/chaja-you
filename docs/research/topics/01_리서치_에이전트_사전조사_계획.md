## 조사 항목

- 유사 서비스와 선행 사례: 제공 기능, 사용 대상, 해결하는 문제, 차별점
- 구현 기술과 아키텍처: 데이터 접근, 외부 연동, 검색·분석 방식, 검증 방법
- 실제 적용 도메인: 사용자가 실제로 겪는 문제와 시연에 사용할 수 있는 사례
- 데이터 출처와 접근성: 사용할 API·자료의 확보 가능 여부 및 신뢰성

## 회의에서 검토한 주제

여러 프로젝트 후보를 논의한 뒤 동적 리서치 에이전트 생성 시스템을 중점 검토 방향으로 두었습니다. 사용자의 목적에 따라 전문화된 조사 에이전트를 구성하는 아이디어였으며, 원문은 공식 주제 확정 전이라고 표시합니다.

## 미확인 사항

회의록에는 조사 담당자별 산출물, 실제 조사 결과, 검증된 외부 출처가 포함되어 있지 않습니다. 후속 조사는 출처와 조사일을 별도 기록해야 합니다.
